# RL 短程序实验：同一个选择，算三次

把任务固定住：在 `start` 可以立即退出拿 1 分，也可以先投入、付出 0.2 分，到 `work` 后完成并拿 2 分。奖励是一步之后拿到的分数；回报是从当前起把未来奖励按时间合起来的总分；折扣因子 $\gamma$ 决定未来一分在今天按多少计。三个实验都使用 $\gamma=0.9$，只用 Python 标准库。

## 第一遍：先比回报

手算：立即退出是 1；先投入再完成是 $-0.2+0.9\times2=1.6$。先预测哪个选择更好，再运行：

```powershell
python -X utf8 RL/experiments/mini_walkthrough.py return
```

把 $\gamma$ 改成 0.5，投入路线就变为 0.8，选择反过来。这说明“更远的大奖励”是否值得取决于任务怎样定义回报，不是算法背出一个固定答案。[第 1 章](chapters/01_MDP与回报.md)把这个算式扩展为状态、行动与策略。

## 第二遍：从整条路变成一步递推

在 `work` 直接完成的价值是 2；若先等待，当前扣 0.1，之后再完成，价值是 $-0.1+0.9\times2=1.7$。**价值**是给定所处状态或所选动作后，未来回报的期望；在这个确定性例子里，期望就等于手算结果。Bellman 递推把“本步奖励”和“下一步起的价值”加在一起。

```powershell
python -X utf8 RL/experiments/mini_walkthrough.py bellman
```

输出同时给出 `start` 中选择投入的价值 1.6。先把三个数字在纸上写出来，再读[第 2 章](chapters/02_Bellman方程与动态规划.md)的通式。

## 第三遍：只有一次经历时怎样改估计

如果我们尚不知道环境规则，只经历一次“投入后到达 `work`”，可以用当前对 `work` 的估值 2 来构造目标 $-0.2+0.9\times2=1.6$。把 `start` 中投入的旧估计设为 0、学习步长 $\alpha=0.5$，一次更新得到 $0+0.5(1.6-0)=0.8$。这叫一次**时序差分**（TD）更新：拿“已见到的一步奖励 + 尚未走完的未来估计”修改当前估计。

```powershell
python -X utf8 RL/experiments/mini_walkthrough.py update
```

0.8 是更新**一次后的估计**，不是任务真实价值 1.6。若把它误读成最优回报，就把“模型目前知道多少”和“环境实际上怎样”混在一起了。[第 3 章](chapters/03_MC_TD与Q学习.md)解释重复采样、MC 与 Q-learning。全部运行可用 `python -X utf8 RL/experiments/mini_walkthrough.py all`；随后再做[完整表格实验](experiments/README.md)。
