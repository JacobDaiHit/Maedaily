# GAE：为策略梯度选择一个可调的优势估计器

> 省流：把未来 TD 残差按几何权重相加，用 lambda 调节估计方式。它首先改的是梯度估计质量，而不是单独定义一种新策略优化器；原论文实验搭配 TRPO，后来也可与 PPO 组合。

## 什么水平、值不值得读

- **发表事实**：本地 v6 PDF 首页注明 ICLR 2016 conference paper；首稿在 2015 年。
- **阅读判断**：核心方法，优先级高。适合研究偏差、方差和截断误差之间的关系。
- **版本**：1506.02438v6，2018-10-20；[原始页面](https://arxiv.org/abs/1506.02438v6)；[本地 PDF](../pdf/1506.02438.pdf)。检索日 2026-09-26。

## 做了什么，试验了什么

GAE 由多步优势估计的加权组合得到。价值函数不准确时，lambda 的变化会影响偏差与方差；有限轨迹还需要处理末端自举。公式和手算见 [Actor-Critic 与 GAE](../../chapters/06_ActorCritic与GAE.md)。

原文 §6 固定策略更新方法，比较不同 gamma、lambda；任务包括 cart-pole、双足和四足运动、双足起身。图 2—3 展示参数与学习曲线，双足实验平均 9 次运行、四足平均 5 次。模拟器采用 MuJoCo；这提供连续控制中的实验证据。

## 应用和结论边界

已有验证场景是模拟控制。语言模型 PPO 中可将 token 序列映射成轨迹，但仍要重新处理回答末端、padding、奖励位置和价值头；原文没有做 LLM 实验。

我的判断是：它很适合数学背景读者，因为推导能直接解释工程超参数；但某个任务中最好的 lambda 不是通用常数。读原文 §3—4 时，区分折扣目标本身的选择、价值估计误差与截断造成的偏差。

**读后检查**：取两步轨迹，手算 lambda 为 0 和 1 的结果；再把自然终止改成人工截断，解释最后一个价值为何可能不应置零。不要在同一实验里同时换优化器和优势估计器，再把收益全部归因于 GAE。
