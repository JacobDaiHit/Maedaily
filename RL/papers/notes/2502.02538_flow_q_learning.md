# Flow Q-Learning：让离线策略既能表达复杂动作，又能一步执行

**省流：** FQL 用 flow matching 学行为分布，再把动作生成蒸馏到另一个单步策略，让后者接受 Q 值优化。这把拟合数据和争取更高回报分给两个网络，是理解现代离线 RL、生成式策略与策略提取的好入口；不宜据此声称 flow 全面胜过 diffusion。

## 做了什么，试验了什么

FQL 用 flow 行为策略表示多峰动作分布，另训练单步噪声条件策略，同时追求高 Q、贴近同一噪声对应的 flow 动作。Q 梯度无需穿过迭代 ODE 求解器；部署动作一步生成，训练中的教师采样仍需迭代。读 §3、算法 1 和附录 B。

§5 覆盖 OGBench、D4RL 的 73 个状态或像素模拟任务，另做 15 项离线转在线实验。比较 BC、IQL、ReBRAC、扩散策略及不同策略提取方式；状态任务用 8 个种子，像素任务用 4 个。消融涉及行为约束、flow 步数、时间采样和价值聚合。

## 应用与局限

**论文验证**：仿真导航、操作、利用在线交互继续改进策略。**潜在应用**：真实机器人控制，尚非本文部署证据。附录 A 承认没有真实任务验证，也没有专门探索机制；行为约束系数仍需调节。

**学习建议**：先读 [离线 RL 章节](../../chapters/08_探索_离线RL与评测.md)，画出行为策略、单步策略、Q 网络的梯度箭头。小实验固定数据和训练预算，比较成功率、种子差异、动作生成耗时及约束敏感性。迁移到 LLM 还要处理离散 token 和序列信用分配，不能直接照搬连续动作公式。
