# 强化学习书籍导读

**想直接开始学习，先读 [中文精讲：强化学习从零上手](../从零上手.md)。** 它已实际阅读下面理论书第 1 章的相关页面，将关键问题用原创算例、逐步手算、练习答案和运行命令讲清；英文 PDF 用于后续核对，不是入门前置要求。

## 已下载：Reinforcement Learning: Theory and Algorithms

作者为 Alekh Agarwal、Kianté Brantley、Nan Jiang、Sham M. Kakade、Wen Sun。[作者主页](https://rltheorybook.github.io/)公开提供书稿；本地保存的是 **2026-06-27 working draft，227 页**：[PDF](pdf/rl_theory_2026.pdf)。在线 URL 可能继续更新，因此以封面日期和下载校验值识别本地版本。

**省流**：这是一部偏理论的研究生读物，适合关心“需要什么假设、多少样本、为什么可学或不可学”的读者。它是理论教材草稿，不是实验论文；不能给它套一组模型 benchmark 或顶会等级。内容定位依据作者页面和本地目录。

| 当前学习问题 | 建议阅读 | 配套动作 |
| --- | --- | --- |
| MDP、Bellman 和动态规划 | 第 1 章，尤其 §1.1—1.3 | 完成仓库的三状态例子，写出压缩假设 |
| 估计模型需要多少样本 | 第 2 章 | 区分生成模型采样接口与沿一条轨迹收集数据 |
| 函数逼近何时有保证 | 第 3 章 | 比较可实现性与 Bellman completeness，找出弱假设为何不足 |
| 探索为什么不是简单随机 | 第 5—6 章 | 从 bandit 到 MDP，明确误差如何沿决策传播 |

**难度判断**：高于只介绍算法的入门材料。第一遍不必证明全部样本复杂度界，先把定理写成“假设—结论—不能推出什么”。它适用于理论分析、离线数据覆盖与算法保证的学习，不是开箱即用的 PyTorch 工程手册。新草稿还可能修订，重要证明需要自行检查。
