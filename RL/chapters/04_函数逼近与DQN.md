# 第 4 章　函数逼近与 DQN：表格装不下时怎么办

图像、连续位置和语言前缀的状态空间太大，无法为每个状态单独建表。函数逼近用共享参数表示价值，相似输入能够共享经验；代价是修改一个状态的估值也会影响其他状态。表格算法的一步局部更新，变成了整个函数的联动变化。

把前几章的小表想成一本字典：每个状态和动作都要有独立的一格。若状态是一张图片，几乎每张都不同，字典就装不下。**函数逼近**改用一个函数接收状态与动作，输出估计价值；相似输入会共享参数。**DQN**（深度 Q 网络）用神经网络实现这个函数。读下面的网络公式时，仍要问它估的是前几章哪一格、目标值从哪来。

## 4.1 从查表到带参数的函数

记 $Q_\theta(s,a)$ 为参数向量 $\theta$ 表示的行动价值函数。线性模型可写 $Q_\theta(s,a)=\phi(s,a)^\top\theta$，其中 $\phi$ 是特征向量；神经网络则自动学习更复杂的特征。对于离散行动，DQN（Deep Q-Network）通常输入一批状态，输出形状为 $[B,|\mathcal A|]$ 的所有行动价值，$B$ 是批大小。训练时只取实际执行行动对应的列，得到形状为 $[B]$ 的预测。

一个直观问题是标签也依赖模型。如果直接用同一网络估计 $r+\gamma\max_aQ_\theta(s',a)$，你更新预测时也在改变目标。即使每次做的是平方误差下降，真实 Bellman 误差也未必下降。

## 4.2 DQN 的三个部件

常用 DQN 用在线网络 $Q_\theta$ 学习，用参数暂时固定的目标网络 $Q_{\bar\theta}$ 产生目标，并从回放缓冲区 $\mathcal D$ 随机抽取过去的转移。对样本 $(s,a,r,s',d)$，其中 $d$ 是真正终止指示，定义

$$
y=r+\gamma(1-d)\max_b Q_{\bar\theta}(s',b),\qquad
L(\theta)=\mathbb E_{\mathcal D}\left[\tfrac12(Q_\theta(s,a)-\operatorname{stopgrad}(y))^2\right].
$$

$\operatorname{stopgrad}$ 表示不沿目标传播梯度。梯度为 $(Q_\theta-y)\nabla_\theta Q_\theta$，这是半梯度更新。回放减弱相邻样本的相关性并提高复用率；目标网络减慢目标漂移。二者是有实验证据的稳定化办法，不是任意非线性网络的收敛定理。2013 年的 [Atari 深度强化学习论文](https://arxiv.org/abs/1312.5602)奠定了像素输入与经验回放路线；常见包含独立目标网络的版本应同时查阅 [2015 年 Nature 论文](https://doi.org/10.1038/nature14236)，不要把两个版本的全部细节混为一谈。

```text
初始化在线网络 θ，拷贝到目标网络 θ_bar，建立回放缓冲区
循环：
    用在线网络的 ε-greedy 策略与环境交互
    保存状态、行动、奖励、真正的最后观测与终止标志
    数据足够后随机采样 B 条转移
    无梯度计算目标 y；抽取 Qθ(s,a)；最小化回归损失
    每 C 次更新将 θ 拷贝到 θ_bar
```

自动重置的环境可能返回新回合起点，计算截断的尾部价值时应使用上一回合真正的最后观测。把新回合起点当成 $s'$ 会把两个任务错误串接。

## 4.3 手算目标与 Double DQN

设当前预测 $Q_\theta(s,a)=0.5$，奖励 $r=-0.2$，$\gamma=0.9$，下一状态目标网络输出 $[2.0,1.7]$，样本未终止。则 $y=1.6$，平方损失为 $\tfrac12(0.5-1.6)^2=0.605$。若该转移真正终止，则目标只有 $-0.2$，与下一状态输出无关。

对含噪声的多个估计取最大值容易选择到正误差较大的项。例如两个行动真值都为 0，每个估计独立等概率取 $+1$ 或 $-1$，最大估计的期望为 $0.5$。这不是行动真的更好，而是选择过程放大了噪声。

Double DQN 将“选哪个行动”与“评价这个行动”分开：

$$
y_{\mathrm{DDQN}}=r+\gamma(1-d)Q_{\bar\theta}\!\left(s',\arg\max_bQ_\theta(s',b)\right).
$$

若在线网络下一状态输出 $[1.0,1.2]$，目标网络仍是 $[2.0,1.7]$，Double DQN 选第二个行动，得到 $-0.2+0.9\times1.7=1.33$，而普通 DQN 目标为 1.6。它能缓解特定过估计问题，并不意味着两个网络独立或误差完全消失。[原论文](https://arxiv.org/abs/1509.06461)在 Atari 上检验了过估计及其修正。

## 4.4 为什么 loss 降低仍会失败

函数逼近、自举、off-policy 数据同时出现时，存在发散反例，常被称为“致命三要素”。这表达可能发生的不稳定组合，并不是说三者一起使用必定发散。工程诊断应同时记录回报、价值量级、TD 误差、探索率、缓冲区覆盖与梯度范数。若奖励尺度乘了 100，价值与损失尺度也会变，原来的学习率和裁剪阈值未必合适。

动作最大化是另一边界：DQN 适合可枚举的离散行动。连续控制中直接求 $\arg\max_aQ(s,a)$ 可能很难，需要另一个优化器或策略网络。语言模型虽是离散词表，但长序列、巨大行动空间与数据分布变化使“把 DQN 原样搬来”并不自然。

## 4.5 深入：半梯度、广播错误与反馈失稳

### 下降的回归 loss 不等于正确的固定点

一个最小反馈反例：固定 replay 只含 s→s'、奖励0、未终止；函数共享参数 $Q(s)=\theta,Q(s')=2\theta$，gamma=.9。若每步目标取当前参数并 detach，$y=1.8\theta$，半梯度更新为 $\theta\leftarrow\theta+\alpha(1.8\theta-\theta)=(1+0.8\alpha)\theta$，非零初值发散。真实任务可令 s' 下一步零奖励终止，但 replay 没有该数据，覆盖缺失和共享参数造成反馈。

若目标固定一段时间，可以把该段回归误差降到接近零，但刷新目标后又继续放大。这是构造的反例，不说明所有 target network 必然失败。若把同一个参数代入残差后完整求导，loss=$0.32\theta^2$、梯度=$0.64\theta$，是另一种更新，不能称为相同 DQN。

一般期望 Bellman 残差平方的完整梯度还可能出现 double-sampling 问题：条件期望的乘积不等于同一个转移样本中两个随机量的乘积；独立下一状态样本可避免该协方差项。停止梯度的 TD、采样平方误差和精确 Bellman 残差优化分别定义目标，不能互换证明。

### 最小 DQN 张量检查

输出 `q_all:[B,A]`，动作 `actions:[B]`，应取 `q_all.gather(1,actions[:,None]).squeeze(1)` 得 `[B]`；目标也是 `[B]`。预测保留 `[B,1]` 而目标为 `[B]`，相减会广播成 `[B,B]`，每个预测错误地拟合所有样本目标。B=2、预测[1,3]、目标[0,2]时，正确均方误差1，错误广播均方误差3。

目标在无梯度区计算，真正终止清尾值，合法动作 mask 作用于下一动作选择。Huber loss 在大误差区域改为线性增长，减小极端样本的梯度影响；它不能修复奖励、覆盖或 done 错误。

记录 target 更新间隔、replay 分布、探索和各桶的 Q 范围；折扣有界奖励的真实 Q 不应超过 $R_{max}/(1-\gamma)$。估计超过界是诊断信号，并不是直接裁剪就证明收敛。

## 4.6 完整自测与面试问答

### 题 1：DQN 为什么固定目标端的梯度？

**题目：**DQN 用在线网络 $Q_\theta$ 预测，目标网络 $Q_{\bar\theta}$ 构造 $y=r+\gamma(1-d)\max_bQ_{\bar\theta}(s',b)$，损失为 $L=\tfrac12[Q_\theta(s,a)-y]^2$；$d=1$ 表示真正终止。请解释更新在线网络时为什么停止沿 y 求导，以及让目标网络也反向并更新会改变什么。

**参考答案：**在这次在线更新中，目标被视为固定回归标签，梯度为 $(Q_\theta-y)\nabla_\theta Q_\theta$。目标网络通过预先规定的复制或平滑同步更新。若也沿目标端优化，会得到推动标签本身变化的导数，偏离这个半梯度更新，可能只让预测和目标互相追逐。

**面试追问：**目标网络与经验回放分别解决什么？

**追问回答：**目标网络减缓自举标签的快速漂移；回放复用旧交互并减轻连续样本相关性。二者有助于训练，但不保证任何函数逼近任务都稳定收敛。

### 题 2：取最大估计为什么可能过估计？

**题目：**两个动作真实价值都为 0，估计误差各自独立，以相同概率取 +1 或 -1。估计值等于误差。列出四种等概率组合，求两个估计的最大值期望，解释为何它不等于真实最优价值。

**参考答案：**组合为 `(1,1)`、`(1,-1)`、`(-1,1)`、`(-1,-1)`，最大值依次为 1、1、1、-1，期望 `(1+1+1-1)/4=0.5`。单个估计无偏，但选最大值偏向正误差，真实最优价值仍为 0。

**面试追问：**Double DQN 怎样把选择与评价分开？

**追问回答：**在线网络选择下一动作，目标网络评价所选动作，缓解这种选择误差。它不要求两个网络完全独立，也不保证消除全部估计偏差。

### 题 3：经验回放能使用旧策略数据吗？

**题目：**DQN 的缓冲区只保留过去探索策略的转移，当前策略已经改变。请说明这种复用是否自动错误，并解释覆盖不足、过时数据与函数逼近误差可能怎样影响学习；如果数据完全没有某动作，应如何判断其估计可信度？

**参考答案：**Q-learning 型更新允许行为策略与目标贪心策略不同，使用旧数据不自动构成错误。但缺少关键状态动作、环境已变化或估计在未见动作上外推，都可能失效。未覆盖动作的低训练误差没有提供证据，应检查覆盖与独立交互结果。

**面试追问：**为何不能把同一回放方式直接用于 REINFORCE？

**追问回答：**标准 REINFORCE 的期望按当前策略采样。直接使用旧策略数据会改变采样分布，需要适当校正与相应条件；DQN 可复用旧数据的理由不能代替策略梯度的推导。

### 题 4：手算 DQN 与 Double DQN 的目标

**题目：**非终止转移奖励 $r=-0.2$，折扣 $\gamma=0.9$。下一状态在线网络输出 $[1.0,1.2]$，目标网络输出 $[2.0,1.7]$，两维对应相同的两个动作。分别用目标网络最大值构造 DQN 目标，用在线网络 argmax 选择、目标网络评价构造 Double DQN 目标。

**参考答案：**DQN 取目标网络最大值 2.0，目标为 $-0.2+0.9\times2=1.6$。Double DQN 在线选择第二动作，目标网络给它 1.7，目标为 $-0.2+0.9\times1.7=1.33$。若真正终止，两者均为 $-0.2$。

**面试追问：**为什么不能在连续动作中直接照抄 max？

**追问回答：**连续集合通常不可枚举，求 Q 的最大值本身是优化问题；需要额外求解或策略网络，算法结构随之改变。

后训练中的价值头也有函数逼近与目标漂移问题；奖励模型又增加了一层学习出来的监督信号。训练损失下降只能说明拟合了当前目标，不能代替真实任务评测。下一章改为直接参数化策略，学习如何把奖励信号转成行动概率的梯度。

### 题 5：手写 DQN 核心 loss 并找广播 bug

**题目：**输入 `q_all:[B,A]`、actions、rewards、next_target_q、terminated，实现一半均方误差和 `[B]` target。核对本章题4，再用预测[1,3]和目标[0,2]重现 `[B,B]` bug；目标网络不能收到梯度。

**参考答案：**gather 后 squeeze，target=reward+gamma*(1-terminated)*max_next 并 detach，loss=$\frac1{2B}\sum(q-target)^2$。上述广播例普通 MSE 为1与3，一半 MSE为.5与1.5。只有匹配轴、终止和梯度才能验证算法。

**面试追问：**batch=1 能抓这个错误吗？

**追问回答：**形状退化时可能看不出来；用至少两个不同标签的样本检查数值和轴。

### 题 6：目标网络也可能掩盖反馈问题

**题目：**实现第 4.5 节标量反例，对比每步 detach、完整残差梯度和每十步刷新目标。记录 theta 与各阶段 loss，并说明 replay 缺失信息。

**参考答案：**半梯度倍率 $1+.8\alpha$ 增长，完整残差梯度下降倍率 $1-.64\alpha$ 在适当步长下缩小；固定目标期间 loss 可下降而刷新后标签继续放大。补充 s' 真终止转移可提供缺失约束，但共享参数的最终折中仍需重新分析。

**面试追问：**这证明半梯度永远比完整梯度差吗？

**追问回答：**它只反驳无条件稳定保证；两个目标不同，一般完整 Bellman 优化也有采样与优化困难，需具体条件和公平实验。
