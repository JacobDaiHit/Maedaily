# 第 3 章　MC、TD 与 Q-learning：从样本估计未来

动态规划需要完整环境模型，实际交互常只给一条转移。模型未知时有两个自然选择：等结果真的发生，再用完整回报学习；或者先用当前估计补上尚未观察到的未来。本章分别把它们称为 Monte Carlo（MC，蒙特卡洛）与 Temporal Difference（TD，时序差分）。

还是 `start → invest → work → finish`：MC 必须等真正完成，才知道这次总回报为 1.6；TD 在刚到 `work` 时，就可用“本步的 $-0.2$ 加上当前估计的 `work` 价值”先更新。**自举**就是用一个尚未完全验证的价值估计来构造另一个估计。[短程序的第三步](../短程序实验.md)会让旧估计 0 经一次更新变成 0.8；它不是已经学到真实值 1.6。

## 3.1 MC 与 TD 的区别在目标

对固定策略 $\pi$，用表格 $V(s)$ 估计 $V^\pi(s)$。步长 $\alpha\in(0,1]$ 控制新目标的权重。MC 在一个完整回合结束后使用实际回报 $G_t$：

$$
V(S_t)\leftarrow V(S_t)+\alpha[G_t-V(S_t)].
$$

从该状态起按 $\pi$ 采样、回合完整且回报可积时，$G_t$ 是对应条件期望的无偏样本。回合越长，环境随机性通常积累得越多；“MC 方差较大”是常见情形，不是对所有问题都成立的严格大小关系。首次访问 MC 每回合仅更新某状态的第一次出现；每次访问 MC 使用所有出现，样本之间可能相关。

TD(0) 只等一步。记真正终止指示为 $d_t\in\{0,1\}$，则 TD 误差为

$$
\delta_t=R_{t+1}+\gamma(1-d_t)V(S_{t+1})-V(S_t),\qquad
V(S_t)\leftarrow V(S_t)+\alpha\delta_t.
$$

用估计值构造另一个估计值的目标叫自举。TD 目标通常带有当前价值误差，却可以立即更新，且不必等整个任务结束。第 1 章的外部截断不是 $d_t=1$；终止才把尾部价值清零。

## 3.2 用同一条轨迹手算

观察 `start → work → terminal`，奖励为 $-0.2,2$，$\gamma=0.9$。从全零价值开始，使用 $\alpha=0.5$。MC 看到完整回报后，更新 $V(\mathrm{start})=0.8$、$V(\mathrm{work})=1$。若 TD 按时间顺序在线更新，第一步目标只有 $-0.2$，所以 $V(\mathrm{start})=-0.1$；第二步得到 $V(\mathrm{work})=1$。在后续访问中，工作状态的正价值才逐渐传回起点。

两者第一回合结果不同不说明 TD 错了，而是它用了不同目标。若 TD 在整条轨迹结束后反向更新，数值又会变化；报告实验时必须交代更新顺序。

## 3.3 从评价走向控制：SARSA 与 Q-learning

令 $Q(s,a)$ 为行动价值表。SARSA 使用实际采样到的下一个行动 $A_{t+1}$：

$$
Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma(1-d_t)Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\right].
$$

真正终止时无需采样下一行动，目标直接取 $R_{t+1}$。SARSA 评价并改进当前行为策略，称为 on-policy。Q-learning 的目标改为

$$
Y_t=R_{t+1}+\gamma(1-d_t)\max_b Q(S_{t+1},b),\qquad
Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[Y_t-Q(S_t,A_t)].
$$

这里 $b$ 遍历下一状态的可选行动。行为策略可以仍在随机探索，但学习目标采用贪心行动，所以 Q-learning 是 off-policy。off-policy 不等于 offline：前者允许训练与采样策略不同，后者强调只有固定数据、不能继续交互。

一个简单行为策略是 $\epsilon$-greedy：以概率 $\epsilon$ 均匀随机选行动，其余时候选价值最大的行动。并列最大值应随机打破或明确固定规则，避免初始化时的隐蔽偏置。

```text
Q 与每个状态行动对的访问次数 N 初始化为 0
重复采样回合：
    从起点出发，按 ε-greedy 选行动 a
    得到 (s, a, r, s', terminated, truncated)
    N[s,a] += 1；α ← N[s,a]^(-0.6)
    target ← r，若非真正终止则加 γ max_b Q[s',b]
    Q[s,a] ← Q[s,a] + α (target - Q[s,a])
    若终止或截断则重置；否则从 s' 继续
```

## 3.4 哪些收敛结论可以使用

经典表格 Q-learning 收敛定理需要有限状态与行动、有界奖励、$\gamma<1$、每个状态行动对被无限访问，以及每个状态行动对自己的步长序列满足 $\sum_n\alpha_n=\infty$、$\sum_n\alpha_n^2<\infty$。在这些随机逼近条件下，估计几乎必然收敛到 $Q^*$。这不是“只要代码叫 Q-learning 就收敛”。固定步长、不充分探索、神经网络替代表格，都不直接受该定理保护。[Watkins 与 Dayan 原论文](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf)给出了离散表示下的证明。

有限次运行只能提供数值证据。本书实验使用可解析环境、固定种子和误差阈值，检验是否接近已知答案；它不能证明任意任务的收敛。若只用贪心策略且初始估值不利，某些行动可能从不被访问。若奖励日志很好看而行动价值严重失真，还要检查终止掩码与探索覆盖。

## 3.5 与后训练的连接

语言模型的整段回答得分类似 MC 回报；PPO 中的价值头与优势估计则使用 TD 思路。训练数据只覆盖某些回答，并不代表模型能准确评价未见过的回答。把 DPO 简称为“Q-learning 的替代品”会丢失其不同的偏好目标与建模假设，需在后训练部分单独推导。

## 3.6 练习与答案提示

1. 上述轨迹第二次按时间顺序做 TD，起点更新到多少？提示：$-0.1+0.5[-0.2+0.9\times1-(-0.1)]=0.3$。
2. 若下一状态两个行动价值为 2 和 0，行为策略各选一半，SARSA 目标的条件均值与 Q-learning 目标有何区别？提示：尾部分别是 $\gamma\times1$ 与 $\gamma\times2$。
3. 为什么 $n^{-0.6}$ 满足两条步长条件，而固定 0.1 不满足？提示：分别检查 $p$ 级数；条件按每个状态行动对的访问次数计算。
