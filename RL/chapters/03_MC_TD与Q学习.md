> **第二遍选读：**终止/截断、覆盖和收敛条件；第 4–6 题。

> **运行命令：**在仓库根目录执行 `python scripts/run_lesson.py rl`；先预测再查看本次目录的 `结果说明.txt`。
>
> **完成标准：**手算一次 TD/Q 更新，并区分探索不足和更新式错误；题目先写出自己的答案，再展开参考答案。

动态规划需要完整环境模型，实际交互常只给一条转移。模型未知时有两个自然选择：等结果真的发生，再用完整回报学习；或者先用当前估计补上尚未观察到的未来。本章分别把它们称为 Monte Carlo（MC，蒙特卡洛）与 Temporal Difference（TD，时序差分）。

还是 `start → invest → work → finish`：MC 必须等真正完成，才知道这次总回报为 1.6；TD 在刚到 `work` 时，就可用“本步的 $-0.2$ 加上当前估计的 `work` 价值”先更新。**自举**就是用一个尚未完全验证的价值估计来构造另一个估计。[短程序的第三步](../短程序实验.md)会让旧估计 0 经一次更新变成 0.8；它不是已经学到真实值 1.6。

## 3.1 MC 与 TD 的区别在目标

对固定策略 $\pi$，用表格 $V(s)$ 估计 $V^\pi(s)$。步长 $\alpha\in(0,1]$ 控制新目标的权重。MC 在一个完整回合结束后使用实际回报 $G_t$：

$$
V(S_t)\leftarrow V(S_t)+\alpha[G_t-V(S_t)].
$$

从该状态起按 $\pi$ 采样、回合完整且回报可积时，$G_t$ 是对应条件期望的无偏样本。回合越长，环境随机性通常积累得越多；“MC 方差较大”是常见情形，不是对所有问题都成立的严格大小关系。首次访问 MC 每回合仅更新某状态的第一次出现；每次访问 MC 使用所有出现，样本之间可能相关。

TD(0) 只等一步。记真正终止指示为 $d_t\in\{0,1\}$，则 TD 误差为

$$
\delta_t=R_{t+1}+\gamma(1-d_t)V(S_{t+1})-V(S_t),\qquad
V(S_t)\leftarrow V(S_t)+\alpha\delta_t.
$$

用估计值构造另一个估计值的目标叫自举。TD 目标通常带有当前价值误差，却可以立即更新，且不必等整个任务结束。第 1 章的外部截断不是 $d_t=1$；终止才把尾部价值清零。

## 3.2 用同一条轨迹手算

观察 `start → work → terminal`，奖励为 $-0.2,2$，$\gamma=0.9$。从全零价值开始，使用 $\alpha=0.5$。MC 看到完整回报后，更新 $V(\mathrm{start})=0.8$、$V(\mathrm{work})=1$。若 TD 按时间顺序在线更新，第一步目标只有 $-0.2$，所以 $V(\mathrm{start})=-0.1$；第二步得到 $V(\mathrm{work})=1$。在后续访问中，工作状态的正价值才逐渐传回起点。

两者第一回合结果不同不说明 TD 错了，而是它用了不同目标。若 TD 在整条轨迹结束后反向更新，数值又会变化；报告实验时必须交代更新顺序。

## 3.3 从评价走向控制：SARSA 与 Q-learning

令 $Q(s,a)$ 为行动价值表。SARSA 使用实际采样到的下一个行动 $A_{t+1}$：

$$
Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma(1-d_t)Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\right].
$$

真正终止时无需采样下一行动，目标直接取 $R_{t+1}$。SARSA 评价并改进当前行为策略，称为 on-policy。Q-learning 的目标改为

$$
Y_t=R_{t+1}+\gamma(1-d_t)\max_b Q(S_{t+1},b),\qquad
Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[Y_t-Q(S_t,A_t)].
$$

这里 $b$ 遍历下一状态的可选行动。行为策略可以仍在随机探索，但学习目标采用贪心行动，所以 Q-learning 是 off-policy。off-policy 不等于 offline：前者允许训练与采样策略不同，后者强调只有固定数据、不能继续交互。

一个简单行为策略是 $\epsilon$-greedy：以概率 $\epsilon$ 均匀随机选行动，其余时候选价值最大的行动。并列最大值应随机打破或明确固定规则，避免初始化时的隐蔽偏置。

```text
Q 与每个状态行动对的访问次数 N 初始化为 0
重复采样回合：
    从起点出发，按 ε-greedy 选行动 a
    得到 (s, a, r, s', terminated, truncated)
    N[s,a] += 1；α ← N[s,a]^(-0.6)
    target ← r，若非真正终止则加 γ max_b Q[s',b]
    Q[s,a] ← Q[s,a] + α (target - Q[s,a])
    若终止或截断则重置；否则从 s' 继续
```

## 3.4 哪些收敛结论可以使用

经典表格 Q-learning 收敛定理需要有限状态与行动、有界奖励、$\gamma<1$、每个状态行动对被无限访问，以及每个状态行动对自己的步长序列满足 $\sum_n\alpha_n=\infty$、$\sum_n\alpha_n^2<\infty$。在这些随机逼近条件下，估计几乎必然收敛到 $Q^*$。这不是“只要代码叫 Q-learning 就收敛”。固定步长、不充分探索、神经网络替代表格，都不直接受该定理保护。[Watkins 与 Dayan 原论文](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf)给出了离散表示下的证明。

有限次运行只能提供数值证据。本书实验使用可解析环境、固定种子和误差阈值，检验是否接近已知答案；它不能证明任意任务的收敛。若只用贪心策略且初始估值不利，某些行动可能从不被访问。若奖励日志很好看而行动价值严重失真，还要检查终止掩码与探索覆盖。

## 3.5 与后训练的连接

语言模型的整段回答得分类似 MC 回报；PPO 中的价值头与优势估计则使用 TD 思路。训练数据只覆盖某些回答，并不代表模型能准确评价未见过的回答。把 DPO 简称为“Q-learning 的替代品”会丢失其不同的偏好目标与建模假设，需在后训练部分单独推导。

## 3.6 深入：n-step、重要性采样与采样覆盖

n-step 目标在非终止窗口写为 $G_t^{(n)}=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}+\gamma^nV(S_{t+n})$；遇到真正终止时截短求和并去掉 bootstrap。n=1 是 TD 目标，完整回合是 MC。不同 n 改变估计偏差、波动与奖励传播速度；相同轨迹的多个目标相关，不能当成新增独立数据。

例如奖励 $[-0.2,2]$、gamma=.9、当前 work 估值 1：起点 1-step 目标 .7，完整 2-step 目标 1.6。若中途外部截断，只观测第一步，就只能用 .7 的估计目标，不能声称已经观测 1.6。

想用行为策略 mu 的完整轨迹评价 pi，可在共同支持下乘比率 $W=\prod_t\pi(A_t|S_t)/\mu(A_t|S_t)$，普通估计 $\frac1n\sum_iW_iG_i$ 可无偏但方差大；自归一化 $\sum_iW_iG_i/\sum_iW_i$ 通常有有限样本偏差。轨迹很长时乘积极端，覆盖缺失时校正无定义，截断权重又改变偏差。Q-learning 的 off-policy 控制不能自动代替这个评价问题。

一步例子：mu 两动作等概率，pi 概率为 [.8,.2]，奖励 [1,0]；W 为 [1.6,.4]，期望 $\mathbb E_\mu[Wr]=.8$。同一份样本若恰好只有第一动作，普通估计为1.6，自归一化为1；都不等于这一批必然精确得到真值 .8。

学习曲线同时画访问次数和价值误差。epsilon 衰减太快会停止覆盖；固定 epsilon 可持续探索，但固定步长会持续波动。定理的无限访问是渐近条件，有限预算验收需要明确误差阈值、种子与已覆盖集合。

## 3.7 完整自测与面试问答

### 题 1：按时间顺序做 TD，信息怎样传回起点？

**题目：**一条确定轨迹为 `start` → `work` → 终止，奖励依次为 $-0.2,2$，折扣 0.9，步长 $\alpha=0.5$。首次沿时间顺序更新后，当前估计为 $V(start)=-0.1,V(work)=1$，终止价值为 0。再次走同一轨迹，每见一步就用当时下一状态估计做 TD：$V(s)\leftarrow V(s)+\alpha[r+\gamma V(s')-V(s)]$。求第二轮两个新值。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**先更新起点，目标为 $-0.2+0.9\times1=0.7$，新值 $-0.1+0.5[0.7-(-0.1)]=0.3$。再更新工作，终止目标为 2，新值 $1+0.5(2-1)=1.5$。起点更新时尚不能使用随后才更新的 1.5；更新次序属于题目条件。

</details>

**面试追问：**MC 与 TD 的核心区别是什么？

<details>
<summary>展开追问回答</summary>

**追问回答：**MC 用完整回合的实际回报作目标，通常要等回合结束；TD 用一步奖励和现有价值估计自举，可逐步更新。MC 不依赖尾部价值估计但可能有较大回报波动，TD 引入估计误差并更早传播信息。

</details>

### 题 2：SARSA 与 Q-learning 谁评价行为策略？

**题目：**一条非终止转移奖励为 0，$\gamma=0.9$，下一状态的两个 Q 估计为 $Q(s',a)=2,Q(s',b)=0$。行为策略在下一状态各以一半概率选 a、b。SARSA 目标为 $r+\gamma Q(s',A')$，Q-learning 目标为 $r+\gamma\max_uQ(s',u)$。求 SARSA 两种目标值、条件均值及 Q-learning 目标。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**SARSA 目标以各一半概率为 1.8 与 0，条件均值为 0.9；Q-learning 目标为 1.8。SARSA 使用实际下一动作，评价当前行为策略；Q-learning 使用贪心尾部，可用另一探索行为策略收集数据，属于 off-policy 更新。

</details>

**面试追问：**Expected SARSA 在这个例子里是多少？

<details>
<summary>展开追问回答</summary>

**追问回答：**它直接对下一动作按策略求期望，目标为 0.9，省去抽到 a 还是 b 所带来的目标波动；仍要核对采用哪份策略概率。

</details>

### 题 3：表格 Q-learning 收敛需要什么条件？

**题目：**有限状态与动作、奖励有界、$\gamma<1$，每个状态动作对均被无限访问。该状态动作对第 $n$ 次访问的步长为 $\alpha_n=n^{-0.6}$。检查 $\sum_n\alpha_n=\infty$、$\sum_n\alpha_n^2<\infty$；比较固定步长 0.1，并说明神经网络 DQN 能否直接套用这个表格结论。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**$\sum_n n^{-0.6}$ 发散，而 $\sum_n n^{-1.2}$ 收敛，满足两条随机逼近步长条件。固定 0.1 的平方和也发散，不满足第二条。步长按各状态动作对自己的访问次数定义。DQN 使用函数逼近与变化目标，不能直接继承表格 Q-learning 的收敛保证。

</details>

**面试追问：**实验跑一万次得到正确数值，是收敛证明吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**它是有限运行的数值证据。应与独立解析解比较误差、检查访问覆盖与终止处理；定理仍需要逐项验证假设。

</details>

### 题 6：Q-learning 不收敛的受控诊断

**题目：**在表格实验只改变探索覆盖、固定/递减步长、终止 mask 三项，逐项构造错误对照。提交状态动作访问、误差与贪心策略真实价值。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**不覆盖动作可能学不到最优路线；固定步长在随机任务中可能保留波动；错终止污染尾值。每次改一项并与解析 Q 对照，区分采样、随机逼近与目标错误。有限实验验证实例，不替代收敛证明。
