# 第二卷：大模型后训练——从监督信号到可靠实验

**想做完整自测或准备面试，打开 [各专题题目索引](../references/面试复习与题目索引.md)。** 题目均给出完整条件、参考答案、常见追问与回答；基础讲解、手算与实验排错按专题连接。

[总入口](../README.md) · [第一卷](../RL/README.md) · [论文索引](../references/论文索引.md)

**第一次接触后训练，从 [中文从零上手](从零上手.md) 开始。**它围绕“1+1”从参数、提示、词元讲到 SFT、DPO、RLVR，包含逐步手算、完整练习答案和 45 项数值检查的输出解读；无需先读完英文书。

读完第一次例子，就做[同一道题的四个短程序实验](短程序实验.md)：示范答案的损失、两份回答的比较、DPO 的四个对数概率、同题四份回答的组内优势。每个只打印一个核心结果；弄清输入和输出之后，再进入系统章节与 45 项完整核算。

这一卷以“数据从哪里来、loss 作用在哪些 token、哪些参数被更新、最后怎样判断变好”为主线。先读过基本 Transformer 和交叉熵即可开始；RL 推导需要时回到第一卷。

贯穿本卷的题目是“1+1 等于几”。先让模型学会按示范回答，这叫**监督微调**（SFT）；再比较两份回答哪份更好，得到**偏好数据**；若正确答案可以被程序核对，就能使用**验证器奖励**。第 1—3 章建立这三种信号，第 4—6 章说明它们怎样分别变成参数更新，第 7 章用独立题目检查是否真的进步。读到任何损失函数，先指出它使用哪种数据、给哪些 token 计分、更新哪个模型。

## 学习与实践顺序

先跑 [CPU 数值实验](experiments/README.md)，检查偏好概率、DPO、组内优势和 mask 等机制。接着参考 [本地实验路径](../references/阅读方法与证据标准.md) 选择一个小规模任务，再做真正的 SFT / DPO / RLVR。数值例子不会下载模型，也不是 LLM 训练复现。

本机 8 GB 显存下先做短程测量，确定模型、序列长度和批量；模型参数少也不保证多轨迹 RL 训练能装下。完整大模型训练结果是论文报告，不能当成本地已完成结果。
