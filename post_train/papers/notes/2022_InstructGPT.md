# InstructGPT：示范、偏好和在线优化组成一条训练链

> 省流：先用人类示范做 SFT，再用回答排序训练奖励模型，最后用 PPO 优化策略。它展示“更符合特定用户意图”不能简单用模型参数量替代，是理解经典 RLHF 系统的首选案例。

## 什么水平、值不值得读

- **发表事实**：[NeurIPS 2022 主会论文](https://proceedings.neurips.cc/paper/2022/hash/b1efde53be364a73914f58805a001731-Abstract-Conference.html)。
- **阅读判断**：后训练基础必读，强项是完整流程与人类评测；不是所有训练资产都能从公开材料复现。
- **版本**：2203.02155v1，2022-03-04；[原始页面](https://arxiv.org/abs/2203.02155v1)；[本地 PDF](../pdf/2203.02155.pdf)。本笔记对应预印本，检索日 2026-09-26。

## 做了什么，试验了什么

从 GPT-3 出发，分别准备示范数据、偏好排序、用于 PPO 采样的 prompts；这三种数据的监督信号不同。PPO-ptx 还混入预训练目标以缓解能力退化。

实验比较起始模型、SFT、PPO 等，主要评价 API prompt 分布上的标注者偏好，并检查真实性、有害输出和公开 NLP 任务。论文也研究未参与训练数据生产的标注者，但他们仍不代表所有用户。方法与数据见 PDF 第 6—9 页，评测定义见 §3.6，结果见 §4。

## 应用和结论边界

已研究的场景包括生成、改写、问答和摘要等语言任务。论文中的偏好优势不等于各项知识或推理能力全面更强，更不等于事实错误已经解决。

我的判断：学习它时最有价值的是追踪监督来源和系统边界。偏好数据代表谁、标注者是否一致、奖励模型能否泛化，都应与 PPO 公式同等重要。项目中应保留能力回归测试，不能只报告奖励上升。

**读后检查**：画出 policy、reference、reward model、value model 的前向与更新箭头；标明每一份参数是否训练。再解释为什么奖励模型准确率、用户偏好胜率和事实正确率是三个指标。参见 [RLHF 系统章](../../chapters/05_RLHF与PPO训练系统.md)。
