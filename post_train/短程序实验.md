# 后训练短程序实验：同一道题的四种反馈

固定题目“1+1 等于几？”。这里重点比较候选回答“2”和“3”，模型还可能输出其他文本；不同训练方法并不是换一个高深名字，而是使用不同的反馈。下面四个小实验先只做数值核算，不下载模型，也不更新语言模型参数。每一步先预测输出，再单独运行程序。

## 1. SFT：有人示范“2”

**监督微调**（SFT）把示范答案作为目标。若模型在题目后给正确 token “2”的概率是 0.6，负对数损失为 $-\log0.6\approx0.510826$。训练希望提高示范答案概率，所以损失随概率增加而下降。

```powershell
python -X utf8 post_train/experiments/mini_walkthrough.py sft
```

真实回答通常有多个 token，要把各 token 对数概率相加或按约定平均；题目作为输入，通常不直接算回答的监督损失。[第 1—2 章](chapters/01_语言模型到后训练.md)解释标签、mask 和数据。

## 2. 偏好：只知道“2”胜过“3”

**偏好数据**记录同一题下哪份回答更好。给“2”的模型奖励分设为 1，给“3”设为 0，Bradley–Terry 比较模型给前者胜出的概率为 $1/(1+e^{-1})\approx0.731059$。这个数字是比较模型的预测，不能直接当成“回答有 73% 概率正确”。

```powershell
python -X utf8 post_train/experiments/mini_walkthrough.py preference
```

从比较结果训练奖励模型见[第 3 章](chapters/03_偏好建模与奖励模型.md)。

## 3. DPO：直接提高好回答的相对概率

**直接偏好优化**（DPO）同时看当前策略与参考策略对好、坏回答给出的对数概率。程序中当前策略的“好减坏”为 $-0.5-(-1.5)=1.0$，参考策略为 $-0.5-(-1.0)=0.5$；差值乘系数 $\beta=0.2$ 得 0.1，DPO 损失约 0.644397。系数控制偏好差值进入损失时的尺度。

```powershell
python -X utf8 post_train/experiments/mini_walkthrough.py dpo
```

这里只做四个数的核算，完整回答的概率要把有效回答 token 的对数概率求和。推导和参考策略的作用在[第 4 章](chapters/04_DPO推导与实现.md)。

## 4. GRPO：同题采四份，彼此作参照

对同一道题采四份回答，验证器给奖励 $(1,0,0,1)$。组内平均为 0.5，按总体标准差 0.5 归一化后，相对优势是 $(1,-1,-1,1)$。**优势**表示这份回答比同组平均好多少；全对或全错的一组没有组内差异，不能仅靠相对比较提供方向。

```powershell
python -X utf8 post_train/experiments/mini_walkthrough.py group
```

这里“可验证奖励强化学习”（RLVR）描述奖励由程序核对，“GRPO”描述如何用同题多条回答构造相对反馈。二者不是同一个概念。[第 6 章](chapters/06_GRPO与RLVR.md)再讨论真实更新、零方差、长度归约和验证器错误。全部运行可用 `python -X utf8 post_train/experiments/mini_walkthrough.py all`；之后再做[完整数值核算](experiments/README.md)。

## 完整自测与面试问答

### 题 1：SFT loss 是怎样由示范概率得到的？

**题目：**给定同一提示，示范只有一个目标 token“2”，当前模型给它概率 0.6，提示不参与损失，不含 padding，使用自然对数 $L=-\ln p$。求当前损失和该概率降为 0.3 后的损失，解释变化；此题只做数值计算，不执行参数更新。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**当前损失约 0.510826，概率 0.3 时约 1.203973，增加 ln2≈0.693147。示范目标被赋予更低概率，在该样本上更差；这不是两模型真实能力的完整评测。

</details>

**面试追问：**有多个示范 token 时是否也只算最后一个？

<details>
<summary>展开追问回答</summary>

**追问回答：**应按明确的回答监督 mask 计算每个有效目标，并说明求和还是平均；最后一个 token 不能替代完整序列。

</details>

### 题 2：DPO 用的四个概率分别是什么？

**题目：**同提示下 chosen 是较好回答、rejected 是较差回答。当前策略给两回答的完整序列 log-prob 分别为 -0.5、-1.5；参考策略分别为 -0.5、-1.0，两策略还可能输出其他回答。beta=0.2，定义 $u=\beta[(\log p_+-\log p_-)-(\log q_+-\log q_-)]$、$L=\ln(1+e^{-u})$。计算两个相对差、u 和损失。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**当前差 1，参考差 0.5，u=0.1，损失约 0.644397。两候选在每个策略下的概率和均不超过 1，其余质量分给其他输出。DPO 比较相对偏好，不能从一个 margin 推出 chosen 的绝对概率一定提高。

</details>

**面试追问：**为何使用整个回答的 log-prob 求和？

<details>
<summary>展开追问回答</summary>

**追问回答：**概率链式法则给出序列概率为条件概率乘积，取对数变成和；自行除以长度会改变此序列概率比的含义，需作为另外的目标说明。

</details>

### 题 3：GRPO 与 RLVR 怎样各定义一句话？

**题目：**对同题四份回答，程序验证奖励为 [1,0,0,1]。以总体标准差 $s=\sqrt{\sum_i(r_i-\bar r)^2/4}$ 构造 $A_i=(r_i-\bar r)/s$。求均值、标准差和优势，再比较全对 [1,1,1,1] 时的处理。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**混合组均值 0.5、标准差 0.5、优势 [1,-1,-1,1]。全对组标准差为零，不能直接相除；需按协议加稳定项后得到零相对优势，或跳过该组并记录。GRPO 是组内相对反馈的优化方法；RLVR 是奖励可由规则验证的任务设置。

</details>

**面试追问：**全对组相对优势为零，说明题目毫无训练价值吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**仅说明该组的这一相对项没有区分方向；KL 项、监督目标或其他组仍可能有梯度，数据价值与单组相对信号不能混称。

</details>
