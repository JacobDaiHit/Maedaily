# 第 7 章：推理评测、蒸馏与实验设计

> 本章目标：让“模型变好了”成为可检查的实验结论，并能比较 SFT、DPO、RLVR 与蒸馏。前置：前六章；统计与数据切分可参照 [RL 第 8 章](../../RL/chapters/08_探索_离线RL与评测.md)。

前六章给出了几种让训练分数上升的办法，本章检验这些分数是否对应真正想要的能力。沿用同一批未参与训练的题目，先规定每题只答一次，或允许答多次并选择结果；两种使用方式要分开评估。**蒸馏**是用一个模型产生的输出训练另一个模型，它也必须在同一评测协议下比较，不能只看教师模型的训练分数。

若每题只回答一次，100 题答对 70 题，单次成功率是 70%。若每题可采样 5 次，问题又变成“5 次里是否至少有一次正确、系统能否识别它、总成本多少”。**pass@k**只回答前半个“至少一次”，不自动提供选择正确答案的办法。先把实际使用方式写下来，再看第 7.2 节的组合数公式。

## 7.1 先定义你要改善哪种使用方式

若用户只收一个答案，关心的是单次采样质量；若系统允许采样十次并用验证器筛选，关心的又是另一种能力。增加推理预算本身可能改善结果，因此评测协议必须包含模型检查点、提示模板、采样温度、top-p、最大生成长度、每题采样次数、终止规则与答案解析器。

greedy accuracy 是固定贪心解码下的正确率；随机采样的 pass@1 是指定随机生成分布下一次回答的成功概率。两者不应无说明地混写。温度为零也不自动保证跨设备、内核与框架的逐位可复现。

## 7.2 pass@k、投票与重排不是一回事

对每题生成 $n$ 个候选，其中 $c$ 个通过验证，常用 pass@$k$ 估计为

$$
\widehat{\mathrm{pass@}k}=1-\frac{\binom{n-c}{k}}{\binom nk},\qquad 1\le k\le n.
$$

它计算从这 $n$ 个候选中随机选 $k$ 个、至少一个通过的比例。在独立同分布采样条件下，可用于估计给定采样分布的 $k$ 次成功概率；跨题再平均。若 $n-c<k$，分子取零。不要用总正确候选数先汇总跨题再代入，因为题目成功率不同。[HumanEval/Codex 原始评测论文](https://arxiv.org/html/2107.03374v1)

例如 $n=5,c=2,k=2$，估计为 $1-\binom32/\binom52=0.7$。pass@2 不表示系统知道两个候选中哪一个对；它使用验证结果检查是否“存在成功答案”。多数投票按出现频率选答案，可能多数都错；best-of-$N$ 按评分器选择，也会受评分器错误影响。报告时写清最终选择规则。

## 7.3 从误差条到配对比较

每题一次二元结果的平均值 $\hat p$ 可用 $\sqrt{\hat p(1-\hat p)/N}$ 粗略理解标准误，但小样本或接近 0/1 时应使用更合适区间。对同一测试题比较两个模型，保留逐题结果做配对分析；仅比较两个汇总百分比会丢失相关性。

bootstrap（自助重采样）可按题目重采样，估计正确率差的区间。若同题有多个采样，通常应把它们作为同一题的簇保留；不能把高度相关的回答全部当独立题目。多个训练种子衡量训练随机性，多个生成种子衡量采样随机性，这两种不确定性不同。

测试集不能反复指导超参数选择。预先分开 train/validation/test，记录去重与题目族切分规则；公开题库还可能进入模型预训练，因此应补充新题、变体与不同难度分布，并准确称为“迁移证据”而非保证无污染。

## 7.4 蒸馏到底转移了什么

知识蒸馏可以用教师分布监督学生分布。给定同一前缀 $s$，一种 soft-target 形式最小化

$$
\mathcal L_{KD}=\mathbb E_s D_{KL}\big(p_{teacher}(\cdot\mid s)\|p_{student}(\cdot\mid s)\big).
$$

若只拿到教师生成的文本，则通常用这些序列做 SFT，而非实际匹配完整 logits。后者是序列级示范学习，可结合答案验证和筛选。二者数据接口、成本与信息量不同。[经典蒸馏论文](https://arxiv.org/abs/1503.02531)

R1 初版报告中的蒸馏路线用整理的数据微调较小的 Qwen/Llama 系列模型；不能把这些模型直接称为“在小模型上复现同等规模 RL”。教师能力、生成分布、筛选规则与学生容量共同影响效果。[R1 初版第 2.4 节](https://arxiv.org/html/2501.12948v1)

训练集答案正确但推理存在错误时，学生仍可能模仿错误路径。可以比较“只最终答案”“完整推理”“筛选后的完整推理”，但要披露训练 token 数、题目数和教师生成成本；否则长推理组多见到的 token 本身就是混杂因素。

## 7.5 一份能回答问题的小实验

建议围绕同一任务、同一 SFT 检查点建立四条分支：不继续训练、继续 SFT、DPO、RLVR。先写一个具体问题，例如“相同测试生成预算下，RLVR 是否提高未见题的单次正确率”。然后冻结数据划分与评测脚本，明确训练预算和停止条件。

| 要记录的量 | 为何需要 |
| --- | --- |
| 模型/数据/代码版本与配置 | 能重建一次运行 |
| 题目数、更新 token、rollout token、耗时 | 区分数据、优化与采样成本 |
| 正确率、格式有效率、输出长度、截断率 | 避免只看训练奖励 |
| 每题结果、失败样例、独立重复 | 分析不确定性和失败类型 |
| KL、clip、组内零方差比例等适用诊断 | 解释优化过程；不替代测试质量 |

首次资源有限时，可先比较两条分支，并报告实际重复次数；不要在只有一个种子的结果上写“稳定提升”。每次只改变奖励、组大小或长度归约中的一个因素。若没提升，先用数值实验确认目标与 mask，再检查采样是否有成功轨迹、奖励是否可信、训练分布是否覆盖测试。

## 7.6 怎样读“最新研究”

按争论找论文，比追逐榜单更有用：RL 是提高已有成功轨迹的概率，还是扩大在固定预算下可找到解法的范围？长度增长来自有效搜索还是目标归约偏差？收益能否迁移到不同模板与难度？这些问题需要基座强采样、预算匹配、过程分析等多种证据。

Dr. GRPO 提醒我们检查基座行为与目标归约；DAPO 展示采样及工程细节对训练的重要性。它们是研究脉络中的锚点，不等同于截至阅读当天的全部最新成果；继续阅读 [后训练总入口](../README.md) 中带版本与证据边界的论文卡。[Dr. GRPO](https://arxiv.org/html/2503.20783v1)、[DAPO](https://arxiv.org/html/2503.14476v1)

## 7.7 深入：估计量、配对证据与蒸馏梯度

### pass@k 的组合式从哪里来

给定一题 n 个已生成候选，其中 c 个正确。所有不放回 k 子集共有 $\binom nk$ 个；全错子集有 $\binom{n-c}k$ 个，相减得原式。在独立同分布候选假设下，每个 k 子集至少一次成功的指标期望都是 $1-(1-p)^k$，对子集平均的期望仍是这个量。因此该估计使用观测 c 而不需要先估 p 再代入非线性函数。

n=5,c=2,k=2 时组合估计为 0.7，而把 $\hat p=2/5$ 代入 $1-(1-\hat p)^2$ 得 0.64。二者回答不同统计计算；有限 n 时不能随意替换。稳定实现可计算全错概率 $\prod_{j=0}^{k-1}(n-c-j)/(n-j)$，避免大阶乘；若 n-c<k 直接返回 1。选取候选存在相关性或不同解码分布时，需要重新界定估计目标。

### 相同题目上的进退应成对分析

设旧/新模型在同一 N 题二元评测，b 题旧错新对，c 题旧对新错，则正确率差是 $(b-c)/N$。一致题不影响差异。零假设下若每个不一致题的改善/退化等概率，条件于 m=b+c，可用二项分布对不一致方向做精确 McNemar 检查；独立题、固定测试和预先定义比较是重要条件。

N=100,b=12,c=4 时提高 8 个百分点，但 m=16，双侧精确概率为 $2\sum_{j=12}^{16}\binom{16}j2^{-16}\approx0.076813$，并没有在常用 0.05 阈值提供足够证据。阈值不是效果有无的魔法边界，还应报告差值、区间、样本与成本；也不能把“未显著”说成两模型完全相同。

多题变体属于同一题族时，按题族重采样；同题候选属于同一簇。训练种子、题目抽样与生成随机性分别报告。反复挑检查点、指标和题目会增加选择偏差，测试只在最终方案冻结后评一次；探索性发现需要新证据确认。

### soft-target 蒸馏为何常出现温度平方

在同一词表与前缀，教师 $p^T=\operatorname{softmax}(z_T/\tau)$，学生 $p^S=\operatorname{softmax}(z_S/\tau)$。教学 loss 为 $\tau^2 KL(p^T\|p^S)$，教师 detach，故学生 logits 梯度为 $\tau(p^S-p^T)$。不乘 $\tau^2$ 时是 $(p^S-p^T)/\tau$；高温时概率差通常也缩小，缩放用于调节梯度大小，但不保证所有温度产生同一最优训练行为。

tau=1、教师 $(0.8,0.2)$、学生 $(0.5,0.5)$ 时 KL≈0.192745，学生梯度 $(-0.3,0.3)$。soft-target CE 为 $\ln2$，多出的教师熵不依赖学生，所以同前缀、同分布下梯度相同。只拿教师生成的一条文本是对教师分布的一次抽样；理想无限抽样且同前缀可对应期望 CE，实际序列选择、验证筛选和长度会改变前缀与标签分布。不同 tokenizer 的完整 logits 不能逐编号直接做 KL，需要对齐定义。

### 用预算回答明确研究问题

分别报告训练获取数据成本、更新成本与测试生成成本。若 RL 用更多候选、蒸馏用教师生成、SFT 只用已有文本，单看 optimizer steps 无法公平比较。对固定资源可以报告质量—成本曲线与失败桶；至少给一个不训练但增加采样预算的基座对照，区分训练更新和搜索预算的收益。

## 7.8 完整自测与面试问答

### 题 1：pass@1 相同，pass@8 能不同吗？

**题目：**仅作教学，测试集有两个等权题型，各候选独立采样。模型 A 在两型上单次成功概率均为 0.5；模型 B 分别为 0.9 与 0.1。pass@1 为单次平均成功率，pass@8 为八次中至少一次成功，单题为 $1-(1-p)^8$。求两模型的指标，解释差异与部署选择问题。

**参考答案：**两者 pass@1 均为 0.5。A 的 pass@8 为 $1-0.5^8\approx0.996094$；B 为 $1-[0.1^8+0.9^8]/2\approx0.784766$。平均单次成功相同，逐题难度分布不同，重复采样收益不同。至少有一个成功候选仍不提供选中它的机制。实际候选不独立时应按实际协议测量。

**面试追问：**只有生成的文本，能做与完整 logits 相同的蒸馏吗？

**追问回答：**完整分布蒸馏需要教师对候选 token 的概率或 logits；只有文本时通常把教师序列当 SFT 示范。二者信息量、接口和成本不同。

### 题 2：奖励上涨、回答变长、正确率不变，有哪些可检验解释？

**题目：**同一测试协议下，训练平均奖励从 0.7 升到 0.9，回答平均长度从 100 增到 200 token，独立测试正确率仍为 70%。请提出三个不同解释，为每个指定一个检查，并说明这些汇总结果能否直接证明更长推理无用。

**参考答案：**解释一：奖励偏好长度，做长度匹配回答对并查 RM 分数；解释二：优化只改善格式或文风，将正确率、格式和偏好分开评测；解释三：训练过拟合或测试难度不同，按未见题型和难度保留逐题结果。均值可能掩盖一些题改善、另一些题退化，应配对查看，不能只由均值判断每段长推理的作用。

**面试追问：**为什么分析要保留生成 token 与时间？

**追问回答：**质量相同而成本翻倍会改变实际用途；公平比较要匹配或披露生成预算，区分模型更新收益与更多推理计算收益。

### 题 3：怎样写可执行的单因素实验方案？

**题目：**研究问题为“同一 SFT 初始模型和偏好数据下，把 DPO 的 beta 从 0.1 改成 0.2，是否提高未见题的偏好胜率”。请写出数据划分、基线、唯一变量、预算、主要和辅助指标、选择与停止规则；此题要求方案，不要求事先猜测赢家。

**参考答案：**按题目族划分并冻结训练/验证/测试；两组从同一 SFT 权重开始，仅改 beta；固定训练 token、优化器与采样协议，预先给定种子。主要指标为保留集偏好胜率，辅助记录正确率、长度、KL 与成本。只用验证集选检查点，按固定步数或已定规则停止，冻结后报告测试逐题结果与不确定性。

**面试追问：**看完结果再换主指标有什么问题？

**追问回答：**容易只选支持结论的指标，放大偶然差异。新增分析可以做，但应标明事后探索，并用独立验证继续检查。

### 题 4：手写稳定的 pass@k

**题目：**实现 `pass_at_k(n,c,k)`，要求 $0\le c\le n,1\le k\le n$，用乘积而非阶乘；核对 (5,2,2)、c=0、c=n、n-c<k，并解释为什么不能先汇总跨题正确数。

**参考答案：**返回值依次按组合式核对，首例 0.7、全错 0、全对 1、错误候选不足 k 时为 1。每题概率不同，非线性变换前汇总会改变目标，需先逐题估计再按约定加权平均。

**面试追问：**候选全由同一次 beam search 生成，还能宣称 i.i.d. 无偏吗？

**追问回答：**不能；搜索候选相关且分布不同。组合子集存在率仍可计算，但它不自动估计独立随机采样的 pass@k。

### 题 5：八个百分点提升是否证据充足

**题目：**使用 N=100、b=12、c=4，求配对差值与双侧精确检查概率；设计按题族 bootstrap 的区间，说明如何处理未显著结果。

**参考答案：**差值 0.08，条件二项概率≈0.076813；重采样单位是完整题族，保留新旧模型逐题对应。报告点估计、区间、测试规模和成本，称证据不足而非确认无差别。新增数据与重复实验须按预先约定实施。

**面试追问：**把同题 20 个候选视为 20 个新题会怎样？

**追问回答：**忽略相关性往往夸大有效样本量，使区间过窄；需按题簇处理。

### 题 6：手推蒸馏 loss 和梯度

**题目：**教师概率 (0.8,0.2)、学生 (0.5,0.5)、tau=1，算 KL、soft-target CE 与学生 logits 梯度；用 float64 核对。再说明只有文本时怎样定义实际蒸馏实验。

**参考答案：**KL≈0.192745，CE=$\ln2$，学生梯度 $(-0.3,0.3)$；两 loss 差教师熵，梯度相同。文本路线做明确筛选和模板的序列 SFT，记录教师、生成/筛选 token、题目和成本，并比较只答案/完整推理的受控分支。

**面试追问：**教师最终答案正确就能保证每一步推理正确吗？

**追问回答：**不能；需过程审查或可靠步骤验证，最终验证只能支持它实际检查的属性。
