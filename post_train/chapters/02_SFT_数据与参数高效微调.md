>
> **完成标准：**手核实际 batch 的 token/label/mask，检查梯度、参数变化和重载一致性；题目先写出自己的答案，再展开参考答案。

> 本章目标：能解释一条指令样本如何产生梯度，以及 LoRA/QLoRA 究竟节省什么。前置：[第 1 章](01_语言模型到后训练.md)。

上一章把“1+1 等于几？”拆成提示和回答。本章先只给模型一条示范：“问题：1+1 等于几？回答：2。”模型读题、逐 token 预测示范回答，预测错了就调整参数。这叫**监督微调**（SFT）。先确认示范和计算损失的位置无误，再讨论 LoRA 如何减少待更新的参数。

如果回答只有 token“2”，模型起初给它 0.6 的概率，[短程序](../短程序实验.md)算出负对数损失约 0.511；若训练后提高到 0.8，损失变为约 0.223。**教师强制**指训练时每一步用示范的真实前缀继续预测；它与部署时模型读取自己刚生成的文字不同。先理解这两个数字和前缀来源，再看多 token 与低秩参数更新。

## 2.1 示范数据是一份行为契约

监督微调 SFT（supervised fine-tuning）要求模型模仿给定示范。若数据里充满长解释，模型会受到输出长解释的训练信号；若拒答占比过高，它也可能学会回避本可回答的问题。因而数据质量不能只用“答案看起来不错”描述，还要明确任务分布、正确性、格式、难度和覆盖范围。

对数学题至少保留题目、最终答案、解答文本、来源、题目族标识和检查状态。按题目族切分，再构造训练变体，避免同一道题换数字或换说法后跨训练与测试。对合成数据记录生成模型与筛选规则：教师生成的长推理不天然正确，最终答案正确也不能保证每一步推理正确。

先抽查数据，再训练。一个实用的小批次审计是：随机查看 20 条原文与渲染后的 chat template，统计空回答、重复题、超长样本、截断比例和有效监督 token。模板中的 role token、结束符、工具消息边界都是输入协议的一部分。[TRL 的监督范围与模板说明](https://huggingface.co/docs/trl/sft_trainer)

## 2.2 SFT 优化什么，如何归约

给定示范 $(x,y)$，目标是提高 $\pi_\theta(y\mid x)$。梯度在教师强制（teacher forcing）条件下计算：预测第 $t$ 个 token 时，前缀来自示范。推理时前缀来自模型自己，所以一次早期错误可能把它带到训练少见的状态。

有效目标仍是 `[B,L-1]`，回答区间 mask 与之对齐。多轮对话可以监督全部 assistant 轮次，也可以只监督最后一轮；这是任务选择，不能默认二者等价。packing 把多条样本装进长序列以减少 padding，但必须明确是否允许跨样本注意力；若要求样本独立，要使用正确的分段 attention 与位置处理。简单拼接不自动提供隔离。

固定 batch size 比较不同数据处理方式可能失真：短样本比例变了，有效 token 数也变了。记录每步有效 token 数、梯度累积步数与总训练 token，比只记录“训练三轮”更容易比较。

## 2.3 LoRA：把更新限制在低秩形式

考虑线性层 $h=Wx$，$W\in\mathbb R^{d_{out}\times d_{in}}$。LoRA 冻结预训练权重 $W_0$，将可学习增量写为

$$
W=W_0+\frac{\alpha}{r}BA,\quad
A\in\mathbb R^{r\times d_{in}},\quad
B\in\mathbb R^{d_{out}\times r}.
$$

$r$ 是秩参数，$\alpha/r$ 是常用缩放。可训练参数从 $d_{out}d_{in}$ 变为 $r(d_{in}+d_{out})$。例如 $d_{in}=d_{out}=1024,r=8$，增量有 16,384 个参数，而完整矩阵有 1,048,576 个。此例只统计这个线性层，不代表整模型的缩减比例。[LoRA 原始论文](https://arxiv.org/html/2106.09685v2)

常见初始化令 $B=0$、$A$ 随机，从而初始增量为零。第一步中 $A$ 的梯度为零而 $B$ 可有梯度；若两者都初始化为零，则双方梯度都为零，适配器无法启动。这可以直接从矩阵乘法的链式法则看出。

低秩不是“原模型只有低秩能力”的结论，而是对任务更新空间的限制。应记录作用于哪些层、秩、缩放、dropout 和是否训练 bias。只改 attention 投影与同时改 MLP 投影，表达能力和显存开销不同。

## 2.4 QLoRA：存储精度与计算精度分开

QLoRA 将冻结的基座权重以低位形式存储，计算时按实现反量化到合适精度，并把梯度传播到 LoRA 参数。它不是直接对整数权重执行普通梯度下降，也不是所有张量都只有 4 bit。原方法还研究 NF4、双重量化与分页优化器。[QLoRA 原始论文](https://arxiv.org/html/2305.14314v1)

显存可粗略拆为：冻结权重、可训练参数及梯度、优化器状态、激活、临时缓冲与生成缓存。LoRA 主要缩小可训练状态，量化缩小冻结权重，梯度检查点通过重算降低激活内存。三者解决不同项，不能把“权重装得下”当成“训练装得下”。

在本机资源边界内，应先选小模型、短上下文和小 micro-batch，测完峰值显存再扩大。梯度累积可扩大有效 batch，但不会减少单条超长序列的激活峰值；CPU offload 会改变速度与内存瓶颈。本文不承诺某个 7B 配置在 8 GB 上可用。

## 2.5 一条可检查的实现路线

流程为：冻结数据划分 → 固定 tokenizer 和模板 → 检查 labels → 插入适配器并列出可训练参数 → 单批次前向与反向 → 小样本过拟合 → 短训练 → 固定评测 → 保存并重载。保存适配器时同时记录基座标识与版本；只保存适配器文件不足以重建模型。

若训练 loss 下降而质量退化，检查截断是否丢失最终答案、重复模板是否支配梯度、学习率是否过大，以及任务外能力是否遗忘。用“起始模型、SFT、小数据高质量 SFT”这样的对照，通常比一次增加数据量、秩和训练步数更能解释结果。

## 2.6 深入：低秩约束怎样进入梯度和实验

### 从矩阵微分到一次实际更新

设 $G=\partial L/\partial W$、$c=\alpha/r$。从 $dW=c(dB\,A+B\,dA)$ 与 $dL=\operatorname{tr}(G^\top dW)$ 得到 $\nabla_A L=cB^\top G,\nabla_B L=cGA^\top$。矩阵形状分别为 `[r,din]` 与 `[dout,r]`。冻结 $W_0$ 只排除其参数更新，通常仍需通过该层对输入 x 反向；把整个前向放入 `no_grad` 会切断前面适配器的训练路径。

完整算例：$W_0=I_2,A=[1,2],B=[0,0]^\top,c=1,x=[1,-1]^\top$，目标为零，$L=\|Wx\|^2/2$。初始输出 $[1,-1]^\top,L=1$；$G=(Wx)x^\top=\left[\begin{smallmatrix}1&-1\\-1&1\end{smallmatrix}\right]$，$\nabla_A=0,\nabla_B=[-1,1]^\top$。SGD 学习率 0.1 后 $B=[0.1,-0.1]^\top$，有效矩阵为 $\left[\begin{smallmatrix}1.1&0.2\\-0.1&0.8\end{smallmatrix}\right]$，输出 $[0.9,-0.9]^\top,L=0.81$。两矩阵的梯度在更新前同一状态计算，不能先更新 B 再计算 A 冒充普通一次 SGD。

### 秩与参数化都约束学习

$\operatorname{rank}(BA)\le r$，不意味着每个最终网络输出只有 r 维；多个层、残差与非线性组合形成更复杂映射。对任意可逆 $Q\in\mathbb R^{r\times r}$，$BA=(BQ^{-1})(QA)$，故因子并不唯一。优化器的逐坐标状态、因子尺度和初始化会改变实际学习动力学，不能只比较最终增量秩。

增大 r 同时改变可训练参数、$\alpha/r$ 缩放和优化条件。若想研究“容量增加是否有用”，至少明确是否保持 alpha、c 或另一初始化尺度，固定目标层和训练 token；报告梯度/更新范数与资源。一个没有控制缩放的秩对照会混入步长变化。

### SFT 的诊断应落到目标 token

按提示、正文、最终答案与 EOS 拆解 loss 和有效数。截断后剩下的可能只有解释，漏掉真正答案；仅平均 loss 仍会下降。多轮监督需逐轮标记；样本边界处理需检查 attention。用十条可靠示范过拟合验证链路，再恢复独立验证；单样本过拟合只证明这条链路可拟合，不证明泛化。

## 2.7 完整自测与面试问答

### 题 1：LoRA 为什么常把一边随机初始化、另一边置零？

**题目：**冻结 $W_0\in\mathbb R^{d_{out}\times d_{in}}$，有效权重为 $W=W_0+cBA$，$A\in\mathbb R^{r\times d_{in}}$、$B\in\mathbb R^{d_{out}\times r}$，$c=\alpha/r>0$ 是固定缩放。令 $G=\partial L/\partial W$。推导 $\partial L/\partial A$、$\partial L/\partial B$，判断 A 随机而 B 为零，以及两者都为零时首步梯度。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**由 $dW=c(dB\,A+B\,dA)$ 得 $\partial L/\partial A=cB^\top G$、$\partial L/\partial B=cGA^\top$。A 随机、B 为零时，初始增量为零，A 首步梯度为零，B 的梯度可非零，随后可带动两者学习。两者都为零时两边梯度均为零，纯粹由该损失驱动的适配器无法启动。

</details>

**面试追问：**LoRA 参数量如何计算？

<details>
<summary>展开追问回答</summary>

**追问回答：**不含偏置时为 $r(d_{in}+d_{out})$。若两端维度都是 1024、r=8，则为 16,384，完整矩阵为 1,048,576；这只是该层的比较，不是整模型显存比例。

</details>

### 题 2：重复数据与新增数据有什么区别？

**题目：**比较两份 SFT 数据：A 将同一条 100-token 的示范复制十次；B 使用十条互不重复、各 100-token 的示范。均训练一遍，监督 token 总量均为 1000，模型与更新方案相同。请说明是否提供相同的新信息，以及怎样设计验证来判断差异。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**两者处理 token 数相同，信息覆盖不同。A 强化同一示范及模板，B 覆盖更多输入和答案，但质量或难度也可能不同。用独立题目族验证，记录独特题目数、重复率、训练与测试表现；控制质量后再判断收益，不能仅凭唯一数量宣布 B 一定更好。

</details>

**面试追问：**数据去重应该只对字符串去重吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**还要关注近似改写、同题不同答案与模板重复；划分时按题目或任务族，避免同题信息泄漏到验证测试。

</details>

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**需固定基座权重版本、模型配置、tokenizer、模板、适配层名、秩与缩放、dtype、适配器启用和是否合并的状态。对固定 token 输入，在 eval 模式下比较保存前后 logits 的最大绝对差与生成设置。续训还需优化器、调度、随机数和数据位置等状态。

</details>

**面试追问：**LoRA 合并后推理能完全不变吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**在精确算术且同一权重布局下，使用 $W_0+cBA$ 与对应分支表达同一线性映射；有限精度、量化和加载配置可能引入差异，需要数值核对。

</details>

### 题 4：LoRA、QLoRA 和梯度检查点分别省什么显存？

**题目：**面试官让你比较全量微调、LoRA、QLoRA 与激活重计算，也叫梯度检查点。请说明可训练权重、冻结权重存储与激活各发生什么变化，解释为什么“4 bit 权重能装下”不能保证训练装得下。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**全量微调要为大部分权重保存梯度与优化器状态；LoRA 只训练增量，主要减少可训练状态；QLoRA 进一步压缩冻结基座存储，计算时按实现反量化，梯度仍传到适配器；激活重计算用重复前向换取较少激活保存。激活、临时缓冲和生成缓存仍可能占据显存。

</details>

**面试追问：**梯度累积能解决一条超长序列的显存峰值吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**它通过多个小批次组成更大有效批量，但单条序列仍必须完成前向和反向，其激活峰值不会因累计次数增加而自动消失。

</details>

### 题 5：手写 LoRA 首步与合并验收

**题目：**按第 2.6 节数据实现 `forward(x)=W0@x+c*B@(A@x)`，手算与 autograd 核对 A/B 梯度、一次 SGD 后输出，再与合并矩阵比较。W0 必须不更新。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**初始 loss 1，A 梯度零，B 梯度 $[-1,1]^\top$；一次同步 SGD 后 loss 0.81。分支与合并的线性输出在 float64 容差内一致，W0 前后完全一致。通过这项只验证单层实现；量化模型的合并误差另测。

</details>

**面试追问：**为什么第二步 A 的梯度可能非零？

<details>
<summary>展开追问回答</summary>

**追问回答：**第一步 B 已非零，$cB^\top G$ 不再被零因子挡住；两者都零的初始化则缺乏启动梯度。

</details>

**题目：**比较 r=4 与 r=16 的 LoRA，预算按有效监督 token 固定。给出目标层、缩放、初始化、训练/评测和资源记录，解释“r 更大训练 loss 更低”能支持什么。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**固定基座/模板/切分/目标层，预先约定 alpha 与 c 的控制策略，检查起始输出及适配器更新范数；记录训练外正确率、长度、可训练参数、峰值与耗时。较低训练 loss 支持更好拟合该数据，独立质量和预算才能支持实际收益。缩放或学习率变化要披露。

</details>

**面试追问：**两个 rank 的 dropout 都固定种子就完全公平吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**不同形状会消耗不同随机流；应使用明确初始化与数据协议、多种子或适当配对，而不是把一个相同 seed 当全部随机性相同的保证。

</details>
