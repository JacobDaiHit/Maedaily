# 第 4 章：DPO 推导与实现

> 本章目标：理解为何能直接用偏好对更新模型，并能检查四个序列对数概率。前置：[BT 奖励模型](03_偏好建模与奖励模型.md)；KL 散度和约束优化可在推导处按需回顾。

上一章把“回答 2 比回答 3 好”变成训练一个打分器的问题。这一章换一条路：直接让模型提高被偏好回答的相对概率，同时用**参考策略**（通常是训练前保存的模型）限制偏离。DPO 是直接偏好优化；下面的配分函数 $Z(x)$ 只是把某个提示下所有回答的权重归一化的常数。先看它为什么会在两个回答的差中消去，再检查公式条件。

先看[短程序的四个对数概率](../短程序实验.md)：当前模型对好、坏回答分别给 $-0.5,-1.5$，参考模型给 $-0.5,-1.0$。当前“好减坏”是 1.0，参考是 0.5；两者再相减得到 0.5。DPO 后面的公式，就是把这种**相对偏好改善**写成可优化的损失。先确认四个数各属于哪个模型、哪份回答，再读推导。

## 4.1 问题从哪里来

已有偏好对时，一条路线是先拟合奖励模型，再通过在线 RL 提高奖励。DPO（Direct Preference Optimization）利用奖励与最优策略之间的解析关系，直接用偏好分类损失更新策略。它省去单独的显式奖励模型和标准离线训练中的在线 rollout，但仍需要偏好数据、参考策略与独立质量评测。[原始论文](https://arxiv.org/html/2305.18290v3)

下面推导的是理想分布空间中的关系，不是“有限神经网络、有限数据、任意优化都能找到全局最优”的保证。

## 4.2 先求 KL 正则化奖励最大化

固定提示 $x$，把所有允许回答记为集合 $\mathcal Y_x$。假设 $\beta>0$、参考分布 $\pi_{ref}$ 在候选支持集上为正，并先假设奖励在该集合上有界，保证相关奖励期望有限、配分函数有限且为正。对无界奖励的推广还需额外可积性条件，不能只靠每个奖励值分别有限。考虑

$$
\max_\pi \sum_y\pi(y\mid x)r(x,y)
-\beta\sum_y\pi(y\mid x)\log\frac{\pi(y\mid x)}{\pi_{ref}(y\mid x)},
\quad\sum_y\pi(y\mid x)=1.
$$

对约束引入乘子 $\lambda$。在内部点，对 $\pi(y\mid x)$ 求导等于零：

$$
r(x,y)-\beta\left(\log\frac{\pi(y\mid x)}{\pi_{ref}(y\mid x)}+1\right)+\lambda=0.
$$

归一化后得到

$$
\pi^*(y\mid x)=\frac{\pi_{ref}(y\mid x)e^{r(x,y)/\beta}}{Z(x)},
\qquad Z(x)=\sum_y\pi_{ref}(y\mid x)e^{r(x,y)/\beta}.
$$

还可将目标改写为 $\beta\log Z(x)-\beta D_{KL}(\pi\|\pi^*)$，直接看出最优性。若参考对某答案概率为零，有限 KL 的策略不能给它正质量；若无限序列没有恰当终止或 $Z$ 发散，上述形式也不能直接套用。教学中可先限定最大长度，得到有限集合。

反解奖励：

$$
r(x,y)=\beta\log\frac{\pi^*(y\mid x)}{\pi_{ref}(y\mid x)}+\beta\log Z(x).
$$

## 4.3 为什么不用算配分函数

BT 模型只使用同一提示下的奖励差 $r(x,y_w)-r(x,y_l)$。两项中的 $\beta\log Z(x)$ 完全相同，所以消去。若把不同提示的回答胡乱配成一对，这个消去就不成立。

用参数策略 $\pi_\theta$ 表示上述最优策略的候选。记序列对数概率为 $\ell_\theta(x,y)=\log\pi_\theta(y\mid x)$，参考策略对应 $\ell_{ref}(x,y)=\log\pi_{ref}(y\mid x)$；$D$ 是偏好对数据分布，$\sigma(z)=1/(1+e^{-z})$。定义

$$
\Delta_\theta=
\big[\ell_\theta(x,y_w)-\ell_{ref}(x,y_w)\big]
-\big[\ell_\theta(x,y_l)-\ell_{ref}(x,y_l)\big],
\qquad
\mathcal L_{DPO}=-\mathbb E_D\log\sigma(\beta\Delta_\theta).
$$

隐式奖励为 $\hat r_\theta=\beta\log(\pi_\theta/\pi_{ref})$，只在偏好模型及相应等价类下解释。它不是一个无需验证的通用正确性评分器。神经网络能表示哪些分布、离线数据覆盖哪些回答、偏好是否符合 BT，都会影响实际结果。[推导与假设来源](https://arxiv.org/html/2305.18290v3#A1)

对单样本有

$$
\nabla_\theta\mathcal L
=-\beta\sigma(-\beta\Delta_\theta)
\left[\nabla_\theta\ell_\theta(x,y_w)-\nabla_\theta\ell_\theta(x,y_l)\right].
$$

这鼓励提高 chosen 相对 rejected 的 log-ratio。由于参数共享与其他候选的归一化耦合，不能据此保证每次更新后 chosen 的绝对概率都上升。

## 4.4 四个数如何从张量得到

每对数据需要 $\ell_{\theta,w},\ell_{\theta,l},\ell_{ref,w},\ell_{ref,l}$，各为 `[B]`。chosen 与 rejected 拼为 `[2B,L]`，取已移位、回答区间有效的 token log-prob，沿长度**求和**。参考模型冻结并关闭梯度，模板、tokenization、截断与 EOS 规则应与策略一致。参考 log-prob 可缓存，但任何影响 token 序列或参考权重的改动都会使缓存失效。

举例：四个 log-prob 依次为 $-4,-6,-5,-5.5$，则 $\Delta=(1)-(-0.5)=1.5$。取 $\beta=0.2$，偏好 logit 为 $0.3$，损失约为 $0.554355$。策略等于参考时 $\Delta=0$，损失为 $\log2$；这是很有用的初始化检查，但不是“梯度为零”的条件。

流程是：检查偏好对 → 固定参考 → 计算四个 log-prob → `softplus(-beta*delta)` → 批次平均 → 反向与更新。标准 DPO 没有 PPO 中每轮刷新的 old policy；不要把 reference 误换成上一小批次策略。

## 4.5 超参数与失效边界

在原始奖励最大化问题中，较大 $\beta$ 表示更强的 KL 代价；但在固定离线偏好数据的训练中，$\beta$ 同时改变分类 logit 与梯度尺度，最终 KL 不必随它简单单调变化。应实际测量任务质量、长度、偏好准确率和与参考的偏移，而不是只看训练 loss。

截断会改变被比较的回答，长度平均会改变目标，chosen/rejected 颠倒会反向训练。偏好标签若主要反映文风，DPO 改善文风并不说明解题正确率改善。离线偏好覆盖不足时，训练外生成也可能退化。合理的首个消融是在同一 SFT 检查点与相同偏好集上改变一个 $\beta$，使用同一测试协议比较。

训练中的“隐式奖励准确率”通常只是检查 $\Delta_\theta>0$ 的比例：它回答模型是否把参考校正后的相对概率排对，而不是生成回答是否真的正确。还应单独记录 chosen/rejected 的 log-prob、margin 和长度，观察是否发生“双方概率都下降，但 rejected 下降更快”。评测时重新生成回答，调用独立任务验证器；训练偏好集上的排序改善只证明拟合了已观察标签。

## 4.6 深入：核心函数、共享前缀与梯度验收

下面函数输入四个已经求和的 `[B]` 序列 log-prob；回答的 token 计算沿用 [语言模型的核心函数](../../transformer/chapters/02_DecoderOnly与语言模型训练.md)。参考量必须停止梯度，beta 为正，batch 非空。它是教学核心函数，不包含模型、数据加载和优化器。

```python
import torch

def dpo_pair_loss(policy_w, policy_l, reference_w, reference_l, beta):
    arrays = (policy_w, policy_l, reference_w, reference_l)
    if beta <= 0 or policy_w.ndim != 1 or policy_w.numel() == 0:
        raise ValueError("beta 为正，log-prob 为非空一维批次")
    if any(a.shape != policy_w.shape for a in arrays):
        raise ValueError("四个 log-prob 的样本轴必须一致")
    delta = (policy_w - policy_l
             - reference_w.detach() + reference_l.detach())
    return torch.nn.functional.softplus(-beta * delta).mean(), delta
```

单对梯度为 $\partial L/\partial\ell_w=-\beta\sigma(-\beta\Delta)$、$\partial L/\partial\ell_l=+\beta\sigma(-\beta\Delta)$；批平均再除以 B。策略等于参考时 delta=0，loss=$\ln2$，两导数为 $-\beta/2,+\beta/2$，所以初始化 loss 正常并不表示无需更新。beta=0.2、delta=1.5 时导数约为 $\mp0.0851115$。

共享回答前缀在同一模型的 chosen/rejected log-prob 差中逐项抵消，因为这些位置的条件前缀完全相同；不同后缀的概率由各自历史计算。只删除共同**字符**而不重新核对 tokenization 和模板，可能破坏相同 token 前缀条件。提示项在严格同题同模板下也可能代数抵消，但应先按回答 mask 清晰计算，避免长度、截断和拼接错误。

参考缓存的有效键至少包括模型权重版本、tokenizer/模板版本、IDs、回答 mask 与 EOS/截断规则。缓存既可能数学过期，也可能样本错配；检查固定样本四个数比只检查文件是否存在更可靠。检查 loss 极端值时使用 softplus；只用 sigmoid 再 log 会在大负间隔溢出或下溢。

训练后比较三条路径：训练对上的间隔、重新生成的任务质量、相对参考的分布偏移。只有第一条变好时不能宣称后训练达成目标；加入 chosen NLL 等项又是新的联合目标，需在报告明确公式与系数。

## 4.7 完整自测与面试问答

### 题 1：KL 正则奖励最大化的最优分布怎样计算？

**题目：**只有两个候选回答，参考概率 $q=(0.8,0.2)$，奖励 $r=(0,1)$，KL 系数 $\beta=1$。在概率分布 p 上最大化 $\sum_i p_i r_i-\beta\sum_i p_i\ln(p_i/q_i)$。已知最优解满足 $p_i^*=q_i e^{r_i/\beta}/Z$，$Z=\sum_iq_i e^{r_i/\beta}$。求未归一化权重、Z 与两个最优概率。

**参考答案：**权重为 $(0.8,0.2e)\approx(0.8,0.543656)$，$Z\approx1.343656$；相除得 $p^*\approx(0.595390,0.404610)$。第二回答概率因奖励提高，但 KL 代价阻止最优解直接把质量全部集中过去。

**面试追问：**DPO 为什么可以省去独立训练的奖励模型？

**追问回答：**在该正则化最优策略关系下，可把奖励改写为策略相对参考的 log-ratio 加同题常数；同题两个回答的常数相减抵消，代入 BT 偏好模型得到直接训练策略的损失。有限数据与模型不自动达到理想最优分布。

### 题 2：给同题所有奖励加常数为什么不改变最优策略？

**题目：**固定提示 x，参考分布 $q(y)>0$，奖励有限，$\beta>0$。最优概率为 $p^*(y)=q(y)e^{r(y)/\beta}/Z$。对该提示下所有回答把奖励改成 $r'(y)=r(y)+c(x)$，c 不依赖回答。证明新最优分布不变，并解释 DPO 为什么通常比较同一个提示下的两个回答。

**参考答案：**新权重共同乘 $e^{c(x)/\beta}$，新归一化和也乘同一因子，相除抵消。DPO 推导中的 $\beta\ln Z(x)$ 同样在同提示奖励差中抵消；跨提示配对时归一化项不同，不能直接套用同题公式。

**面试追问：**奖励乘正数也一定不变吗？

**追问回答：**固定 beta 时不会只是共同因子，会改变各候选相对权重。奖励尺度与 KL 权重之间的关系要明确，不能把平移不变误当尺度不变。

### 题 3：DPO loss 降低能保证 chosen 概率上升吗？

**题目：**同一提示有 chosen、rejected、other 三个候选，固定参考分布为 $(0.4,0.4,0.2)$。训练前策略为 $(0.4,0.4,0.2)$，训练后为 $(0.3,0.1,0.6)$。定义参考校正间隔 $\Delta=\ln(p_w/q_w)-\ln(p_l/q_l)$，损失 $L=\ln(1+e^{-\beta\Delta})$，$\beta=1$。计算两次间隔与损失，并检查 chosen 绝对概率。

**参考答案：**训练前间隔 0、损失 $\ln2\approx0.693147$；训练后间隔 $\ln(0.3/0.4)-\ln(0.1/0.4)=\ln3$，损失 $\ln(1+1/3)=\ln(4/3)\approx0.287682$。Chosen 从 0.4 降为 0.3，但 rejected 降得更多，参考校正相对排序仍改善。

**面试追问：**实际 DPO 应额外看什么？

**追问回答：**记录 chosen/rejected 的 log-prob、间隔、回答长度和偏好排序，并重新生成回答测独立质量。训练集相对排序改善不能代替生成效果。

### 题 4：用四个 log-prob 手算 DPO

**题目：**一对同提示偏好回答，序列自然对数概率依次为：当前 chosen $-4$、当前 rejected $-6$、参考 chosen $-5$、参考 rejected $-5.5$。它们已在有效回答 token 上求和。取 $\beta=0.2$，定义 $\Delta=(\ell_{\theta,w}-\ell_{ref,w})-(\ell_{\theta,l}-\ell_{ref,l})$，$L=-\ln\sigma(\beta\Delta)$。求间隔、偏好 logit 与损失，并说明哪些 token 应排除。

**参考答案：**间隔为 $1-(-0.5)=1.5$，偏好 logit 为 0.3，损失 $\ln(1+e^{-0.3})\approx0.554355$。在本题回答监督规则下排除提示和 padding；EOS 是否计入需固定。本题序列概率不要求两候选之和为 1，因为还有其他回答。

**面试追问：**把序列 log-prob 改成 token 平均是无关实现细节吗？

**追问回答：**它会改变长短回答在偏好比较中的得分，属于目标变动。标准求和与其他变体应明确区别；参考计算也要使用一致的分词和截断。

### 题 5：手写 DPO 核心 loss 并核对梯度

**题目：**使用题 4 的四个数实现上述函数，用 float64 autograd 与有限差分核对对当前两个 log-prob 的梯度，参考量不应收到梯度；再核对策略等于参考时 beta=0.2 的 loss 和梯度。

**参考答案：**delta=1.5，当前梯度约为 $(-0.0851115,0.0851115)$；相等时 loss=$\ln2$，梯度 $(-0.1,0.1)$。参考停止梯度。有限差分扰动的是教学 log-prob 变量，真实模型中还要经过合法概率参数化与共享网络。

**面试追问：**四个数是负数就必然是合法概率吗？

**追问回答：**负 log-prob 只保证单个概率小于 1；同题互斥完成序列的概率和不能超过 1。题 4 的值满足这一约束，任意负数列表未必满足。

### 题 6：loss 下降但测试退化的最小排查

**题目：**DPO 训练 loss 从 0.69 降到 0.2，测试正确率下降且回答变短。给出四个 log-prob、长度、截断与生成评测的检查方案，设计一个可区分偏好标签与实现错误的对照。

**参考答案：**先核对样本配对和 chosen/rejected、回答 mask、序列求和、参考缓存；分桶看 chosen/rejected 是否都降及有效长度。用小可靠偏好集验证核心函数和排序，再用同初始模型、固定预算训练原数据与人工审计后的数据；若实现检查通过而标签仍偏好错误短回答，目标与正确率冲突。比较独立生成与长度，避免仅据训练间隔解释。

**面试追问：**把 beta 改大能保证解决退化吗？

**追问回答：**离线优化的最终 KL 与质量不必随 beta 单调，标签、覆盖和截断错误更不能靠系数修复；应做单因素实验。
