# 第 1 章：从语言模型到后训练

> 本章目标：把“训练聊天模型”拆成概率模型、数据分布、监督信号和评测协议。读完后应能手工检查一条样本的标签移位与损失。前置：条件概率、梯度和基本 Transformer。

先用“1+1 等于几？”固定问题：同一个模型可能回答“2”，也可能续写一段无关文字。后训练要改变这些回答出现的概率。这里的**提示**是输入给模型的问题，**回答**是模型生成的文字，**监督信号**是告诉训练程序哪种回答更合适的示范、比较或分数。先分清三者，再看它们怎样进入损失函数。

可以先做[四个短程序实验](../短程序实验.md)中的 SFT 一步：模型给“2”的概率为 0.6，示范答案正是“2”，损失约 0.511。这个数只涉及一题、一个答案 token；下文才推广到整段回答和一批数据。

## 1.1 后训练究竟改变什么

设模型已经读过大量文本，它可能既会续写正确解答，也会续写错误解答；既会回答问题，也会把问题当成小说开头。预训练优化的是训练语料上的预测，产品却要求它在特定提示下提供有用答案。这两个分布与目标并不自动相同。后训练通过示范、偏好或任务奖励，改变给定提示后各种回答的概率。

这不是“先学知识、再学礼貌”的严格分工。监督微调可能教会新任务格式和知识；强化学习可能改变解题策略及其出现概率；已有能力也可能因数据偏移而退化。应以控制实验判断变化，避免仅凭阶段名称解释模型行为。InstructGPT 是理解“示范—偏好—奖励—策略更新”数据流的经典入口，其结果依赖所用提示与评判分布。[原始论文](https://arxiv.org/html/2203.02155v1)

## 1.2 把一句话变成概率

记提示为 $x$，回答为 $y=(y_1,\ldots,y_T)$，其中每个 $y_t$ 是一个 token，$T$ 是回答长度，最后包含约定的结束符 EOS。**条件分布**表示在给定提示和已生成前缀后，模型对下一 token 给出的概率。整段回答的概率按链式法则写为

$$
\pi_\theta(y\mid x)=\prod_{t=1}^{T}\pi_\theta(y_t\mid x,y_{<t}),\qquad
\ell_\theta(x,y)=\sum_{t=1}^{T}\log\pi_\theta(y_t\mid x,y_{<t}).
$$

$\theta$ 是可更新参数，$y_{<t}$ 是已生成前缀。序列概率很小，因此代码累加 log-prob（对数概率），不要连乘概率。这里的和是整段回答的 log-prob；除以长度会产生另一个统计量，不能随意替换 DPO 等方法中的序列量。

在监督数据分布 $D$ 上，SFT 最小化负对数似然；在奖励函数 $r$ 下，RL 最大化当前策略生成回答的预期奖励。差别不仅是 loss 公式，还包括训练答案来自哪里：SFT 通常读取固定示范，在线 RL 必须不断采样当前或近期策略的回答。离线偏好优化则使用固定的回答对。本书依次研究这三种反馈方式。

## 1.3 从 token IDs 到标量损失

设一次送进模型的样本数为 $B$（批大小），每条拼接后的最大 token 数为 $L$，词表中不同 token 的总数为 $V$。`input_ids` 是 token 编号组成的 `[B,L]` 数组；模型给每个位置的每个候选 token 一个未归一化分数，叫 **logit**，所以输出形状是 `[B,L,V]`。若手工实现“预测下一个 token”的损失，应使用 `logits[:, :-1, :]` 预测 `input_ids[:, 1:]`，得到 `[B,L-1]` 个目标 token 的对数概率。许多模型接口在内部移位，外部再次移位会造成错位。

例如拼接序列为 `[BOS, 问题, 答案甲, 答案乙, EOS, PAD]`。以“只监督回答”为约定，移位后的目标为 `[问题, 答案甲, 答案乙, EOS, PAD]`，loss mask 为 `[0,1,1,1,0]`。注意第一个答案 token 由最后一个提示位置的 logits 预测，而不是由答案自己的位置预测。

$$
\mathcal L_{\mathrm{SFT}}
=-\frac{\sum_{b,t}m_{bt}\log\pi_\theta(z_{b,t+1}\mid z_{b,\le t})}
{\sum_{b,t}m_{bt}},
$$

其中 $m_{bt}\in\{0,1\}$ 表示该目标是否参与监督，分母必须大于零。这个公式按有效 token 平均；先按样本平均再平均批次会让长短答案的权重不同，两者都可以定义，但必须写清。

要区分三种 mask：因果 mask 禁止关注未来；attention mask 标识 padding 或分段可见性；loss mask 决定哪些目标产生训练信号。忽略提示的 loss 不等于模型看不到提示。`labels=-100` 常作为损失忽略标记，但它不是词表 token。[TRL SFT 文档](https://huggingface.co/docs/trl/sft_trainer)

## 1.4 与强化学习的对应

在单轮文本生成中，可令状态 $s_t=(x,y_{<t})$、动作 $a_t=y_t$、转移为把 token 追加到前缀，EOS 终止。只有最终答案可判分时，奖励主要集中在终点。对话工具调用还需把工具输出与环境变化纳入状态；不能把所有文本都当成策略动作。完整定义见 [RL 第 1 章](../../RL/chapters/01_MDP与回报.md)。

因此，一个 LLM RL 样本不是单独的文本：它还需要提示、回答、有效长度、采样策略的 log-prob、奖励，以及之后计算的优势。数据生成器、验证器和优化器共同决定实验的含义。

## 1.5 第一次实验应如何落地

先用三条短样本打印 token、目标与 mask；再比较手工 log-prob 与库 loss 的归约约定；随后只对少量样本做过拟合。若 loss 降低但生成不变，检查推理是否加载了更新后的权重、模板是否一致、EOS 是否被错误屏蔽。若验证 loss 异常好，先排查问题重复和答案泄漏。

8 GB 显存应从短序列、小模型和单批次资源测量开始。参数量只能估算权重存储；激活、优化器状态、参考模型、采样缓存都会占显存。本书的 [CPU 数值实验](../experiments/README.md) 用来检查数学与 mask，不代表已完成真实语言模型训练。

## 1.6 深入：同一模型上的监督梯度与奖励梯度

### 一个前缀下的两种目标

固定状态 s，三个候选的 softmax 概率为 $p=(0.6,0.3,0.1)$，示范选择候选 1。对 logits z 的交叉熵梯度是 $\nabla_z L_{SFT}=p-e_1=(-0.4,0.3,0.1)$。推导使用 $\partial\log p_i/\partial z_j=\mathbf1[i=j]-p_j$；做梯度下降会提高示范 logit 的相对值。

若奖励为 $r=(1,0,0)$，RL 目标 $J=\sum_i p_i r_i=0.6$，梯度为 $\partial J/\partial z_j=p_j(r_j-J)$，即 $(0.24,-0.18,-0.06)$。可从 softmax Jacobian 直接推出，也可从 score-function 形式 $\mathbb E_{a\sim p}[(r(a)-b)\nabla_z\log p(a)]$ 推出，b 不依赖当前动作。本例方向有对应关系，但幅度不同；多条奖励、负反馈和采样覆盖改变后，两目标不能简单互换。

SFT 读取示范，能够为当前概率很小但数据中存在的答案提供梯度；在线奖励学习首先要采样到有用输出。某类成功轨迹采样概率极低时，验证器正确也不等于训练拥有足够信号。这是为什么基座、冷启动数据、探索和题目难度共同影响 RL 实验。

### 模型概率与实际采样概率要分开

温度采样给 $\tilde p_i\propto\exp(z_i/\tau)$；top-k/top-p 还会截断并重新归一化。它们定义实际行为分布，不一定等于模型原始 $p_i$。若 PPO 的分母号称是采样分布，却缓存另一种分布的 log-prob，重要性解释会发生改变。一个系统可以有明确的近似选择，但必须写明并做误差或稳定性检查。

有限最大长度使回答集合可控；到达上限的无 EOS 输出是截断结果，是否把它当有效答案和终止必须在任务里定义。若没有最大长度与几乎必然终止保证，不能自动说所有有限完成序列的概率总和为 1。教学项目应把 EOS、最大长度、解析与奖励协议一起冻结。

### 作业应提交能定位问题的样本记录

每条记录包括原始问题与模板版本、完整 token IDs、目标 mask、序列 log-prob、行为模型版本、奖励及解析状态。用固定输入核对重新计算概率与缓存是否一致，再检查奖励。只保存一个平均 reward 无法区分“回答全错”“解析全坏”与“加载错误模型”。

## 1.7 完整自测与面试问答

### 题 1：SFT 的标签移位与三种 mask 怎样区分？

**题目：**一条完整序列为 `[P1,P2,P3,A1,A2,EOS]`，P 为提示 token，A 为回答 token，EOS 是回答结束标记。使用手动一次移位：输入取前五项，标签取后五项；只监督 A1、A2 与 EOS，提示目标不参与 loss。写出输入、标签和 loss mask，并说明因果 mask、padding attention mask、loss mask 的职责。

**参考答案：**输入为 `[P1,P2,P3,A1,A2]`，标签为 `[P2,P3,A1,A2,EOS]`，loss mask 为 `[0,0,1,1,1]`。每个 logits 位置预测下一 token。因果 mask 限制看未来，padding attention mask 标识无效补齐位置，loss mask 选择监督目标。提示虽然不产生监督 loss，仍是回答可读取的上下文。

**面试追问：**使用会在内部移位的模型接口时怎么办？

**追问回答：**按该接口传完整、未额外移位的 labels，并检查一次真实样本的对齐。自己再移一次会造成两次移位；不能只看张量形状正确。

### 题 2：token 平均与序列平均怎样给长答案加权？

**题目：**一个批次有两条回答，短回答含 2 个有效 token，各 token 损失为 1；长回答含 20 个有效 token，各 token 损失为 2。没有 padding 参与计分。分别算全批有效 token 平均损失，以及先对每条回答取均值再对两条回答平均的损失；给出长回答的总权重。

**参考答案：**Token 平均为 `(2×1+20×2)/22=21/11≈1.909091`，长回答总权重为 `20/22=10/11`。序列平均为 `(1+2)/2=1.5`，长回答总权重为 1/2。两者定义不同，不能在训练和验证里悄悄切换。

**面试追问：**两条回答每个 token 损失都相同，是否说明目标等价？

**追问回答：**单次标量 loss 可能碰巧相同，逐 token 的梯度权重仍不同。应比较一般损失和梯度，而不只看一个相同数值。

### 题 3：训练奖励提高但测试正确率下降，怎样排查？

**题目：**同一初始模型做后训练，训练奖励从 0.6 升至 0.9，但冻结测试集上的正确率从 70% 降至 65%。测试提示与解码设置已固定。请提出至少三种解释，并为每种给出能检查它的证据。

**参考答案：**可能过拟合训练题：按未见题目族或数字范围分桶检查；可能奖励漏洞：比较高奖励回答与独立正确性验证，人工复核解析边界；可能训练与测试分布不同：按题型、长度与难度比较数据和逐题变化。还应核对所加载检查点、模板和终止规则，避免把工程错误当算法结论。

**面试追问：**只报告训练 loss 或奖励能证明后训练有效吗？

**追问回答：**它只表明训练目标被拟合。有效性要由预先确定的独立任务指标、成本和失败样例支持。

### 题 4：手推同一 softmax 的两种梯度

**题目：**使用第 1.6 节 p、示范和奖励，推导 SFT loss 与期望奖励对 logits 的梯度；用三维 logits 和 autograd 核对。解释梯度之和为何为零，并给出 SFT 与在线 RL 的数据差别。

**参考答案：**梯度分别为 $(-0.4,0.3,0.1)$ 与 $(0.24,-0.18,-0.06)$。共同平移 logits 不变，故沿全 1 方向导数为零。SFT 有示范目标；在线 RL 的奖励来自策略实际采样，覆盖不足会限制学习信号。

**面试追问：**把所有奖励加 10，期望奖励梯度变吗？

**追问回答：**在这个固定概率空间且正确求期望时不变，因为增加的常数期望为 10，其梯度为零；截断、奖励归一化或有限估计要分别分析。

### 题 5：训练正常但在线更新突然失稳

**题目：**采样器把温度从 1 改为 0.5，但缓存仍是原始 softmax log-prob，PPO learner 使用这些值作为 old 分母。以原 logits $(0,\ln3)$ 算两种概率，并给出修复和验收。

**参考答案：**原概率为 $(1/4,3/4)$，温度 0.5 后为 $(1/10,9/10)$。真实采样概率与缓存不一致，需冻结并明确训练/采样分布定义，保存真实行为版本和采样配置；在采样参数处重新计算比率，匹配分布时应为 1。采用原始概率的近似算法要说明其目标，不应宣称严格重要性校正。

**面试追问：**只换回温度能验证全部系统正确吗？

**追问回答：**还需核对 top-p、模板、token mask、EOS、模型权重版本与推理/训练数值差异，再做固定样本比率检查。

### 题 6：把后训练实验写成可重建记录

**题目：**提交三条样本的上述记录和一份不训练基线评测。故意制造标签移位、错误加载权重、格式解析失败三个案例，说明哪些字段能定位每种错误。

**参考答案：**标签错误靠逐位置 token/目标/mask 与手算 loss；加载错误靠 checkpoint 标识及固定输入 logits；解析失败靠原输出、解析状态与 reward reason。基线冻结问题、解码与验证器，三类错误应分别报告，不能统称模型不会回答。

**面试追问：**程序退出码 0 为什么不等于实验有效？

**追问回答：**它只证明程序走完；数据目标、奖励语义与评测可能仍错误，需数值参照和逐样本证据。
