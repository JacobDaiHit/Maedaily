# 环境准备与常见问题：把第一条命令跑起来

[回到入门目录](README.md) · [第一课](第一课_从预测到学习.md)

本项目入门实验都在本机 CPU 上运行，不需要购买 API、下载模型权重或配置云服务。先完成标准库第一课，再使用已有 PyTorch 环境。以下 Windows 路径与统一入口重新核验于 2026-10-02；更换电脑时路径需要相应调整。

## 1. 三种东西先分清

| 名称 | 它是什么 | 在这里用来做什么 |
| --- | --- | --- |
| PowerShell / 终端 | 输入系统命令的窗口 | 进入项目文件夹、启动 Python |
| Python 解释器 | 执行 `.py` 文件的程序 | 运行课程脚本 |
| PyTorch，导入名 `torch` | 安装在某个 Python 环境里的包 | 张量运算、自动微分、训练模型 |

同一台电脑可以有多个 Python。一个环境装了 torch，另一个未装，完全可能。遇到 `No module named 'torch'`，先检查使用的是哪一个解释器；不要在不清楚的环境里反复安装。

文件 `.md` 是阅读用的 Markdown，`.py` 是执行用的代码，`.json` 是结构化记录，`.csv` 是表格数据，`.pdf` 是参考原文。第一次不用打开全部目录，也不用先运行下载脚本。

## 2. 进入项目并检查环境

打开 PowerShell，逐行执行：

```powershell
Set-Location 'D:/github_book/Maedaily'
python --version
python scripts/run_lesson.py --check
```

`Set-Location` 就是切换当前文件夹。第二行显示当前默认 Python 版本，第三行只检查环境。2026-10-02 本机默认 `python` 是 `D:/anaconda/python.exe` 的 Python 3.8.3，低于统一入口要求的 3.10；入口随后尝试已存在的 `C:/Python313/python.exe`（3.13.5）运行标准库课程。检查 PyTorch 时，再找到 `D:/anaconda/envs/pytorch_env/python.exe`（3.11.15 / PyTorch 2.7.1+cu118）。入口会打印实际选中的解释器。中间出现“不可用”是候选环境的检查结果，最后“PyTorch 课程：可以开始”才是完整结论。

若 `python` 命令不存在或跳到商店，在这台机器上用已核验的完整路径：

```powershell
& 'C:/Python313/python.exe' 'D:/github_book/Maedaily/scripts/run_lesson.py' --check
```

若采用这个备用方式，后续命令开头的 `python` 也要换成 `& 'C:/Python313/python.exe'`。例如进入项目目录后，第一课运行 `& 'C:/Python313/python.exe' scripts/run_lesson.py first`。

PowerShell 中路径被引号包住时，开头的 `&` 表示执行它。项目目录 `pytorch&mindspore` 也包含 `&`，直接调用其中脚本时要给整条路径加引号；统一入口已经处理这种路径。

## 3. 跑第一课，再跑真实训练

```powershell
python scripts/run_lesson.py first
python scripts/run_lesson.py linear
python scripts/run_lesson.py lm
```

每次运行结束先读终端末尾的“中文结果说明”，再看它打印的结果目录。`linear` 和 `lm` 会选择可导入 torch 的已有解释器；没有自动下载、安装或切换系统配置。

明确指定环境也可以：

```powershell
python scripts/run_lesson.py lm --python 'D:/anaconda/envs/pytorch_env/python.exe'
```

显式指定的环境不可用时，脚本会停下，不会默默改用另一个。`--check` 检查的是版本和导入，实际实验中的数值检查才检验课程行为；新设备或其他 torch 版本不保证逐位相同。

## 4. 结果存在哪里，下一次会不会覆盖

默认每次创建 `study_runs/年月日_时间_课程名/`。这个目录保存个人运行结果，已加入 Git 忽略；各模块 `experiments/results` 里的教学参照仍保留在项目中。

| 文件 | 怎么看 |
| --- | --- |
| `结果说明.txt` | 先读中文关键指标 |
| `console.txt` | 完整程序输出；出错时保留报错上下文 |
| `run.json` | 实际命令与传递参数、代码/环境、时间与退出码；`program_success` 表示子程序成功，`success` 还要求结果说明生成成功 |
| `artifacts/summary.json` / `artifacts/first_steps.json` | 支持文件输出的课程指标，按本课中文字段表查阅 |
| `artifacts/learning_curve.csv` | 用编辑器或表格软件查看训练过程；不是每课都有 |

也能指定一个尚不存在或空的目录：

```powershell
python scripts/run_lesson.py first --output-dir 'study_runs/我的第一课'
```

同名目录已有内容时入口与支持输出的底层实验会停止，以保留原记录。重新运行可省略参数自动创建新目录。`.json` 与 `.csv` 用文本编辑器打开即可，现阶段不用另外安装绘图软件。

## 5. 按报错找解决位置

| 看到什么 | 通常意味着什么 | 先做什么 |
| --- | --- | --- |
| `can't open file` / 找不到文件 | 当前目录或脚本路径错误 | 重新执行 `Set-Location`，确认根目录里有 `README.md` 和 `scripts` |
| `>>>` 后执行命令报 `SyntaxError` | 把终端命令输入了 Python 交互窗口 | 输入 `exit()` 后，在 PowerShell 执行 |
| `No module named 'torch'` | 所选解释器没有该包 | 用 `--check`，再用 `--python` 指定已有 PyTorch 环境 |
| 路径中的 `&` 报语法错 | PowerShell 把路径部分当成运算符 | 给整个路径加单引号，或使用统一入口 |
| `AssertionError` | 某个结果没有通过明确的正确性检查 | 看最后一条断言含义；保留参数与完整日志，回对应算例 |
| `NaN` / `inf` | 非有限数，常来自除零、溢出或全零有效 mask | 先回默认配置，再查损失分母与学习率 |
| `0.000000` 或 `1.36e-09` | 打印精度或科学计数法 | `1.36e-09` 是 $1.36\times10^{-9}$，不一定是错误 |
| 训练损失下降、验证损失变差 | 更贴合训练数据，不保证更好泛化 | 固定验证集，检查过拟合、切分与超参数；不要直接继续加步数 |
| 第一次导入 torch 稍慢 | 解释器加载包和库 | 等终端结果；此步骤不是下载权重 |

不确定时，记录“运行命令、完整错误最后约 20 行、`--check` 输出、刚改过什么”。这四项足够开始排查，比只说“跑不了”更容易定位问题。

## 6. 换到一台没有 PyTorch 的电脑时

标准库课只需要 Python 3.10 或更高版本；本地真实训练验证使用 Python 3.11.15 / PyTorch 2.7.1。若已经有可用环境，直接指定它。下面是 **Windows、已安装 Python 3.11、准备新建课程环境时** 的可选命令，不是当前机器必须执行的步骤：

```powershell
py -3.11 -m venv .venv-maedaily
& '.venv-maedaily/Scripts/python.exe' -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
python scripts/run_lesson.py linear --python '.venv-maedaily/Scripts/python.exe'
```

`venv` 创建独立环境，`-m pip` 确保把包安装到指定解释器。这里只需 torch，课程没有使用图像或音频包。CPU 包的固定版本安装方式核对自 [PyTorch 官方历史版本页](https://pytorch.org/get-started/previous-versions/)。若第一行提示不存在 Python 3.11，先确认已有 Python 版本；可以先学标准库课，避免把环境问题和算法问题同时处理。

本次没有实际创建该新环境或执行安装；真正实跑的是当前已有环境。MindSpore 对照、GPU 和分布式训练放到后续阶段。

## 统一入口、变参实验和结果目录

从仓库根目录运行 `python scripts/run_lesson.py --list` 查看当前课程。`first`、`embedding`、`rl`、`posttrain`、`agent`、`trajectory` 和 `data-asset` 使用 Python 标准库；`linear`、`lm`、`lm-resume`、`attention` 及三个模型后训练阶段需要可用 PyTorch。统一入口探测已有解释器，缺少依赖时打印缺失信息；换电脑后先运行 `--check`。

```powershell
python scripts/run_lesson.py --check
python scripts/run_lesson.py linear
python scripts/run_lesson.py lm
python scripts/run_lesson.py first -- --learning-rate 0.05
python scripts/run_lesson.py lm -- --seed 11 --learning-rates 0.001 0.003
```

入口参数写在 `--` 之前，实验参数写在它之后。例如 `--python` 选择解释器、`--output-dir` 选择本次目录；学习率、种子和步数属于后面的实验参数。底层脚本的 `--help` 可查受支持的实验参数；`--output-dir` 统一由入口管理，不能再放在实验参数中。非法参数会失败，缩小预算后未达到学习门槛也会据实失败。

每次运行新建独立的 `study_runs/时间_课程/`。第一课学习率 0.05 的变参结果应为预测 `2 → 2.75`、损失 `4.5 → 2.53125`；默认 0.1 的参考值不会被套用到新配置。先看终端打印的位置和父目录 `结果说明.txt`，再看 `console.txt`；`run.json` 保存真实命令与传递参数、代码版本/脚本哈希及 Python/PyTorch 环境信息。支持文件输出的实验把 JSON、CSV、数据和检查点放入本次 `artifacts/`，实际解析配置与默认参数按本课的 summary 或 `config.resolved.json` 核对，日志与说明留在父目录。课程目录里跟踪的 `experiments/results/` 是固定教学参照，自己新跑的结果在 `study_runs`。

```powershell
python scripts/run_lesson.py linear --output-dir 'study_runs/第一次线性训练'
python scripts/run_lesson.py lm --output-dir 'study_runs/lm_seed19' -- --seed 19
```

指定目录已有内容时，入口和底层实验都拒绝覆盖。要保留另一配置，使用默认新目录或另一个空目录。目录中的 `.maedaily-output.json` 用于识别由运行程序创建的输出位置，不需手动编辑；不要把已存在的教学参照目录传给输出参数。

### 2026-09-26 至 2026-10-02 的默认配置参考结果

下面迁移自首页的历史教学参照，具体日期、配置和浮点精度以各实验说明及[版本记录](../references/版本与验证记录.md)为准。更改种子、学习率或步数后，以本次运行的配置和结果为准。

| 课程 | 默认配置的重要结果 | 怎样理解 |
| --- | --- | --- |
| `first` | 损失 4.5 → 1.125 | 手写解析梯度完成一次更新 |
| `linear` | 学到权重约 `[2,-3]`、偏置 0.5；恢复下一步误差 0 | 真实 PyTorch 训练；遗漏动量会改变下一步更新 |
| `lm` | lr=0.001 的验证损失约 1.053525；lr=0.003 约 1.187625 | 同一初始化和预算下，训练更低不一定验证更好 |
| `lm-resume` | 连续 40 步与完整恢复的 20+20 步，每步参数和损失差 0 | 保存模型、AdamW、数据位置与随机源；遗漏状态的两种对照都会产生差异 |
| `data-asset` | 50 条输入保留 44 条、过滤 6 条；分组切分为 28/6/10 | 保留来源、审计和版本，逐字重建；显式题族与精确重复不跨划分 |
| `embedding` | SGNS 损失 2.006409 → 1.858407；有限差分误差约 1.55e-10 | 核对查表、负采样、pooling、温度与检索排序 |
| `attention` | RoPE 缓存与完整因果计算误差 0；错误矩形 mask 偏差约 2.388 | 核对 Attention 梯度、在线 softmax 与 MLA 等价 |
| `rl` | 起点价值 1.6，选择先投入再完成 | 表格 Q-learning 与独立手算一致 |
| `posttrain` | 45 项数值检查；DPO loss 约 0.554355 | 检查概率、掩码、偏好、组优势和验证器 |
| `agent` | 42 项检查；正常计算和暂时故障恢复都得到 4 | 检查规则控制器的工具流程与请求级重试编号 |
| `trajectory` | 正确动作 mask 的损失 0.25 | 工具观察不应混入策略动作损失 |

不同机器的耗时和浮点末位可能不同，先确认检查通过和结果方向，再分析差异。标准库公式核算、数字语法 LM、字符模型真实 SFT/DPO/RLVR 与预训练自然语言项目各有适用范围；小实验通过不能代替年度项目的独立评测、数据质量和自然文本验收。
