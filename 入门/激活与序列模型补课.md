# 激活与序列模型补课：从一条折线到一段记忆

读完本课，你应能亲手解释三个问题：网络为什么需要激活函数，一句话的先后顺序怎样进入计算，较早的信息为什么可能难以学到。这里用一个数代表一层或一刻的状态，先算懂，再进入向量和矩阵。所有数字都是为教学自设的例子。

## 一、层数多，为什么还可能只是一条直线？

设输入为实数 $x$，第一层输出 $h=2x$，第二层输出 $y=3h$。代入便得到 $y=6x$：两层纯线性变换仍是线性变换。给它们加上常数，改成 $h=2x+1$、$y=3h-4$，就得到 $y=6x-1$。这里的常数叫**偏置**，负责平移；严格说，带偏置的形式叫仿射变换。两层仿射仍能合成一层仿射。即使换成矩阵，只要维度相容，也有同样的合并规律。

如果目标是“太小和太大都不好，中间最好”，单条直线就无法表达这种转折。**激活函数**是在层间施加的非线性函数，让输入改变时，响应方式也能改变。常见的 ReLU 定义为

\[
\operatorname{ReLU}(z)=\max(0,z).
\]

读作“零和输入 $z$ 取较大者”。逐个处理 $[-2,0,3]$，得到 $[0,0,3]$。例如 $y=\operatorname{ReLU}(2x+1)$，在 $x<-0.5$ 时输出零，在 $x>-0.5$ 时沿斜率为二的直线增长，中间出现折点。非线性增加了表达可能性，但不能保证数据、训练方法和模型容量都足够。

**导数**描述输入微小变化时输出怎样变化，也就是局部斜率。ReLU 在负数处导数为零，在正数处为一，在零点没有普通导数，软件需选择约定。若当前 $z=-2$，只稍微移动 $z$，输出仍为零，因此反向传播经过这一节点的局部梯度为零。这不等于该节点永远失效：其他样本可能使它进入正区，其他参数变化也可能改变它的输入。判断“死亡”需要看它在实际数据上的持续表现。

## 二、为什么用 sigmoid 做门？

若要控制“让多少信息通过”，一个介于零和一之间的乘数很好理解。sigmoid 函数写作

\[
\sigma(z)=\frac{1}{1+\exp(-z)}.
\]

这里 $\exp(u)$ 表示自然指数 $e^u$。对有限实数输入，输出严格位于 $(0,1)$；输入零，输出 $0.5$。输入 $\ln 9$ 时输出 $0.9$，输入 $-\ln 9$ 时输出 $0.1$，其中 $\ln$ 是自然对数。用 $0.9$ 乘一份信息，就保留它的九成数值，这种乘法控制叫**门控**。门值是计算中的缩放系数，并不自动代表“信息正确的概率”。

sigmoid 也有代价：输入绝对值很大时，输出靠近两端，局部斜率很小，称为**饱和**。所以“输出有界”和“容易训练”是两个不同问题。

## 三、让网络记住刚才发生了什么

逐个读取数字时，不能只看眼前这个数。循环神经网络，简称 RNN，会保留**隐状态**：处理到当前时刻形成的一份内部摘要。先用最简单的标量递推：

\[
h_t=0.5h_{t-1}+x_t,\qquad h_0=0.
\]

$t$ 是步骤编号，$x_t$ 是当前输入，$h_{t-1}$ 是上一步摘要，$h_t$ 是新摘要。读法是“旧摘要保留一半，再加当前输入”。输入按 $[1,2,3]$ 到来时，计算如下：

| 步骤 | 计算 | 新摘要 |
|---|---|---|
| 1 | $0.5\times0+1$ | 1 |
| 2 | $0.5\times1+2$ | 2.5 |
| 3 | $0.5\times2.5+3$ | 4.25 |

逆序读取 $[3,2,1]$，摘要依次为 $3,3.5,2.75$。同样三个数，最后结果不同，因为越早出现的输入经过了越多次衰减。把原式展开为 $h_3=0.25x_1+0.5x_2+x_3$，便能直接看到顺序的作用。

这也是**参数共享**的例子：每一步复用相同系数 $0.5$，没有给第一步和第二步各设一套规则。实际 RNN 通常学习矩阵和偏置，并使用非线性；上面的标量线性递推只是帮助理解状态更新。固定大小的隐状态通常是压缩摘要，不能假定它完整保存所有历史。

## 四、旧信息还在，为什么可能学不到？

训练要追问“当前误差对较早的状态有多敏感”。固定中间输入不变，从 $h_{t-2}$ 到 $h_t$ 经过两次乘 $0.5$。由链式法则，即沿计算路径把局部导数相乘，得到

\[
\frac{\partial h_t}{\partial h_{t-2}}=0.5\times0.5=0.25.
\]

这表示较早状态增加一个很小的量，当前状态只增加其四分之一。跨越 $k$ 步时为 $0.5^k$，步数大时接近零。误差反馈经过这条路径可能越来越弱，这就是**梯度消失**的一种具体机制。反过来，若这个标量系数改成二，路径导数就是 $2^k$，可能迅速变大。实际 RNN 还涉及矩阵、激活函数和损失，不能仅凭一个权重的数值判断整个网络。

这里算的是“状态对状态”的导数，还不是最后用于更新参数的梯度。真正训练时，先用损失函数衡量预测错了多少，再沿展开的时间步骤反向求导；同一个共享参数在多步出现，来自各步的贡献需要相加。这个过程叫**通过时间反向传播**。因此，即使前向计算仍能得到一个数，也要另外检查反向信号是否足够有效。

## 五、门控怎样给记忆多留一条路？

先设旧记忆为 $c_{\text{old}}$，待写入的候选内容为 $u$，固定两个门值，做一次简化混合：

\[
c_{\text{new}}=0.9c_{\text{old}}+0.1u.
\]

若旧记忆为一、候选为二，新记忆就是 $0.9\times1+0.1\times2=1.1$。固定门和候选不变，沿旧记忆直接传递的导数为 $0.9$，两步为 $0.81$，比前例的 $0.25$ 衰减得慢。不过重复足够多步，$0.9^k$ 仍会趋近零。

这只演示 LSTM 的一条记忆更新路径，不是完整 LSTM。标准 LSTM 的候选通常经过 tanh，数值在 $(-1,1)$ 内，本例的候选二只是混合算术示意；两个门也不必相加为一。实际门值随输入和旧隐状态变化，还存在输出门和其他导数路径。因此，这里的 $0.9$ 不是整个 LSTM 的总导数，更不能推出“LSTM 保证永久记忆”。

## 六、注意力为什么要回看旧位置？

如果一句话很长，回答当前问题时，可能需要回看其中某个旧词。注意力保留多个位置的表示，再根据当前需要计算权重，取它们的加权和。例如两个位置的数值为一和三，权重为 $0.25,0.75$，读出的结果就是 $2.5$。换一个当前问题，权重可以改变，从而减少把所有内容先挤进单份摘要的压力。

注意力权重来自可训练的计算，不代表系统天然知道什么有用。它还需要位置信息；生成下一个词时，需要屏蔽未来位置，避免偷看答案。保存和比较更多位置也有计算与存储成本。接下来可分别进入[激活函数](../激活函数/README.md)、[RNN](../RNN/README.md)，再读 [Transformer 从零上手](../transformer/从零上手.md)。

## 七、完整自测与运行核对

### 题 1：ReLU 的局部导数怎样经过链式法则？

**题目：**定义 $y=\operatorname{ReLU}(2x+1)$，$\operatorname{ReLU}(z)=\max(0,z)$。分别求 x=-1 与 x=1 的输出，以及 y 对 x 的导数。请区分 ReLU 对其输入 z 的导数和整个函数对 x 的导数；本题不在不可微零点计算。

**参考答案：**x=-1 时内部值 -1，输出 0，对 x 的导数 0；x=1 时内部值 3，输出 3，对 x 的导数 2。正区间 ReLU 对 z 的导数为 1，再乘内部 2x+1 对 x 的导数 2。

**面试追问：**把正区间导数答成 1，遗漏了什么？

**追问回答：**遗漏了内部映射的导数，链式法则要沿完整计算路径逐项相乘。

### 题 2：递推结构一定区分顺序吗？

**题目：**标量递推为 $h_t=a h_{t-1}+x_t$，初始 $h_0=0$。取 a=1，分别输入 [1,2,3] 与 [3,2,1]，给出所有中间状态和最后摘要。再取 a=0.5 求两个最后摘要，说明结构与具体参数的区别。

**参考答案：**a=1 时两组状态分别为 [1,3,6]、[3,5,6]，最后都为 6；a=0.5 时最后分别为 4.25、2.75。递推允许顺序影响，但某个参数设置可能退化为求和，不能只根据结构名称推断实际区分能力。

**面试追问：**两个输入的最终摘要相同，就说明模型从没看到顺序吗？

**追问回答：**不能。中间状态可以不同，最终映射也可能把不同历史压成相同数值；应检查具体状态与任务输出。

### 题 3：保留门与写入门怎样改变记忆？

**题目：**简化标量门控更新为 $c_{new}=f c_{old}+i u$，保留门 f=0.9，写入门 i=0.1，旧记忆 $c_{old}=4$，候选 u=-2。门值在本题中固定，u 只是算术候选，没有经过 tanh。求新记忆及其对旧记忆的局部导数，并说明不能直接称其为完整 LSTM 的原因。

**参考答案：**新记忆为 0.9×4+0.1×(-2)=3.4，固定 f、i、u 后对旧记忆的导数为 0.9。完整 LSTM 还包含由输入与隐藏状态计算的门、候选非线性和输出门；本题只展示记忆保留与写入这条路径。

**面试追问：**f=0.9 就能保证任意长序列梯度稳定吗？

**追问回答：**不能。仅该直接路径连续 n 步就含 $0.9^n$；完整梯度还有门值变化和其他路径，须分别分析。

下面只用 Python 标准库。在项目的 `study_runs` 文件夹中新建 `sequence_first.py`，粘贴代码块内的内容并保存；没有该文件夹时先新建。`assert` 是核对条件，条件不成立就报错；`isclose` 允许浮点数的微小舍入误差。

```python
from math import exp, isclose, log

def scan(xs, coefficient=0.5):
    h, history = 0.0, []
    for x in xs:
        h = coefficient * h + x
        history.append(h)
    return history

relu = lambda z: max(0.0, z)
sigmoid = lambda z: 1.0 / (1.0 + exp(-z))
assert [relu(z) for z in [-2, 0, 3]] == [0, 0, 3]
assert all(isclose(3 * (2*x + 1) - 4, 6*x - 1)
           for x in [-2, 0, 3])
assert isclose(sigmoid(log(9)), 0.9)
assert isclose(sigmoid(-log(9)), 0.1)
forward, reverse = scan([1, 2, 3]), scan([3, 2, 1])
assert forward == [1.0, 2.5, 4.25]
assert reverse == [3.0, 3.5, 2.75]
two_steps = lambda h: 0.5 * (0.5*h + 2) + 3
epsilon = 1e-5
gradient = (two_steps(1+epsilon)-two_steps(1-epsilon))/(2*epsilon)
assert isclose(gradient, 0.25, abs_tol=1e-9)
for x, expected in [(-1, 0), (1, 2)]:
    slope = (relu(2*(x+epsilon)+1)-relu(2*(x-epsilon)+1))/(2*epsilon)
    assert isclose(slope, expected, abs_tol=1e-9)
assert isclose(0.9*1 + 0.1*2, 1.1)
assert isclose(0.9*4 + 0.1*(-2), 3.4)
assert scan([1, 2, 3], 1)[-1] == scan([3, 2, 1], 1)[-1] == 6
print("forward:", forward, "reverse:", reverse)
print("two-step gradient:", round(gradient, 6))
print("all checks passed")
```

在项目根目录的 PowerShell 中运行：

```powershell
python study_runs/sequence_first.py
```

预期两行数值分别包含 `[1.0, 2.5, 4.25]`、`[3.0, 3.5, 2.75]` 和 `0.25`，最后显示 `all checks passed`。这里是确定性算术核对，没有训练网络，也不需要安装深度学习框架。
