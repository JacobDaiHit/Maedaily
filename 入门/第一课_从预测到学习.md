# 第一课：从一次预测，理解模型怎样学习

[入门目录](README.md) · [不会运行时看这里](环境准备与常见问题.md) · 下一课：[张量与框架](../pytorch&mindspore/从零上手.md)

这一课只需要加减乘除。导数、概率和代码第一次出现时都会解释。目标是亲手算出一次参数更新，并知道屏幕上的结果代表什么。预计用 45–90 分钟；可以分两次完成。

## 1. 先认识输入、答案和模型

假设我们拿到一条数据：输入数字 2，希望输出数字 5。这里先不讨论自然语言，也不需要大模型。用一个很小的计算规则预测：

$$\widehat y=wx+b.$$

逐个读：$x$ 是输入；$\widehat y$ 读作“y 帽”，表示预测；$w$ 是权重，决定把输入放大多少；$b$ 是偏置，决定整体再加多少。$w,b$ 合称参数，是训练要调整的数字。真实答案记为 $y$。帽子用来区分“猜的值”和“给定的答案”。

现在令 $x=2,y=5,w=1,b=0$。模型预测 $\widehat y=1\times2+0=2$，与答案相差 $2-5=-3$。这里的“模型”就是一条带可调参数的函数，不需要先把它想成有理解能力的主体。

问题是：怎样根据猜错的程度调整参数？直接把答案存下来也能对这一个输入答对，但我们希望学习一个规则，后来换输入也能使用。这是后面训练集、验证集要分开的原因。

## 2. 损失把“猜得多差”变成一个数字

定义损失（代码里叫 `loss`）：

$$L=\frac12(\widehat y-y)^2.$$

减法得到误差，平方让正负误差都变成非负数，前面的 $1/2$ 使后续导数更简洁。本例 $L=\tfrac12(2-5)^2=4.5$。预测正好是 5 时损失为 0；预测为 4 或 6 时损失都是 0.5。

损失是设计出来的优化目标，不是世界上唯一的正确标准。回归可以用平方误差，分类常用交叉熵；后训练中的偏好、正确率又有不同目标。今天先固定这一个，理解“算出一个标量，再设法让它下降”。

## 3. 梯度告诉我们，哪个方向会让损失上升

导数描述变量发生微小变化时结果怎样变化。“对 $w$ 的偏导数”写成 $\partial L/\partial w$，意思是先固定其他变量，只考察改变 $w$ 的影响。把预测公式代进损失，利用链式法则：

$$\frac{\partial L}{\partial w}=(wx+b-y)x=(-3)\times2=-6,$$

$$\frac{\partial L}{\partial b}=wx+b-y=-3.$$

为什么多一个 $x$？因为 $w$ 增加一点点，预测增加的是这点变化乘 $x$；$b$ 增加一点点，预测就增加同样多。这里的负导数表示：在当前位置把参数略微增大，会让损失下降。它不是在说“负梯度意味着计算错了”。

如果尚未学导数，可以先用微小扰动理解方向：固定 $b=0$，把 $w$ 从 1 改为 1.01，预测从 2 变为 2.02，离 5 更近，损失从 4.5 变成 4.4402。有限差分估计 $(4.4402-4.5)/0.01=-5.98$，已接近导数 -6。自动微分会沿计算图使用解析导数规则，不需要每个参数都这样试探。

## 4. 学习率决定往这个方向迈多大一步

学习率记为 $\eta$，本例取 0.1。梯度下降的“下降”体现在减号：

$$w_{\text{新}}=w-\eta\frac{\partial L}{\partial w}=1-0.1\times(-6)=1.6,$$

$$b_{\text{新}}=b-\eta\frac{\partial L}{\partial b}=0-0.1\times(-3)=0.3.$$

两个导数都在旧参数位置算好，再一起更新。新预测是 $1.6\times2+0.3=3.5$，新损失是 $\tfrac12(3.5-5)^2=1.125$，比 4.5 小。一次学习完整经过：输入 → 预测 → 损失 → 梯度 → 更新参数。

学习率大不一定好。若把它改成 0.5，新参数为 $w=4,b=1.5$，预测 9.5，损失 10.125，反而变差。导数只提供当前位置的局部方向，有限的一大步可能跨过低损失区域。

## 6. 从预测一个数，转向给候选答案分配概率

如果任务是选 A 或 B，模型通常先输出两个任意实数，称为分数 `logits`，再转换成概率。取分数 $[0,\ln3]$。这里 $\ln$ 是自然对数，$\exp$ 是它的反函数，所以 $\exp(0)=1,\exp(\ln3)=3$。

Softmax 的计算是先指数，再除以指数总和：

$$p_A=\frac1{1+3}=0.25,\qquad p_B=\frac3{1+3}=0.75.$$

两个概率之和为 1。若真实答案是 B，常用损失为 $-\ln p_B=-\ln0.75\approx0.287682$。把正确答案的概率从 0.75 提高到 0.9，损失就下降到约 0.105361。负对数不是额外打分模型，只是把“正确答案概率应提高”写成便于优化的损失。

语言模型把这件事重复到每个位置。token 是文本编码后的一个单位，可能是字、词或词的一部分；暂时把它理解为模型逐个预测的符号。假设一段回答有三个 token，模型在各自前缀下给实际目标 token 的条件概率为 0.8、0.5、0.25，序列概率为 $0.8\times0.5\times0.25=0.1$。取对数后，乘法变成加法：

$$\log p(\text{回答})=\ln0.8+\ln0.5+\ln0.25\approx-2.302585.$$

这里乘的是依次给定前缀的条件概率，不是假设三个 token 彼此独立。对三个位置平均的负对数损失是 $2.302585/3\approx0.767528$。后面的 SFT 与 DPO 会反复使用这些量。

## 7. 从“猜答案”再走一步：选择会影响未来

假设有两个选择：立即结束得 1 分；或者先付出 0.2 分，然后下一步得到 2 分。若把下一步收益按 0.9 倍计入，第二个选择的回报是 $-0.2+0.9\times2=1.6$，因此更有利。

单看第一步奖励 -0.2，会选错。强化学习要考虑行动造成的未来结果；这里的折扣 0.9 用来定义如何权衡不同时间的收益。它在更一般的无限时域模型中还有数学作用，后面再讲。这一课先分清即时奖励和累计回报。

现在你已经见过项目的共同语言：模型给出预测或行动；损失、奖励或偏好提供学习信号；算法用这些信号改变参数；评测检查变化是否真的有用。

## 8. 四道完整自测与面试问答

### 题 1：手算一次梯度下降，解释学习率的作用

**题目：**只有一条训练样本，输入 $x=2$、目标 $y=5$。模型为 $\widehat y=wx+b$，初始权重 $w=1$、偏置 $b=0$，损失为 $L=\tfrac12(\widehat y-y)^2$。取学习率 $\eta=0.05$，在初始参数处计算两个梯度，再同时执行一次 $w\leftarrow w-\eta\,\partial L/\partial w$、$b\leftarrow b-\eta\,\partial L/\partial b$。请依次给出更新前预测与损失、梯度、更新后参数、预测与损失，并解释为什么沿负梯度更新。

**参考答案：**更新前 $\widehat y=2$、$L=4.5$。误差为 $-3$，故 $\partial L/\partial w=(-3)\times2=-6$、$\partial L/\partial b=-3$。两个梯度都在旧参数处计算，得到 $w_{new}=1-0.05(-6)=1.3$、$b_{new}=0-0.05(-3)=0.15$。新预测为 $1.3\times2+0.15=2.75$，新损失为 $\tfrac12(2.75-5)^2=2.53125$。梯度给出局部最陡上升方向，因此最小化损失时沿其反方向迈步。

**面试追问：**学习率越大，损失下降一定越快吗？

**追问回答：**不一定。仍从 $w=1,b=0$ 出发，若 $\eta=0.5$，一次更新得到 $w=4,b=1.5$、预测 9.5、损失 10.125，超过初始 4.5。负梯度描述局部方向，有限的一大步可能越过低损失区域。

### 题 2：解释分类交叉熵与正确类别概率

**题目：**某分类样本有一个确定的真实类别。模型对这个真实类别分配的概率，更新前为 $p=0.5$，更新后为 $p=0.25$。本题单样本交叉熵定义为 $L=-\ln p$，$\ln$ 为自然对数，不含额外类别权重。请计算两次损失及变化量，并说明损失变化是否表示模型对这个样本变好。

**参考答案：**更新前损失为 $-\ln0.5=\ln2\approx0.693147$；更新后为 $-\ln0.25=\ln4\approx1.386294$；增加约 0.693147。模型给真实类别的概率降低，所以在这个样本上变差。交叉熵使用负对数，概率越小，损失越大。

**面试追问：**模型输出的 logits 是概率吗？为什么交叉熵通常接收 logits？

**追问回答：**Logits 是归一化之前的任意实数分数；softmax 将它们转换为总和为 1 的类别概率。框架可把 log-softmax 与负对数似然合并，用稳定的数值计算得到损失，因此使用接收 logits 的接口时应直接传原始分数。

### 题 3：区分序列概率、对数概率与 token 平均损失

**题目：**一个回答恰有三个有效 token，即模型逐个预测的三个文本单位，没有提示或补齐位置参与计分。给定提示以及各自此前 token 后，模型对这三个实际 token 的条件概率依次为 $0.8,0.5,0.25$。使用自然对数。请计算整个回答的概率、整个回答的 log-prob（对数概率）和有效 token 平均负对数损失，并回答最后一个量能否直接代替 log-prob。

**参考答案：**序列概率由概率链式法则得到 $0.8\times0.5\times0.25=0.1$；序列 log-prob 为 $\ln0.1\approx-2.302585$；平均负对数损失为 $-\ln0.1/3\approx0.767528$。后两者符号不同，而且平均损失多除以 3，不能直接互换。本题给出的是依次条件概率，不需要假设 token 相互独立。

**面试追问：**比较长短回答时，按 token 求和和按 token 平均有什么区别？

**追问回答：**求和表示整段序列的对数概率，平均表示每个有效 token 的平均损失。回答长度不同，二者会产生不同权重和排序；训练与评测都要说明归约方式。平均损失更低，并不直接表示整段回答更正确。

### 题 4：区分即时奖励、折扣回报与最优选择

**题目：**一个确定性任务有两个选择：A 立即得到奖励 1 并终止；B 第一步得到奖励 $-0.2$，第二步得到奖励 2 后终止，没有其他奖励。两步回报定义为 $G=r_1+\gamma r_2$，$\gamma$ 是折扣因子。取 $\gamma=0.5$，分别计算 A、B 的回报并选较优者；再求两者一样好时的折扣阈值。

**参考答案：**A 的回报为 1；B 的回报为 $-0.2+0.5\times2=0.8$，所以选 A。解 $1=-0.2+2\gamma$ 得阈值 $\gamma=0.6$；大于 0.6 时 B 更好，小于时 A 更好，恰为 0.6 时两者同优。B 第一步的即时奖励是 $-0.2$，0.8 是整条路线的折扣回报。

**面试追问：**折扣因子只是为了让程序收敛而加的吗？

**追问回答：**它先定义优化目标中未来收益的权重，会改变最优策略。在无限时域且奖励有界时，取折扣小于 1 还可保证折扣和有界，并使 Bellman 算子具有压缩性质；这些数学条件不能替代对任务目标的选择。
