# RNN：理解序列状态、梯度与 Attention 的起点

**想做完整自测或准备面试，打开 [各专题题目索引](../references/面试复习与题目索引.md)。** 题目均给出完整条件、参考答案、常见追问与回答；基础讲解、手算与实验排错按专题连接。

读一串词时，我们需要记住前面发生了什么。循环神经网络（RNN）把刚读到的输入和上一时刻的**隐藏状态**结合，形成新的隐藏状态；它是模型内部保存的历史摘要。先在 [从零上手](从零上手.md) 里手推三步，再看 [梯度、门控与注意力](chapters/01_梯度传播_门控与注意力的起点.md)：历史太长时，梯度要穿过许多步，门控试图保留重要信息，注意力则提供从当前词回看相关位置的路径。三个概念按这个问题顺序出现。

第一次接触序列模型，先读 [激活与序列模型补课](../入门/激活与序列模型补课.md)，算完三步状态递推和两步导数，再读下面的笔记。

原有 [RNN 基础笔记](RNN.md) 保留作术语和变体查阅；第一次阅读以[从零上手](从零上手.md)为主，随后读[梯度、门控与注意力](chapters/01_梯度传播_门控与注意力的起点.md)补公式成立的条件和通向 Transformer 的问题链。

学习目标是解释隐藏状态怎样压缩历史、BPTT 怎样复用同一组参数、梯度乘积何时衰减，以及 attention 为什么提供了另一种信息路径。第 1 月投入一到两个学习单元即可，无需先复现所有 RNN 变体。

| 参考 | 对应问题 | 验收 |
| --- | --- | --- |
| [D2L 第 9 章](https://d2l.ai/chapter_recurrent-neural-networks/index.html) | RNN 与 BPTT | 展开三步计算图，列出共享参数的梯度贡献 |
| [D2L 第 10 章](https://d2l.ai/chapter_recurrent-modern/index.html) | GRU、LSTM、seq2seq | 区分状态保留与候选状态写入 |
| [Bahdanau attention](https://arxiv.org/abs/1409.0473) | 翻译中的动态对齐 | 解释 query 与源端状态分别来自哪里 |

通过后进入 [Transformer](../transformer/README.md)。保留 RNN 的状态视角，它也帮助理解 [Agent 历史与部分可观测性](../agentic_rl/README.md)，但神经网络有隐藏状态不自动保证它学到了环境的 Markov 状态。
