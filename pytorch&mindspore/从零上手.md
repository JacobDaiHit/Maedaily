# 从零上手：亲手算清一次参数更新

这一课只解决一个问题：**程序怎样根据一个错误预测，修改两个数字，让下一次预测更接近答案？** 不要求先会神经网络，也不用先读英文教材。准备纸笔，把本页的数字算一遍，再运行代码；看到同样的结果，才算打通数学与程序。正文的例子只在 CPU 上运行。

## 2. 从列表到张量：先给每个轴起名字

Python 列表可以写成 `[2.0, 3.0]`。它保存两个对象，但没有规定机器学习含义。`torch.tensor` 把数值组织成张量：它记录数据、形状、数值类型和设备，并支持批量数值计算。此处“张量”先理解为带轴的数值数组，不必先学抽象张量代数。

```python
import torch

a = torch.tensor([2.0, 3.0], dtype=torch.float64)
X = torch.tensor([[2.0], [3.0]], dtype=torch.float64)
print(a.shape)       # torch.Size([2])
print(X.shape)       # torch.Size([2, 1])
print((X * 2).tolist())  # [[4.0], [6.0]]
```

`shape` 是每个轴的长度。约定输入形状为 `[B,d]`：`B` 是一次处理的样本数，叫批量大小；`d` 是每个样本的特征数。上面的 `X` 有两条样本，每条只有一个输入数字，因此 `B=2,d=1`。若每条样本记录身高、体重两个量，`d` 才是 2；样本数和特征数不能混为一谈。

`[2]` 和 `[2,1]` 含有相同数量的数字，但轴不同。尤其要小心广播：形状 `[2,1]` 的预测减去 `[2]` 的标签，可能变成 `[2,2]`，每个预测都与两个标签相减。程序未必报错，目标却已经错了。第一条排错习惯是同时打印预测和标签的 `shape`。

`float64` 表示每个数用 64 位浮点数存储，适合本课核对小数。`device` 指数据放在 CPU 还是 GPU。后面语言模型的 token 编号通常是整数，参数通常是浮点数；编号不需要求导，参数才需要。类型、设备、是否记录梯度是三个不同属性。

## 3. 前向：把当前参数变成预测与损失

训练样本为输入 $x=2$、目标 $y=5$。选择模型

$$\hat y=wx+b,$$

其中 $w$ 是权重，控制输入增加时预测怎样变化；$b$ 是偏置，负责整体平移。二者是要学习的参数，$x,y$ 是本次给定的数据。先设 $w=1,b=0$，于是预测 $\hat y=2$。

定义误差 $e=\hat y-y$，本例 $e=-3$。损失使用半平方误差：

$$L=\tfrac12(\hat y-y)^2=\tfrac12(-3)^2=4.5.$$

损失不是预测结果本身，而是评价预测偏离目标的一个标量。平方使正负误差都产生非负代价；前面的 $1/2$ 是本课明确选择的系数，便于导数消去 2。PyTorch 的普通均方误差默认没有这个 $1/2$，不能拿不同定义的数字直接比较。

从 $x,w,b$ 算到预测，再算到损失，称为前向计算。计算图可以写成：`w,x → 乘法 → 加b → 减y → 平方再除2`。此时只是计算了“当前做得怎样”，参数还没有改变。

## 4. 反向与更新：两个动作分开理解

反向传播按链式法则计算损失对参数的导数。先看损失对预测的变化率，再乘预测对参数的变化率：

$$\frac{\partial L}{\partial\hat y}=\hat y-y=-3,\qquad
\frac{\partial\hat y}{\partial w}=x=2,\qquad
\frac{\partial\hat y}{\partial b}=1.$$

所以 $\partial L/\partial w=-6$，$\partial L/\partial b=-3$。负号说明在当前点附近，适当增大参数会让损失下降。梯度描述的是当前参数附近的局部变化，不保证跨出任意大的一步仍然改善。

选择学习率 $\eta=0.1$，它控制每次沿负梯度走多远。最基本的梯度下降更新为

$$w_{\mathrm{new}}=1-0.1(-6)=1.6,\qquad
b_{\mathrm{new}}=0-0.1(-3)=0.3.$$

用新参数重新前向，预测为 $1.6\times2+0.3=3.5$，新损失为 $\tfrac12(3.5-5)^2=1.125$。**求出梯度是反向，修改参数是更新。** `backward()` 完成前者，优化器的 `step()` 完成后者；不能把它们当作同一个命令。

这里只有一条样本，所有满足 $2w+b=5$ 的参数都能把它拟合好。因此即使损失最终为零，也不能从这一个点判断学到了唯一规律。要检验其他输入，必须增加独立数据。

## 5. 完整短程序：让每个数字对应到代码

下面程序已在本机上述解释器中执行核对。在编辑器新建 `D:/github_book/Maedaily/first_update.py`，粘贴程序并保存，再运行 `& 'D:/anaconda/envs/pytorch_env/python.exe' 'D:/github_book/Maedaily/first_update.py'`。这个文件由你练习时创建，不需要下载数据。`Linear(1,1)` 创建“一个输入特征、一个输出数字”的模型，它保存本例的 $w,b$。

```python
import math
import torch

torch.set_num_threads(1)
model = torch.nn.Linear(1, 1, dtype=torch.float64)
with torch.no_grad():
    model.weight.fill_(1.0)
    model.bias.zero_()

x = torch.tensor([[2.0]], dtype=torch.float64)
y = torch.tensor([[5.0]], dtype=torch.float64)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

model.train()
optimizer.zero_grad(set_to_none=True)
prediction = model(x)
loss = 0.5 * (prediction - y).square().mean()
print("before:", prediction.item(), loss.item())
loss.backward()
print("grad:", model.weight.grad.item(), model.bias.grad.item())
assert math.isclose(model.weight.grad.item(), -6.0)
assert math.isclose(model.bias.grad.item(), -3.0)
optimizer.step()

model.eval()
with torch.no_grad():
    new_prediction = model(x)
    new_loss = 0.5 * (new_prediction - y).square().mean()
    x_val = torch.tensor([[3.0]], dtype=torch.float64)
    y_val = torch.tensor([[7.0]], dtype=torch.float64)
    val_prediction = model(x_val)
    val_loss = 0.5 * (val_prediction - y_val).square().mean()
print("parameters:", model.weight.item(), model.bias.item())
print("after:", new_prediction.item(), new_loss.item())
print("validation:", val_prediction.item(), val_loss.item())
assert math.isclose(new_prediction.item(), 3.5)
assert math.isclose(new_loss.item(), 1.125)
assert math.isclose(val_loss.item(), 1.805)
```

输出中的关键数字依次是 `before: 2.0 4.5`、`grad: -6.0 -3.0`、参数约 `1.6 0.3`、`after: 3.5 1.125`。浮点显示可能把 0.3 写成 `0.30000000000000004`，这不意味着算法不同，所以检查用带容差的 `isclose`。

验证点 $x=3,y=7$ 是另给的一条教学数据，符合教师设定的 $y=2x+1$；它没有参与这次更新。新模型预测 5.1，半平方误差为 1.805。这个数字说明当前模型在该点的表现；只检查一个验证点，仍不能作全面泛化结论。

## 6. 把单步变成训练循环

真实训练重复六件事：取一批数据，清理旧梯度，计算预测与损失，反向计算当前梯度，按优化器规则更新参数，定期用未训练的数据验证。训练步数是更新次数；一轮完整遍历训练集叫一个 epoch。小批次随机抽样时，两者不是同一个计数。

为什么清零？PyTorch 通常把新求得的梯度加到参数已有的 `.grad` 上。若在相同参数处重新前向同一样本并反向两次，未清零时 $w$ 的梯度会累加成 $-12$。这是支持梯度累积的机制；本课每步只要当前批次的梯度，因此先清理。`zero_grad` 清的是梯度缓冲区，不会把已经学到的权重清成零。

`model.train()` 与 `model.eval()` 控制某些层的训练 / 评估行为，例如 dropout；`torch.no_grad()` 控制是否为自动微分记录计算。这两组功能互不替代。眼前的单个线性层没有 dropout，所以切模式不会改变数值；仍保留这套写法，便于后面迁移到复杂网络。验证阶段不调用 `backward()` 和 `step()`。

自动微分不是有限差分：它利用已执行运算的导数和链式法则。有限差分另外把参数加减一个很小量，用两次损失估计导数，适合小例子验算；参数太多时不能把它当作日常训练方法。

第一次读训练程序时，可以在纸上画四个框：数据框保存输入与标签，模型框保存可调整参数，损失框把预测压成一个数，优化器框按梯度修改参数。数据框提供的是学习材料；优化器并不自己知道答案，它只拿到程序定义的损失产生的梯度。因此标签写错、误把不同样本相减时，框架仍可能非常认真地优化这个错误目标。

同一批数据做第二步，也要使用更新后的参数重新前向。不能拿第一步保存的 `loss` 反复 `backward()` 就当作正常训练；旧计算图描述的是旧参数处的计算，框架还可能已经释放了反向需要的中间值。初学时每轮重新写清“前向—反向—更新”，比调整保留计算图选项更可靠。

## 7. 从一条样本扩展到一批样本

设两个输入特征都参与预测：$\hat y=w_1x_1+w_2x_2+b$。取 $w_1=2,w_2=-1,b=1$，输入矩阵与标签分别为

$$X=\begin{bmatrix}1&3\\2&4\end{bmatrix},\qquad y=\begin{bmatrix}1\\0\end{bmatrix}.$$

第一行预测 $2\times1-3+1=0$，第二行预测 $2\times2-4+1=1$。所以预测向量是 $[0,1]^\top$，误差为 $[-1,1]^\top$。当批量大小 $B=2$ 时，平均半平方损失为

$$L=\frac{1}{2B}\sum_{i=1}^B e_i^2=\frac14(1+1)=0.5.$$

这里的 $1/2$ 来自单条损失定义，$1/B$ 来自批次平均，二者含义不同。权重梯度是各样本“误差乘该特征”的平均：$\partial L/\partial w_1=(-1\times1+1\times2)/2=0.5$；第二个权重梯度同样是 0.5；偏置梯度为 $(-1+1)/2=0$。两个样本对偏置的要求抵消，并不意味着每个样本都预测正确。

矩阵写法就是 $\nabla_wL=X^\top e/B$。乘法形状为 `[d,B] @ [B,1] → [d,1]`。本课先把数学权重写成列向量；`torch.nn.Linear` 内部把多个输出的权重按行保存，所以实际计算用输入乘内部权重的转置。一个输出、两个特征时，内部 `weight.shape` 是 `[1,2]`，不应仅凭和纸上形状不同就判定代码错误。

批次平均也解释了为什么换 batch size 后不一定要把学习率按相同比例改动：若样本完全相同，平均梯度不会因复制样本而改变；若样本不同，平均梯度的噪声会变化。更大批次的最优学习率属于需要验证的训练选择，不能靠“样本翻倍所以步子翻倍”直接决定。

## 9. 遇到报错，先缩小到这一层

| 现象 | 先检查什么 | 可以采取的动作 |
| --- | --- | --- |
| `No module named torch` | 当前解释器是不是预期环境 | 用上面的绝对路径启动，不先反复安装 |
| 矩阵乘法形状不匹配 | `B` 与 `d` 有没有交换 | 打印输入、权重、标签形状，逐轴解释 |
| `.grad` 为 `None` | 是否对参数相关的 loss 反向了 | 检查 `backward()`，避免训练前向放进 `no_grad` |
| loss 变成普通 Python 数字 | 是否过早使用 `.item()` | 用张量求导，仅在打印时取普通数值 |
| loss 突然变大 | 标签、归约和学习率是否改变 | 恢复单样本已知参数，重新手算一轮 |

不要把所有问题归结为 GPU。上面的代码在 CPU 上就能检验参数、梯度和更新是否连通；只有机制正确后，测算设备成本才有意义。

## 10. 练习与完整答案

**练习一：**三条样本、每条两个特征，输入形状是什么？**答案：**`[3,2]`。若每条预测一个数，预测和标签统一成 `[3,1]`，不要把标签压成 `[3]` 后直接相减。

**练习二：**初始参数不变，把学习率改为 0.5，一次更新后怎样？**答案：**梯度仍为 $(-6,-3)$，新参数为 $(4,1.5)$，预测 $9.5$，损失 $\tfrac12(9.5-5)^2=10.125$，比原来的 4.5 更大。方向正确，步子也可能太大。

**练习三：**若损失去掉 $1/2$，能否照用上面的梯度？**答案：**不能，梯度变成 $(-12,-6)$。若想让本次参数变化与原例相同，需要把学习率减半到 0.05。

**练习四：**第一步后忘清零，再用同一点计算第二步，会怎样？**答案：**当前误差为 $-1.5$，本应产生新梯度 $(-3,-1.5)$；若旧梯度仍是 $(-6,-3)$，缓冲区变为 $(-9,-4.5)$。这不是第二步目标本身的正确梯度。

**练习五：**验证损失进入 `backward()` 再更新，还能称作独立验证吗？**答案：**不能，这些标签已用于参数学习。验证集可用于选择配置，但仍应另保留最终测试集，避免反复围绕验证结果调参后高估效果。

建议把这一课分成两次学习。第一次只做到第 5 节：在运行前写下输出预期，运行后检查每个数字来自哪一步。第二次先把学习率改成 0.5，在纸上预测它会变差，再核对结果；恢复 0.1 后，把一条样本改为第 7 节的两条样本，检查平均损失与梯度。一次只改一个条件，才能知道差异来自哪里。

改为 0.5 时，也要把第 5 节最后三条断言的预期值依次改为 `9.5`、`10.125`、`21.125`：新验证预测是 $4\times3+1.5=13.5$，验证损失为 $\tfrac12(13.5-7)^2=21.125$。前面的梯度仍在相同旧参数处计算，所以梯度断言不改。断言是针对指定配置的预期，不是所有学习率共用的答案。恢复默认学习率时同步恢复默认预期值。

自己的学习记录至少写三句话：我改了什么；按公式预计会发生什么；程序是否符合预期。若不符合，先保存实际形状、输入和输出，再定位最早出现差异的运算。只把运行成功截图存下来，很难在下一次遇到广播或梯度错误时复用经验。
