# 第 1 章　张量、广播与自动微分

训练代码最危险的错误不一定报异常：两个形状不匹配的数组可能被自动广播，程序顺利运行，却优化了另一个目标。本章先给每个轴赋予含义，再把链式法则落实到程序。前置是矩阵乘法与多元微分；不要求已经熟悉框架。

先做[短程序的形状实验](../短程序实验.md)：三个预测值与三个标签，本来应得到三个差；因为一个是 `[3,1]`、另一个是 `[3]`，程序却算出九个差。**形状**就是每个轴有多少位置；**广播**是框架按规则复制较短的轴，使两个数组能计算。先能解释“为什么九个”，再看本章的 $[B,d]$ 记号，其中 $B$ 是样本数、$d$ 是每个样本的特征数。

## 1.1 数组的形状也是模型定义

设一个批次有 $B$ 个样本，每个样本 $d$ 个特征。输入矩阵 $X\in\mathbb R^{B\times d}$、权重向量 $w\in\mathbb R^d$、标量偏置 $b$ 定义预测 $\hat y=Xw+b\mathbf1$，其中 $\mathbf1\in\mathbb R^B$。框架中的 tensor 是带形状、数据类型、设备与存储信息的多维数组；这里不需要预设抽象张量代数。

`[B,d]` 的第一轴是样本，第二轴是特征。`nn.Linear(d,1)` 通常返回 `[B,1]`，而自己写 `X @ w` 可以返回 `[B]`。二者的数值语义可以相同，但后续与标签相减时必须统一形状。`reshape` 改变元素如何分组，`transpose` 交换轴；它们不能因为元素总数相等就任意互换。

## 1.2 广播是隐式复用，不是智能配对

广播从末尾对齐各维：对应长度相同、某一方为 1，或某一方缺失该维，才能扩展。`[B,d]+[d]` 把同一个特征偏置用于所有样本，这是合理的共享；`[B,1]-[B]` 却得到 `[B,B]`，比较了所有样本之间的交叉差。[PyTorch 2.7 广播文档](https://docs.pytorch.org/docs/2.7/notes/broadcasting.html)给出了精确规则。

```python
import torch
pred = torch.tensor([[1.0], [2.0], [3.0]])  # [3,1]
target = torch.tensor([1.0, 2.0, 3.0])     # [3]
wrong = ((pred - target) ** 2).mean()     # 4/3，悄悄变成 [3,3]
right = ((pred[:, 0] - target) ** 2).mean()  # 0
```

所以形状断言应表达语义，例如 `assert pred.shape == target.shape`。看到 loss 有限或下降，并不能证明数据按预期配对。

## 1.3 反向传播计算的是向量–雅可比积

第一次阅读先回[短程序的梯度实验](../短程序实验.md)：输入 2、目标 5，手算得权重梯度 $-6$、偏置梯度 $-3$，PyTorch 打印出相同结果。下面的**雅可比矩阵**只是把“多个输出分别对多个输入求导”排成表；标量损失的反向传播最终仍在回答“每个参数改一点，损失会怎样变”。

设 $f:\mathbb R^n\to\mathbb R^m$ 可微，雅可比矩阵 $J_f$ 的第 $(i,j)$ 项是 $\partial f_i/\partial x_j$。对输出端给定权重向量 $v\in\mathbb R^m$，反向传播计算 $J_f(x)^\top v$。若最终输出是标量损失 $L$，取 $v=1$，就得到所有输入参数的梯度。它利用程序中各局部运算的导数与链式法则，不是逐参数扰动的数值微分。

取 $z=wx+b$、$L=\tfrac12(z-y)^2$。令 $x=2,y=5,w=1,b=0$，则 $z=2$，上游梯度 $\partial L/\partial z=-3$，从而 $\partial L/\partial w=-6$、$\partial L/\partial b=-3$。若同一参数影响多条计算路径，来自各路径的梯度必须相加；广播共享的偏置梯度也会沿被扩展的样本维求和。

对于整批均方损失 $L=B^{-1}\|Xw+b\mathbf1-y\|_2^2$，记残差 $e=Xw+b\mathbf1-y$，则

$$
\nabla_w L=\frac2B X^\top e,\qquad
\frac{\partial L}{\partial b}=\frac2B\mathbf1^\top e.
$$

这两个公式是本册实验的独立参照，不用另一个 autograd 调用证明 autograd 正确。

## 1.4 计算图何时被保留、何时被切断

PyTorch eager 模式按实际执行的前向运算建立求导记录；`loss.backward()` 把叶子参数的梯度累加到 `.grad`，不会自动调用优化器。`detach()` 切断这条求导联系，`.item()` 把单元素张量变成 Python 数值。它们适合记录日志，却不应被无意放到损失计算的关键路径上。`model.eval()` 改变 Dropout 等模块行为，不等于关闭梯度；验证时通常同时使用 `torch.no_grad()`。[Autograd 官方说明](https://docs.pytorch.org/docs/2.7/notes/autograd.html)区分了这些机制。

普通训练不需要每步设置 `retain_graph=True`。反向传播完成后释放本步保存的中间量，有助于控制内存；把带图的 loss 持续放入列表可能延长计算图生命周期。需要高阶导数时才进一步讨论 `create_graph`，不要为了消除报错随意打开所有保留选项。

## 1.5 有限差分作为独立检查

对标量函数 $L(\theta)$ 和参数第 $j$ 维单位向量 $e_j$，中心差分是

$$
g_j^{FD}=\frac{L(\theta+he_j)-L(\theta-he_j)}{2h}.
$$

足够光滑时截断误差为 $O(h^2)$，但浮点消减误差会随 $h$ 太小而放大。因此“步长越小越准”不成立；用 float64、避开不可微点，尝试几个步长。梯度校验只能覆盖测试的运算与点，不是整个模型永远正确的证明。

## 1.6 项目 A 的对应关系与练习

语言模型中输入 token IDs 为 `[B,T]`，隐藏状态为 `[B,T,d]`，输出 logits 为 `[B,T,V]`，其中 $T$ 是序列长度、$V$ 是词表大小。轴的语义决定 softmax 沿词表维、loss 沿有效 token 归约；这比先背 API 更重要。

1. `[2,1,4]+[3,4]` 得到什么？提示：末尾对齐后为 `[2,3,4]`。
2. 损失从样本求和改成均值，梯度怎样变？提示：相同批次下除以 $B$，学习率解释也随之改变。
3. 上述标量例子重复构建前向并 backward 两次但不清零，`w.grad` 是多少？提示：累积为 -12；同一图直接重复反向另有图释放问题。
