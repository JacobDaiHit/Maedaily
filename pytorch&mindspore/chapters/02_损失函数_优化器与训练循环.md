# 第 2 章　损失函数、优化器与训练循环

“能调用 backward”只完成了训练的一部分。我们还要确认损失对应什么统计问题、每个样本如何加权、优化器怎样改变参数，以及验证是否在独立数据上进行。本章从线性回归走到语言模型交叉熵，搭建第 1 月项目 A 可复用的训练结构。

继续用上一章的标量例子：输入 2、目标 5、当前预测 2，平方误差能告诉我们“错了多少”，梯度能告诉我们“参数怎样改”。但训练还要决定多条样本怎样平均、每次更新走多远、何时用未参与训练的数据检查结果。下面按这个顺序把一次参数更新扩展为训练循环。

可先运行[短程序的梯度与三点拟合](../短程序实验.md)。梯度实验只更新一次，拟合实验把“清梯度 → 前向 → 损失 → 反向 → 更新”重复 200 次。代码打印第 0、20、200 步，让“训练循环”成为可观察的过程，再看交叉熵和优化器如何改变其中一环。

## 2.1 损失定义了你在拟合什么

线性回归假设 $y_i=x_i^\top w+b+\varepsilon_i$，其中 $\varepsilon_i$ 为独立、同方差、零均值高斯噪声。固定噪声方差后，负对数似然与平方误差只差正比例因子和常数，因此最小二乘可以解释为最大似然估计。没有这些假设也能用平方损失，但那时应把它解释为选定的误差度量，不能自动套用高斯统计结论。

分类则定义 logits $z\in\mathbb R^V$，$V$ 是类别数。归一化概率 $p_k=e^{z_k}/\sum_j e^{z_j}$，真实类别为 $y$ 时，交叉熵为

$$
\ell(z,y)=-\log p_y=-z_y+\log\sum_{j=1}^V e^{z_j},\qquad
\frac{\partial\ell}{\partial z_k}=p_k-\mathbf1\{k=y\}.
$$

若两个 logits 都为 0，真实类别是第一个，概率各为 0.5，损失是 $\log2$，梯度为 $[-0.5,0.5]$。更新增加真实类别与另一类别之间的差距。数值实现通常采用稳定的 log-sum-exp；PyTorch 的 `CrossEntropyLoss` 接收 logits，通常不应先 softmax 再传入。[2.7 官方定义](https://docs.pytorch.org/docs/2.7/generated/torch.nn.CrossEntropyLoss.html)同时区分整数标签与概率标签。

## 2.2 语言模型先移位，再确定有效位置

自回归语言模型要由前缀预测下一个 token。若序列为 `[a,b,c,d]`，可以把 `[a,b,c]` 作为输入、`[b,c,d]` 作为标签。某些模型接口内部完成移位，自己再移一次就错位；必须检查接口而不是套模板。

令 $m_{it}\in\{0,1\}$ 表示第 $i$ 条序列第 $t$ 个目标是否参与监督，则有效 token 平均损失为

$$
L=\frac{\sum_{i,t}m_{it}\ell_{it}}{\sum_{i,t}m_{it}}.
$$

分母必须大于零。padding 不应贡献 loss，SFT 中提示词是否受监督由训练方案明确规定。两条序列分别有 2 和 8 个有效 token 时，按 token 平均会让后者占更大权重；先各自平均再对序列平均则让两条序列同权。这是目标选择，不是无关紧要的代码差异。

## 2.3 优化器处理的是梯度与状态

最简单的 SGD 更新为 $\theta_{t+1}=\theta_t-\eta_tg_t$，其中 $\theta_t$ 是参数向量、$g_t$ 是当前梯度估计、$\eta_t>0$ 是学习率。带动量更新使用 $v_t=\mu v_{t-1}+g_t$、$\theta_{t+1}=\theta_t-\eta_tv_t$，$\mu\in[0,1)$ 控制历史梯度的保留。恢复训练只加载参数、不加载 $v_t$，下一步通常就不再相同。

Adam 使用梯度的一阶和逐元素二阶滑动平均，并进行偏差校正；AdamW 把权重衰减与自适应梯度步骤解耦。SGD 中 L2 正则与某些衰减写法可等价，但这种等价不能不加条件搬到自适应优化器上。[AdamW 官方算法](https://docs.pytorch.org/docs/2.7/generated/torch.optim.AdamW.html)用于核对实现，本册线性实验用 SGD，避免同时引入过多状态。

## 2.4 一次训练步骤怎样闭合

以下是供已有模型与批次使用的 PyTorch 2.7 训练骨架；变量 `model`、`optimizer`、`x`、`target`、`loss_fn` 需由任务定义，完整可运行文件在实验目录。

```python
model.train()
optimizer.zero_grad(set_to_none=True)
prediction = model(x)
assert prediction.shape == target.shape
loss = loss_fn(prediction, target)
if not torch.isfinite(loss):
    raise RuntimeError("non-finite loss")
loss.backward()
optimizer.step()

model.eval()
with torch.no_grad():
    validation_loss = loss_fn(model(x_valid), y_valid)
```

顺序具有因果意义：先清除上一轮梯度，再前向建立本轮图，反向计算本轮梯度，最后更新参数。若有梯度裁剪，应在反向之后、更新之前；混合精度时还需按框架规则先恢复真实梯度尺度。梯度累积是有意跨微批保留梯度，并按总有效样本权重缩放，不是简单忘记清零。

## 2.5 哪些指标能回答哪些问题

训练 loss 下降表示拟合训练目标有进展；验证 loss 检查相同任务分布下未参与更新的数据。两者都不能单独证明输出正确、无数据泄漏或目标符合需求。对语言模型还应固定生成提示与解码参数，观察输出；对线性实验则比较已知解析参数和新输入点的预测误差。

常见失败包括：标签 dtype 或索引错误，输出 `[B,1]` 与标签 `[B]` 广播，先把 loss 转 Python 数值再反传，以及优化器没包含新增参数。初始化 loss 约等于 $\log V$ 只适用于近似均匀词表预测等条件，是有用诊断量而非所有语言模型的定律。

## 2.6 深入：曲率、AdamW 状态与大批次等价

### 交叉熵的一阶与二阶结构

由 $\log p_y=z_y-\log\sum_ke^{z_k}$，逐坐标求导得到 $p_k-\mathbf1\{k=y\}$。再用 $\partial p_i/\partial z_j=p_i(\mathbf1\{i=j\}-p_j)$，可得 Hessian（梯度的 Jacobian）为

$$
H=\operatorname{diag}(p)-pp^\top.
$$

对任意向量 $u$，$u^\top Hu=\sum_kp_ku_k^2-(\sum_kp_ku_k)^2\ge0$，它是按概率 p 计算的方差，所以交叉熵关于 logits 是凸函数。共同平移 logits 不改变概率，对应 $H\mathbf1=0$。这不证明多层网络关于参数也凸：logits 是参数的非线性函数，复合后的目标具有不同结构。

### 学习率要与曲率一起理解

取一维损失 $L(\theta)=a(\theta-\theta^*)^2/2$，$a>0$ 是曲率。SGD 无噪声更新后误差为

$$
\theta_{t+1}-\theta^*=(1-\eta a)(\theta_t-\theta^*).
$$

因此固定学习率下，对任意起点收敛需要 $|1-\eta a|<1$，即 $0<\eta<2/a$；边界通常不收敛。多维正定二次函数要考虑最大特征值。语言模型不是固定正定二次函数，但这说明为何梯度尺度与曲率变动会改变合适步长，不能把某个学习率当通用常数。

### 写出 AdamW，才能判断状态和尺度

固定逐元素运算，$g_t$ 为当前梯度，一二阶状态初值均为零。忽略 AMSGrad 等变体：

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\quad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,
$$

$$
\hat m_t=m_t/(1-\beta_1^t),\quad
\hat v_t=v_t/(1-\beta_2^t),\quad
\theta_t=(1-\eta_t\lambda)\theta_{t-1}
-\eta_t\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}.
$$

$\lambda$ 是解耦衰减，$\epsilon>0$ 是稳定项。若把 L2 梯度 $\lambda\theta$ 加入 $g_t$，它会进入 m 和 v，更新方向受到历史与逐坐标尺度影响；上式的衰减直接作用在参数上。这是两者通常不等价的原因。[PyTorch 2.7 AdamW](https://docs.pytorch.org/docs/2.7/generated/torch.optim.AdamW.html)

例如首步 $\theta_0=1,g_1=2,\beta_1=0.9,\beta_2=0.999,\eta=0.1,\lambda=0.1$，若为手算暂取 $\epsilon=0$，则 $m_1=0.2,v_1=0.004,\hat m_1=2,\hat v_1=4$，参数更新为 $0.99-0.1=0.89$。首步将正梯度放大十倍，这个简化条件下自适应步子仍为 0.1；普通 SGD 的步子则放大十倍。真实 epsilon、历史状态、裁剪和衰减使简单尺度不变关系受到限制。

### 梯度累积与分布式归约的同一目标

要最小化全局有效 token 平均，令微批损失和为 $S_j$、有效数为 $n_j$，则目标是 $\sum_jS_j/\sum_jn_j$。可以预先知道总有效数后对每个 $S_j/N$ 反向；也可以先累积未归一化梯度，再在更新与裁剪前除以 N。两种方式都要求参数在微批间不更新，随机性、状态型层的行为须另行控制。

如果 P 个 DDP rank 的梯度最终取平均，全局数 $N=\sum_p n_p$，每 rank 应对 $P S_p/N$ 反向；平均后恰为 $\nabla\sum_pS_p/N$。若每 rank 直接用各自的 $S_p/n_p$，有效数不等时就成为 rank 平均目标。该结论假设实际通信是梯度平均，定制通信 hook 或其他并行系统要重新核对。[DDP 官方说明](https://docs.pytorch.org/docs/2.7/generated/torch.nn.parallel.DistributedDataParallel.html)

混合精度累积还需在同一更新窗口保持缩放约定一致；更新前先 unscale，再按原梯度范数裁剪，最后 step。若先裁剪放大后的梯度，阈值含义就变了。发生溢出并跳过参数更新时，调度器与有效更新步数的计数也要一致。[PyTorch 2.7 AMP 示例](https://docs.pytorch.org/docs/2.7/notes/amp_examples.html)

## 2.7 完整自测与面试问答

### 题 1：softmax 与交叉熵为何对共同平移不变？

**题目：**单样本 logits 为 $z=(0,\ln3)$，真实类别为第二类。概率定义为 $p_k=e^{z_k}/\sum_j e^{z_j}$，损失为 $L=-\ln p_2$。把两个 logits 同时加常数 10，计算平移前后的概率和损失，并用公式解释。

**参考答案：**两次概率均为 $(1/4,3/4)$，损失均为 $-\ln(3/4)\approx0.287682$。平移后分子分母同时乘 $e^{10}$，因子抵消。这也允许减去最大 logit 以避免指数溢出，而不改变数学上的 softmax。

**面试追问：**为什么不先 softmax，再传给接收 logits 的 CrossEntropyLoss？

**追问回答：**该接口已经包含从 logits 到对数概率的计算。先 softmax 会把概率当作新的 logits 再处理，改变目标；应按接口约定传原始分数。

### 题 2：不同长度微批次怎样做梯度累积？

**题目：**同一模型参数下，微批 A 有 10 个有效 token，平均损失 $L_A=2$；微批 B 有 30 个有效 token，平均损失 $L_B=4$。希望复现把 40 个 token 合成一批后的 token 平均梯度。忽略 Dropout 等随机差异，中途不更新参数。应对两个微批的均值损失分别乘什么权重？最终损失是多少？

**参考答案：**权重为 $10/40=1/4$ 与 $30/40=3/4$，总损失为 $\tfrac14\times2+\tfrac34\times4=3.5$。分别反向这两个加权损失再更新，得到合批 token 均值的梯度。直接各乘 1/2 会让两个微批同权，得到 3，目标不同。

**面试追问：**“梯度累积 K 次就把 loss 除以 K”总对吗？

**追问回答：**只有各微批在目标中权重相同等条件满足时才对。有效 token 数不同，要按真实有效数加权；跨设备时还需核对梯度汇总究竟取和还是取平均。

### 题 3：继续训练为什么要保存优化器状态？

**题目：**普通动量 SGD 定义为 $v_t=\mu v_{t-1}+g_t$、$\theta_{t+1}=\theta_t-\eta v_t$。恢复时当前参数为 $\theta_t=1$，保存的 $v_{t-1}=2$，下一梯度 $g_t=1$，$\mu=0.9,\eta=0.1$。比较完整恢复与仅加载参数、把动量置零的下一步参数，并列出其他可能影响继续训练的状态。

**参考答案：**完整恢复得到 $v_t=0.9\times2+1=2.8$，参数为 0.72；动量置零得到 $v_t=1$，参数为 0.9。相同权重仅保证当前前向可一致，不保证下一步更新一致。还需保存优化器步数、学习率调度、随机数状态、混合精度缩放状态，以及后续数据顺序和位置。

**面试追问：**怎样检验恢复成功？

**追问回答：**在尚未收敛的步骤保存，分别让原训练与恢复训练读取同一下一批数据，比较下一步参数和随后曲线；同时检查当前前向输出。只比较最终都收敛到同一数值，可能掩盖恢复错误。

### 题 4：SGD、Adam 与 AdamW 怎样概括？

**题目：**面试官让你比较普通 SGD、带动量 SGD、Adam 和 AdamW。请分别说明它们怎样使用当前与历史梯度，以及为什么“Adam 加 L2 正则”与 AdamW 的权重衰减通常不能直接视为相同。

**参考答案：**普通 SGD 沿当前梯度更新；动量 SGD 用历史梯度的加权累计平滑方向。Adam 分别维护梯度一阶与逐元素平方的二阶滑动平均，进行偏差校正，再按二阶尺度调整步子。把 L2 项加入 Adam 梯度，会使它也参与这些自适应状态；AdamW 把权重衰减与梯度更新分开。

**面试追问：**哪个优化器一定更好？

**追问回答：**没有与任务无关的保证。要在相同数据、训练预算和合理调参条件下比较验证指标、稳定性与成本，并记录学习率、衰减和调度。

### 题 5：手算 AdamW 首步并解释梯度缩放

**题目：**标量参数初值 1，梯度 2，m/v 初值 0，betas 为 0.9/0.999，学习率 0.1，解耦衰减 0.1。本题为非零梯度手算设 epsilon=0，不用 AMSGrad。计算 m、v、偏差校正和新参数；再将梯度改成 20，其他条件相同，比较普通 SGD 与这个 AdamW 首步。

**参考答案：**m=0.2、v=0.004，校正后为 2、4，衰减后参数 0.99，自适应步子 0.1，新参数 0.89。梯度改成 20 后校正值为 20、400，AdamW 新参数仍为 0.89。若普通 SGD 不含衰减，分别为 0.8 与 -1；因而不能把损失缩放与学习率缩放在各优化器中一概等同。实现题应加入正常正 epsilon，并对照固定版本优化器。

**面试追问：**bias correction 为什么需要知道恢复时的步数？

**追问回答：**m/v 从零开始会低估早期矩，校正因子使用 $1-\beta^t$。只恢复矩值却重置 t，会改变校正与下一步更新；这也是完整优化器状态的一部分。

### 题 6：不同 token 数的 DDP rank 怎样保持目标一致？

**题目：**两个 rank，A 有 10 个有效 token、局部均值损失 2，B 有 30 个、局部均值损失 4。目标为全局 40-token 均值，梯度通信最终除以 rank 数 2。忽略随机性与其他状态，各 rank 在同一参数处计算。写出应乘在两个局部均值上的系数及最终标量目标；如果都不缩放会优化什么？

**参考答案：**系数为 `2×10/40=0.5` 与 `2×30/40=1.5`。通信平均后的梯度对应 `(0.5 L_A+1.5 L_B)/2`，损失为 3.5。都用局部均值再平均得到 3，给两个 rank 同权而非给有效 token 同权。实现时全局有效数需要同步，并确保所有 rank 遵循一致的更新与跳过规则。

**面试追问：**加入梯度累积时什么时候裁剪？

**追问回答：**全部微批的目标梯度累积完成并按正确分母归一化后，再处理 unscale 和全梯度范数裁剪，最后只更新一次；逐微批裁剪通常不等于裁剪合批梯度。
