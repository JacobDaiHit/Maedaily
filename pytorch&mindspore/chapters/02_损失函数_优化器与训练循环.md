# 第 2 章　损失函数、优化器与训练循环

“能调用 backward”只完成了训练的一部分。我们还要确认损失对应什么统计问题、每个样本如何加权、优化器怎样改变参数，以及验证是否在独立数据上进行。本章从线性回归走到语言模型交叉熵，搭建第 1 月项目 A 可复用的训练结构。

继续用上一章的标量例子：输入 2、目标 5、当前预测 2，平方误差能告诉我们“错了多少”，梯度能告诉我们“参数怎样改”。但训练还要决定多条样本怎样平均、每次更新走多远、何时用未参与训练的数据检查结果。下面按这个顺序把一次参数更新扩展为训练循环。

可先运行[短程序的梯度与三点拟合](../短程序实验.md)。梯度实验只更新一次，拟合实验把“清梯度 → 前向 → 损失 → 反向 → 更新”重复 200 次。代码打印第 0、20、200 步，让“训练循环”成为可观察的过程，再看交叉熵和优化器如何改变其中一环。

## 2.1 损失定义了你在拟合什么

线性回归假设 $y_i=x_i^\top w+b+\varepsilon_i$，其中 $\varepsilon_i$ 为独立、同方差、零均值高斯噪声。固定噪声方差后，负对数似然与平方误差只差正比例因子和常数，因此最小二乘可以解释为最大似然估计。没有这些假设也能用平方损失，但那时应把它解释为选定的误差度量，不能自动套用高斯统计结论。

分类则定义 logits $z\in\mathbb R^V$，$V$ 是类别数。归一化概率 $p_k=e^{z_k}/\sum_j e^{z_j}$，真实类别为 $y$ 时，交叉熵为

$$
\ell(z,y)=-\log p_y=-z_y+\log\sum_{j=1}^V e^{z_j},\qquad
\frac{\partial\ell}{\partial z_k}=p_k-\mathbf1\{k=y\}.
$$

若两个 logits 都为 0，真实类别是第一个，概率各为 0.5，损失是 $\log2$，梯度为 $[-0.5,0.5]$。更新增加真实类别与另一类别之间的差距。数值实现通常采用稳定的 log-sum-exp；PyTorch 的 `CrossEntropyLoss` 接收 logits，通常不应先 softmax 再传入。[2.7 官方定义](https://docs.pytorch.org/docs/2.7/generated/torch.nn.CrossEntropyLoss.html)同时区分整数标签与概率标签。

## 2.2 语言模型先移位，再确定有效位置

自回归语言模型要由前缀预测下一个 token。若序列为 `[a,b,c,d]`，可以把 `[a,b,c]` 作为输入、`[b,c,d]` 作为标签。某些模型接口内部完成移位，自己再移一次就错位；必须检查接口而不是套模板。

令 $m_{it}\in\{0,1\}$ 表示第 $i$ 条序列第 $t$ 个目标是否参与监督，则有效 token 平均损失为

$$
L=\frac{\sum_{i,t}m_{it}\ell_{it}}{\sum_{i,t}m_{it}}.
$$

分母必须大于零。padding 不应贡献 loss，SFT 中提示词是否受监督由训练方案明确规定。两条序列分别有 2 和 8 个有效 token 时，按 token 平均会让后者占更大权重；先各自平均再对序列平均则让两条序列同权。这是目标选择，不是无关紧要的代码差异。

## 2.3 优化器处理的是梯度与状态

最简单的 SGD 更新为 $\theta_{t+1}=\theta_t-\eta_tg_t$，其中 $\theta_t$ 是参数向量、$g_t$ 是当前梯度估计、$\eta_t>0$ 是学习率。带动量更新使用 $v_t=\mu v_{t-1}+g_t$、$\theta_{t+1}=\theta_t-\eta_tv_t$，$\mu\in[0,1)$ 控制历史梯度的保留。恢复训练只加载参数、不加载 $v_t$，下一步通常就不再相同。

Adam 使用梯度的一阶和逐元素二阶滑动平均，并进行偏差校正；AdamW 把权重衰减与自适应梯度步骤解耦。SGD 中 L2 正则与某些衰减写法可等价，但这种等价不能不加条件搬到自适应优化器上。[AdamW 官方算法](https://docs.pytorch.org/docs/2.7/generated/torch.optim.AdamW.html)用于核对实现，本册线性实验用 SGD，避免同时引入过多状态。

## 2.4 一次训练步骤怎样闭合

以下是供已有模型与批次使用的 PyTorch 2.7 训练骨架；变量 `model`、`optimizer`、`x`、`target`、`loss_fn` 需由任务定义，完整可运行文件在实验目录。

```python
model.train()
optimizer.zero_grad(set_to_none=True)
prediction = model(x)
assert prediction.shape == target.shape
loss = loss_fn(prediction, target)
if not torch.isfinite(loss):
    raise RuntimeError("non-finite loss")
loss.backward()
optimizer.step()

model.eval()
with torch.no_grad():
    validation_loss = loss_fn(model(x_valid), y_valid)
```

顺序具有因果意义：先清除上一轮梯度，再前向建立本轮图，反向计算本轮梯度，最后更新参数。若有梯度裁剪，应在反向之后、更新之前；混合精度时还需按框架规则先恢复真实梯度尺度。梯度累积是有意跨微批保留梯度，并按总有效样本权重缩放，不是简单忘记清零。

## 2.5 哪些指标能回答哪些问题

训练 loss 下降表示拟合训练目标有进展；验证 loss 检查相同任务分布下未参与更新的数据。两者都不能单独证明输出正确、无数据泄漏或目标符合需求。对语言模型还应固定生成提示与解码参数，观察输出；对线性实验则比较已知解析参数和新输入点的预测误差。

常见失败包括：标签 dtype 或索引错误，输出 `[B,1]` 与标签 `[B]` 广播，先把 loss 转 Python 数值再反传，以及优化器没包含新增参数。初始化 loss 约等于 $\log V$ 只适用于近似均匀词表预测等条件，是有用诊断量而非所有语言模型的定律。

## 2.6 练习与进一步阅读

1. 交叉熵的所有 logits 同时加常数，损失会变吗？提示：分子分母同乘指数因子，概率不变。
2. 两个微批有效 token 数为 10、30，要复现合批 token 均值，两个微批均值损失应如何加权？提示：分别乘 $1/4$ 与 $3/4$。
3. 为什么加载参数后继续训练与从检查点恢复可能不同？提示：动量、学习率调度、随机数与数据位置都是训练状态。
