# 三个短程序实验：从形状到一次完整训练

先用同一组数值学习 PyTorch，再到 MindSpore 里核对同一个数学问题。每个实验都能单独运行；不需要下载数据。这里的三个问题按顺序接起来：数组有没有按预期配对？损失对参数的导数是多少？反复更新后能否学回已知直线？

## 实验一：程序不报错，结果也可能错

预测是列向量 `[[1],[2],[3]]`，标签是一维数组 `[1,2,3]`。我们本来想逐个相减，得到三个零。但 `[3,1]` 与 `[3]` 按广播规则相减，会产生 `[3,3]` 的九个差；其均方误差是 $4/3$。把预测压成 `[3]` 后，误差才是零。**均方误差**（MSE）是所有差值平方的平均。

```powershell
& 'D:/anaconda/envs/pytorch_env/python.exe' 'pytorch&mindspore/experiments/torch_mini.py' shape
```

先不看输出，写下错误和正确结果的形状。程序中 `assert` 检查形状；以后训练真实模型时，也要按样本、时间、词表分别检查轴的含义。[第 1 章](chapters/01_张量_广播与自动微分.md)给出广播规则。

## 实验二：先手算一次梯度

定义预测 $\hat y=2w+b$、目标 $y=5$、损失 $L=\tfrac12(\hat y-y)^2$。从 $w=1,b=0$ 开始，预测 2，损失 4.5。链式法则给出 $\partial L/\partial w=-6$、$\partial L/\partial b=-3$。学习率为 0.1 时，一步更新后 $w=1.6,b=0.3$，新预测为 3.5。这里**学习率**是梯度更新的步长，**自动微分**让框架按计算路径应用链式法则。

```powershell
& 'D:/anaconda/envs/pytorch_env/python.exe' 'pytorch&mindspore/experiments/torch_mini.py' gradient
```

代码只有前向、求损失、`backward()` 和手动更新四段。先对照手算；把目标改成 4 的完整条件、更新和断言要求见本页题 2。[第 2 章](chapters/02_损失函数_优化器与训练循环.md)把这一步扩展为训练循环。

## 实验三：反复更新，学回一条直线

给三组训练数据 $(0,1),(1,3),(2,5)$，假设模型为 $\hat y=wx+b$。数据由 $y=2x+1$ 生成；训练程序不知道 2 和 1，开始时取 $w=b=0$。每步计算三点的平均平方误差，再按梯度更新。第 200 步后再给一个新输入 $x=3$，看预测是否接近 7。

```powershell
& 'D:/anaconda/envs/pytorch_env/python.exe' 'pytorch&mindspore/experiments/torch_mini.py' fit
```

默认打印第 0、20、200 步。已在本机 PyTorch 2.7.1、CPU 上运行：损失持续下降，第 200 步 $w,b$ 的显示值约为 2 和 1，$x=3$ 的预测约为 6.999997。这个新点只验证已知线性关系下的一次外推计算，不能说明模型会处理真实世界的噪声与分布变化。

## 在 MindSpore 中做同样三件事

[MindSpore 版程序](experiments/mindspore_mini.py)使用固定 2.4.0 API 的 `PYNATIVE_MODE` 和 `value_and_grad`。后者一次返回损失与所选输入参数的梯度；与 PyTorch 示例中把梯度累加到 `.grad` 的写法不同，数学目标相同。请在**已安装并支持 CPU 的 MindSpore 环境**中运行：

```powershell
python 'pytorch&mindspore/experiments/mindspore_mini.py' shape
python 'pytorch&mindspore/experiments/mindspore_mini.py' gradient
python 'pytorch&mindspore/experiments/mindspore_mini.py' fit
```

这三条 MindSpore 命令是供对应环境执行的练习；本次检查的 `pytorch_env` 中没有 MindSpore，因此仅通过 Python 语法检查，**没有声称运行结果已验证**。MindSpore 版用 float32，PyTorch 梯度和拟合例用 float64；比较时先看形状、梯度方向与近似数值，不要求浮点末位完全相同。`value_and_grad` 的双输入梯度返回形式见 [MindSpore 2.4 梯度文档](https://www.mindspore.cn/docs/en/r2.4.0/migration_guide/model_development/gradient.html)，运行模式见 [PyNative 文档](https://www.mindspore.cn/docs/en/r2.4.0/model_train/program_form/pynative.html)。

**题目：**预测 p=[[1],[2],[3]]，标签 y=[1,2,3]。均方误差定义为差值张量所有元素平方的平均。分别计算直接 p-y 和先把 p 压成一维后的损失，给出差值形状。请分别说明 PyTorch 和 MindSpore 应先检查什么。

**参考答案：**直接广播得到 `[3,3]`，差值行是 [0,-1,-2]、[1,0,-1]、[2,1,0]，平方和 12，均值 4/3；压成 `[3]` 后逐样本差为零，损失 0。两框架都应断言预测与标签的形状及轴语义；合法广播并不代表语义正确。

### 题 3：直线拟合成功代表什么？

**题目：**训练点为 (0,1)、(1,3)、(2,5)，模型为 wx+b，初始 w=b=0，损失为三点平均平方误差，无动量 SGD 学习率 0.1，更新 200 次。请算第一次损失、两个梯度与更新参数，给出唯一零损失解及 x=3 的理想预测；说明这个实验验证范围。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**初始损失 $35/3$，w 梯度 $-2(0\times1+1\times3+2\times5)/3=-26/3$，b 梯度 -6；更新为 w=13/15、b=0.6。零损失解为 w=2、b=1，x=3 预测 7。它验证既定线性模型和优化循环可恢复已知关系，有限次迭代输出按误差容差验收，不代表真实数据泛化。

</details>

</details>
