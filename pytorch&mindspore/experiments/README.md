# 实验：梯度核对、线性训练与中断恢复

第一次接触框架，请先做[三个短程序实验](../短程序实验.md)：每个都能单独运行，并把形状、梯度、一步更新和拟合结果逐项解释清楚。本页的 `linear_train_lab.py` 是下一步的完整验收，加入解析参照、检查点和中断恢复。

实验使用现有 PyTorch 环境，代码为[linear_train_lab.py](linear_train_lab.py)。无需下载数据、安装包或启动 GPU。固定 CPU、float64、一个计算线程、seed 7，以减少机制验证中的额外变量。

## 要回答的问题

第一，形状错误能否让损失算错却不报异常？第二，自动微分是否符合手推和有限差分？第三，完整训练能否恢复已知参数？第四，保存再加载是否既能恢复预测，也能恢复带动量的后续更新？

## 运行

从仓库根目录的 PowerShell 执行：

```powershell
& 'D:/anaconda/envs/pytorch_env/python.exe' 'pytorch&mindspore/experiments/linear_train_lab.py' --output-dir 'pytorch&mindspore/experiments/results'
```

当前默认 `python` 对应没有 torch 的另一解释器，因此命令显式使用已经核验可用的环境。换电脑时，把解释器路径改为你已经配置的 PyTorch 环境；不要为复现这个小实验盲目覆盖现有环境。

## 数学参照与检查顺序

数据是 20 个二维网格点，真实关系为 $y=2x_1-3x_2+0.5$。四个独立输入点用于预测验收；这是无噪声、模型完全正确的教学情形，不能用很小的误差宣称现实泛化能力。

1. 对 `[3,1]` 与 `[3]` 的差，错误广播产生 `[3,3]`，均方误差为 $4/3$；修正后为 0。
2. 在参数 $(0.3,-0.2,0.1)$ 处，对均方损失比较三种梯度。解析式为 $2\widetilde X^\top(\widetilde X\theta-y)/N$，其中 $\widetilde X$ 在输入后拼接常数 1，$N=20$。
3. 中心差分步长为 $10^{-6}$，与 autograd 的最大绝对误差应小于 $10^{-7}$。代码还检查两次独立前向的梯度累积与二分类交叉熵梯度。
4. SGD 学习率 0.05、动量 0.9、训练 800 步，验收参数误差小于 $10^{-6}$、训练与验证 MSE 小于 $10^{-12}$。
5. 一条分支连续训练 800 步；另一条在第 40 步保存参数、优化器状态与框架随机数状态，重建对象后加载，继续到 800 步。同时比较恢复后的**紧接着一步**，避免最终都收敛而掩盖恢复错误。代码还故意只加载权重、不加载动量状态，确认这个错误对照会立刻产生不同更新。

这些是本实验明确条件下的检查。`torch.use_deterministic_algorithms(True)` 并不保证任意设备、框架版本和程序都有跨平台逐位相同结果；实际 LLM 还需管理数据位置、混合精度与分布式状态。

## 本次实跑记录

2026-09-26，Python 3.11.15、PyTorch 2.7.1+cu118，实际计算使用 CPU float64。自动微分与解析式最大误差为 $2.22\times10^{-16}$，与中心差分最大误差为 $1.36\times10^{-9}$；训练 MSE 从 19.6686 降到 $1.66\times10^{-30}$，独立输入点 MSE 为 $3.94\times10^{-31}$，参数最大误差为 $8.88\times10^{-16}$。

重载预测误差、恢复后下一步参数误差、最终参数误差均为 0。故意省略优化器状态的对照，下一步参数偏差约为 0.104246，说明恢复检查在尚未收敛时确实能区分有无动量状态。完整精度与配置保存在 JSON，命令退出码为 0。

## 完整实验题与面试问答

### 题 1：怎样给解析梯度核对提供完整数据？

**题目：**取两样本 $(x_1,y_1)=(0,1),(x_2,y_2)=(2,5)$，模型 $\hat y=wx+b$，w=0.3、b=-0.2，损失 $L=\frac12\sum_{i=1}^2(\hat y_i-y_i)^2$；这里的 1/2 是样本平均系数，不额外再乘半平方。求两误差、L、w/b 梯度，写出用中心差分核对的参数扰动规则。

**参考答案：**误差为 -1.2、-4.6，loss=(1.44+21.16)/2=11.3；w 梯度为 2×平均(error×x)=-9.2，b 梯度为 -5.8。每次只扰动一个参数，其他数据/参数固定，用 h=1e-6 计算 [L(theta+h)-L(theta-h)]/(2h)，float64 下比较容差。

**面试追问：**为什么题干要说明 1/2 的来源？

**追问回答：**均值和半平方都可能出现 1/2，但导数与缩放不同；必须把完整损失式写出，不能只说“用 MSE”。

### 题 2：恢复优化器状态怎样设计有区分力的验收？

**题目：**优化器是普通 momentum SGD，定义 v_new=0.9v_old+g、theta_new=theta_old-0.1v_new，无 dampening、无 Nesterov、无衰减。存档时 theta=1、v_old=2；恢复后的下一批梯度固定为 g=1。比较完整恢复和只恢复 theta、把 v_old 设0的下一步参数。

**参考答案：**完整恢复 v_new=2.8、theta_new=0.72；只恢复参数 v_new=1、theta_new=0.9。应在恢复后的紧接一步比较，而非只比较最终收敛点。真实训练还需数据位置、随机数、调度器与混合精度状态。

**面试追问：**能只比较重载前后的预测吗？

**追问回答：**预测一致只检验模型权重，不能确认下一步训练状态；需要连续训练分支作为对照。
