## 做了什么

671B 总参数、每 token 37B 激活参数，采用 MLA 和 MoE；结合负载平衡、多 token prediction、FP8 及并行调度。预训练后还有 SFT 与 RL，因此 Base 与 Chat 结果需分开读。

## 实验了什么

报告训练 14.8T token，分别给出基础模型和后训练模型在知识、数学、代码等任务上的比较。表 4 用两种规模做 MTP 消融，多数指标改善，但大规模 MMLU 从 67.5 到 66.6，不能写成所有指标均提升。

表 1 报告正式训练共 2.788M H800 GPU 小时；按每 GPU 小时 2 美元换算为 5.576M 美元。原文明说不含此前架构、算法和数据研究及消融成本，所以不是公司的全部研发成本。

## 应用与限制

展示大规模通用语言模型训练与任务评测；对当前学习的直接用途是结构、资源与后训练衔接分析。较少激活参数不等于只需存储这些参数，部署仍受全部权重和通信限制。报告的整模结果不能证明每个模块的独立贡献，本地单卡也无法复现这些规模结论。

## 怎么读与怎么用

先在 [系统章节](../../chapters/05_MoE_MLA与训练系统.md) 分清 MoE 与 MLA 改变的成本，再整理模型、训练、评测三张表。把“采用了某设计”“有对应消融”“只有作者经验描述”标成三类证据。它也连接到 [R1 的多阶段训练](../../../post_train/papers/notes/2025_DeepSeek_R1.md)，但不把两个报告的时间和版本混用。
