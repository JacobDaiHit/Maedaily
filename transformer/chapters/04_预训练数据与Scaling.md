# 第 4 章：数据与 Scaling——预算究竟花在哪里

**本章问题：多一点参数、多一点 token、多训练几步，哪一种更值得？** 需要区分训练目标上的经验规律、最终任务能力以及数值稳定性。

前两章说明怎样训练与生成，第三章说明一次训练和生成消耗哪些计算。现在固定可用计算预算，选择模型大小和训练 token 数：**预训练数据**是用于学习下一 token 分布的语料，**scaling 规律**是研究规模变化与测得损失之间关系的经验描述。先检查数据切分和计数，再谈“更大模型”是否值得。

先做一个只用于理解约束的数值例子：令 $N$ 是模型参数数目，$D$ 是训练 token 数，$C$ 是粗略训练计算预算。若估算式是 $C\approx6ND$，取 $N=10,D=100$，预算就是 6000 个相对计算单位。固定这笔预算把参数翻倍到 20，能处理的 token 就要减半到 50。哪种方案损失更低，不能只看这道乘法题，还要有同口径数据和实验拟合；后面的经验式正是尝试回答这个比较。

## 1. 数据量不是文件大小

清洗、质量筛选、语言识别、去重和混合比例共同定义训练分布。token 数要在确定 tokenizer 后计算；同一文档重复十遍增加处理 token，却没有增加十倍独立信息。按来源切分、近重复检查和评测污染审计应先于追求数量。

质量过滤也有代价：一个偏好规范语体的分类器可能删掉稀有领域、方言或困难样本。应保存过滤规则、各来源保留比例、重复率以及小样本人工检查，而不只记录“高质量数据”。当验证损失改善时，要问它改善的是同一来源分布，还是目标任务。

## 2. 经验规律不是普适定律

常见经验拟合可写为

$$L(N,D)\approx E+A N^{-\alpha}+B D^{-\beta},$$

其中 $N$ 是模型规模，$D$ 是训练 token，系数依赖模型、数据、训练设置及拟合范围。对于稠密 Transformer 的一种粗略训练计算估算，$C\approx6ND$；它省略注意力长序列的额外成本，词表投影是否计入则取决于 $N$ 的参数统计口径。它也不含系统效率，不能直接当作墙钟时间。拟合与成本公式必须使用一致的参数定义。

把 $D=C/(6N)$ 代入后，在这一假定拟合成立的区间内求导，可得

$$N^{\alpha+\beta}=\frac{\alpha A}{\beta B}\left(\frac C6\right)^\beta.$$

因此 $N\propto C^{\beta/(\alpha+\beta)}$、$D\propto C^{\alpha/(\alpha+\beta)}$。当两指数接近时，两者大致同比增长。关键不是背“20 token/参数”，而是理解拟合条件改变，最优点也会改变。[Chinchilla 省流](../papers/notes/2022_Chinchilla.md)

Chinchilla 针对固定训练计算预算研究参数和数据配置。若部署要生成巨量 token，小模型更长训练可能降低总训练加推理成本；若数据受限或重复严重，另一套约束又会主导选择。MoE 的总参数和激活参数不同，更不能直接把稠密拟合中的 $N$ 随意替换。

## 3. 两条应分开的排查路径

Scaling 研究预算配置。数值稳定性研究是否正确、稳定地执行训练。loss spike、梯度溢出、学习率过大、异常数据或精度问题不能用“模型太小不满足 Scaling Law”解释。先确保实验实现和优化过程可靠，再拟合规模趋势。

为了公平比较，改变参数量时需考虑训练步数、有效 token、学习率调度和预算是否共同变化。固定 epoch 并不固定算力；固定步数且 batch 长度不同也不固定 token。只报告最终最优一次运行，会掩盖配置搜索成本。

## 4. 第 7 月可完成的小实验

在项目 A 的模型上选择一个变量：独立训练样本数、重复比例或合成噪声比例。固定其余条件及测试集，至少记录有效 token、训练时间、训练与验证损失。先做两到三个规模点，看方向是否稳定，再决定是否需要重复。

如果选择不同模型规模与不同数据量的网格，应同时给出等 token 和近似等计算预算的视图。小模型、短序列和合成语法只能验证预算分析流程，不足以估计产业规模的幂律指数。负结果也应保存：数据增加但不收益，可能意味着模型容量、数据同质性或训练未收敛。

自检：两个实验处理同样多 token，但一个重复率更高，能否说它们“数据规模一样”？一个模型训练更贵但服务更便宜，目标函数该怎样改？写出条件比背结论更重要。
