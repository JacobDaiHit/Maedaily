**本章问题：多一点参数、多一点 token、多训练几步，哪一种更值得？** 需要区分训练目标上的经验规律、最终任务能力以及数值稳定性。

前两章说明怎样训练与生成，第三章说明一次训练和生成消耗哪些计算。现在固定可用计算预算，选择模型大小和训练 token 数：**预训练数据**是用于学习下一 token 分布的语料，**scaling 规律**是研究规模变化与测得损失之间关系的经验描述。先检查数据切分和计数，再谈“更大模型”是否值得。

先做一个只用于理解约束的数值例子：令 $N$ 是模型参数数目，$D$ 是训练 token 数，$C$ 是粗略训练计算预算。若估算式是 $C\approx6ND$，取 $N=10,D=100$，预算就是 6000 个相对计算单位。固定这笔预算把参数翻倍到 20，能处理的 token 就要减半到 50。哪种方案损失更低，不能只看这道乘法题，还要有同口径数据和实验拟合；后面的经验式正是尝试回答这个比较。

## 1. 数据量不是文件大小

清洗、质量筛选、语言识别、去重和混合比例共同定义训练分布。token 数要在确定 tokenizer 后计算；同一文档重复十遍增加处理 token，却没有增加十倍独立信息。按来源切分、近重复检查和评测污染审计应先于追求数量。

质量过滤也有代价：一个偏好规范语体的分类器可能删掉稀有领域、方言或困难样本。应保存过滤规则、各来源保留比例、重复率以及小样本人工检查，而不只记录“高质量数据”。当验证损失改善时，要问它改善的是同一来源分布，还是目标任务。

## 2. 经验规律不是普适定律

常见经验拟合可写为

$$L(N,D)\approx E+A N^{-\alpha}+B D^{-\beta},$$

其中 $N$ 是模型规模，$D$ 是训练 token，系数依赖模型、数据、训练设置及拟合范围。对于稠密 Transformer 的一种粗略训练计算估算，$C\approx6ND$；它省略注意力长序列的额外成本，词表投影是否计入则取决于 $N$ 的参数统计口径。它也不含系统效率，不能直接当作墙钟时间。拟合与成本公式必须使用一致的参数定义。

把 $D=C/(6N)$ 代入后，在这一假定拟合成立的区间内求导，可得

$$N^{\alpha+\beta}=\frac{\alpha A}{\beta B}\left(\frac C6\right)^\beta.$$

因此 $N\propto C^{\beta/(\alpha+\beta)}$、$D\propto C^{\alpha/(\alpha+\beta)}$。当两指数接近时，两者大致同比增长。关键不是背“20 token/参数”，而是理解拟合条件改变，最优点也会改变。[Chinchilla 省流](../papers/notes/2022_Chinchilla.md)

Chinchilla 针对固定训练计算预算研究参数和数据配置。若部署要生成巨量 token，小模型更长训练可能降低总训练加推理成本；若数据受限或重复严重，另一套约束又会主导选择。MoE 的总参数和激活参数不同，更不能直接把稠密拟合中的 $N$ 随意替换。

## 3. 两条应分开的排查路径

Scaling 研究预算配置。数值稳定性研究是否正确、稳定地执行训练。loss spike、梯度溢出、学习率过大、异常数据或精度问题不能用“模型太小不满足 Scaling Law”解释。先确保实验实现和优化过程可靠，再拟合规模趋势。

为了公平比较，改变参数量时需考虑训练步数、有效 token、学习率调度和预算是否共同变化。固定 epoch 并不固定算力；固定步数且 batch 长度不同也不固定 token。只报告最终最优一次运行，会掩盖配置搜索成本。

## 4. 第 7 月可完成的小实验

在项目 A 的模型上选择一个变量：独立训练样本数、重复比例或合成噪声比例。固定其余条件及测试集，至少记录有效 token、训练时间、训练与验证损失。先做两到三个规模点，看方向是否稳定，再决定是否需要重复。

如果选择不同模型规模与不同数据量的网格，应同时给出等 token 和近似等计算预算的视图。小模型、短序列和合成语法只能验证预算分析流程，不足以估计产业规模的幂律指数。负结果也应保存：数据增加但不收益，可能意味着模型容量、数据同质性或训练未收敛。

数据重复率与训练、服务成本的完整问答见本章第 6 节。

参考：[Kaplan 等 Scaling Laws](https://arxiv.org/abs/2001.08361)、[Chinchilla 固定版本](https://arxiv.org/abs/2203.15556v1)、[D2L 优化章节](https://d2l.ai/chapter_optimization/index.html)。

## 5. 深入：从数据流水线到可检验的预算结论

### 5.1 等预算最优点的完整推导

令 $K=C/6>0$，用约束 $ND=K$ 消去 $D$。在 $A,B,\alpha,\beta>0$ 且模型成立的范围内：

$$f(N)=L(N,K/N)-E=A N^{-\alpha}+B K^{-\beta}N^\beta.$$

直接对 $N$ 求导可以求解；对 $u=\log N$ 求导更容易看出两个误差项怎样平衡：

$$\frac{df}{du}=-\alpha A e^{-\alpha u}+\beta B K^{-\beta}e^{\beta u}=0.$$

所以最优点满足 $\alpha A N^{-\alpha}=\beta B D^{-\beta}$。它平衡的是**边际收益**，不是把参数误差与数据误差强行设成相同。对 $u$ 的二阶导数为两个正项之和，故无额外边界约束时有唯一最小值；实际参数只能取某些离散架构、数据可能耗尽，还要在可行集合重新比较。

完整算例采用教学单位：$E=0,A=B=1,\alpha=\beta=1/2,K=10^4$。最优 $N=D=100$，损失 $0.1+0.1=0.2$。等预算备选 $N=25,D=400$ 的损失是 $0.2+0.05=0.25$。若最多有 50 单位独立数据，理想可行最优变为 $D=50,N=200$，损失约 $0.212132$；重复数据是否能当作额外 $D$ 必须重新建模，不能突破这个约束时直接假装样本独立。

### 5.2 数据处理应该输出什么中间证据

一个能排错的数据流水线保留稳定文档 ID 和来源，依次执行解析、规范化、质量/语言规则、去重与分组切分、tokenization、打包。**去重和切分要联合设计：**先发现同源、转载、近重复和同题变体所属的组，再把整个组放入一个划分；已有测试集先冻结，其近重复内容从训练候选中移除。随机拆文档后只在各划分内部去重，仍会留下跨集合泄漏。

精确去重可使用规范化文本的哈希，但规范化不能随意破坏代码缩进、数学符号等语义。近重复可以用 token shingle 集合比较：$J(A,B)=|A\cap B|/|A\cup B|$。MinHash 用多个哈希排列下的最小值估计 Jaccard，LSH 只负责生成候选；阈值和人工检查决定误删、漏检的取舍。它不能识别全部语义改写，也不能把有共同模板的不同正确样本一律视作重复。

例如 $A=\{a,b,c,d\},B=\{a,b,c,e\}$，交集 3、并集 5，$J=0.6$。设阈值 0.8 时它们不会被本规则合并；不能据此声称完全无污染。提交样例时同时给原文、规范化结果、shingle 大小、候选来源、最终判定和保留原因。

打包后的样本契约至少包括 token IDs、有效 token mask、文档边界和所属划分。连续拼接文档允许跨文档注意力，还是采用块对角 attention mask，是模型训练目标的选择；两者不是同一数据实现。loss 仍应按实际预测目标计数，padding、BOS 等特殊位置不能靠文件长度猜测。

### 5.3 混合比例定义的是训练目标

若目标来源权重为 $p_s$，各来源目标为 $L_s(\theta)$，整体损失是 $L=\sum_s p_s L_s$。实际按 $q_s$ 采样且直接求均值，优化的是 $\sum_s q_s L_s$。希望恢复目标权重时可用 $p_s/q_s$ 的重要性权重，要求 $p_s>0$ 的来源都满足 $q_s>0$；极小 $q_s$ 会放大方差，截断权重又引入偏差。

“70% 通用、30% 数学”还必须说明按文档、序列还是 token 抽样。通用文档平均 100 token、数学文档平均 1000 token 时，按文档 7:3 抽样所得期望 token 比例是 $700:3000$，数学约占 81.1%。要按 token 7:3 分配，需按长度核算采样量及实际消耗，记录预算结束时的实际比例。

### 5.4 怎样避免把拟合曲线当成研究结论

至少准备多个模型规模、多个 token 预算的网格，并记录架构、优化器、学习率和完整搜索成本。一个规模只训一个时长，会把模型大小、数据量和优化程度混在一起。拟合时说明是在 loss 空间还是对数残差空间最小化误差；估计 $E$ 与指数往往相关，小范围内许多参数组合都能解释观察。

保留某些规模点只做外推检验，画残差而非只画平滑曲线；检查不同来源的 loss、下游任务与置信区间。若预算加倍而结果落在原波动范围，结论是证据不足。若不同 tokenization，先解决计量单位。最终报告应能回答：哪条假设被证据支持、在哪个范围、下一次训练最能区分哪两种解释。
