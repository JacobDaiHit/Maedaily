# 激活函数从零上手：为什么模型需要一段弯曲的计算

## 1. 从一条直线开始

[入门第一课](../入门/第一课_从预测到学习.md)用 $\hat y=wx+b$ 把输入变成预测。$x$ 是输入，$w$ 和 $b$ 是待学习参数，$\hat y$ 是预测值。只有一个输入时，无论怎样调整 $w,b$，图像始终是一条直线。若真实规律是“太低或太高都不合适，中间最好”，一条直线就很难同时表示两端和中间。

多加几层线性或仿射计算也不会解决这一点。例如先算 $z=w_1x+b_1$，再算 $y=w_2z+b_2$，合起来仍是 $y=(w_2w_1)x+(w_2b_1+b_2)$。**激活函数**是在中间加入的非线性映射，记作 $h=\phi(z)$；于是模型变成 $y=w_2\phi(w_1x+b_1)+b_2$。这里的“非线性”指一般不能再化简成单个 $wx+b$，不保证模型只要加激活就能学好。

## 2. 用 ReLU 认识输出与导数

最简单的常用例子是 $\operatorname{ReLU}(z)=\max(0,z)$。输入 $z=-2$ 时输出 0，输入 $z=3$ 时输出 3。它在负半轴的局部导数为 0，在正半轴为 1；零点不可微，程序会采用约定的次梯度。**导数**告诉我们输入稍变时输出如何变化，也决定反向传播时这一环节怎样传递梯度。

假设模型最终损失为 $L$，中间计算是 $z\rightarrow h=\phi(z)\rightarrow L$。链式法则给出 $\partial L/\partial z=(\partial L/\partial h)\phi'(z)$。若 ReLU 长期落在负半轴，这一路的导数为零，参数可能难以从当前样本得到更新。但“某个批次输出为零”不等于神经元永远死亡；还要看整个数据分布、上游输入变化和其他梯度路径。[Dead Neuron 笔记](Dead_Neuron.md)专门讨论这些条件。

## 3. 用 sigmoid 认识饱和

Sigmoid 定义为 $\sigma(z)=1/(1+e^{-z})$，把实数压进 0 到 1。$z=0$ 时输出 $1/2$；$z$ 很大时接近 1，很小时接近 0。导数为 $\sigma(z)(1-\sigma(z))$，在两端都接近 0。这叫**饱和**：输入再变化一点，输出几乎不动，梯度也较小。若多层都处在饱和区，梯度沿链相乘，学习早期层的信号可能变弱。

Sigmoid 的输出范围让它适合表达某些概率或“保留多少”的门值，但不能只凭图像说它总比 ReLU 好或差。函数用于输出层、门控层，还是普通隐藏层，输入分布和训练目标都不同。Tanh 也会在两端饱和，但输出落在 $-1$ 到 1；[总览](activate_func.md)可按函数查询公式和曲线。

## 4. 从单个函数走向完整模块

**门控**让一路数值控制另一路数值，例如 $h=g\odot u$；$\odot$ 表示逐元素相乘，$g$ 是控制分支，$u$ 是内容分支。RNN 的门控帮助保留历史，Transformer 前馈层中的 SwiGLU 也使用两路投影和相乘。它不只是把 ReLU 的曲线换成另一条曲线。

**残差连接**把输入直接加回模块输出，形如 $y=x+F(x)$，提供一条直接信息路径。**归一化**按约定的维度调整数值尺度，例如 LayerNorm 会使用该维度的均值与方差。它们处理的是信息与梯度在整个网络中怎样流动的问题，与逐元素激活函数各有角色。[门控与归一化补充](从激活函数到门控与归一化.md)给出公式和边界。

## 5. 合上文档做三件事

1. 写出两层仿射计算合并为一层的式子，并指出加入 ReLU 后哪一步无法照样合并。
2. 计算 ReLU 在 $-2$ 与 3 的输出和局部导数；再解释为什么单个负输入不能证明神经元“已死”。
3. 用 $\sigma(0)=1/2$ 算出 sigmoid 在零点的导数 $1/4$，再说明输入绝对值很大时梯度为何变小。
