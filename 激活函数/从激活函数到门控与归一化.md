# 从激活函数到门控与归一化

**问题：一个局部导数怎样影响整条训练链，为什么现代网络不能只靠更换激活函数？** 本章保留已有笔记的直觉，同时补齐必要条件。

先从[从零上手](从零上手.md)中的 ReLU 例子继续：输入 $-2$ 时输出 0，局部导数也为 0；输入 3 时输出 3，局部导数为 1。**局部导数**只描述这一环节怎样把梯度传回去；整条网络还要乘上其他层的导数与权重。本篇先检查这个区别，再把激活函数放进门控、残差和归一化组成的完整模块。

## 1. 看局部导数，也看它乘了什么

Sigmoid 的导数为 $\sigma(x)(1-\sigma(x))$，最大为 $1/4$；tanh 的导数为 $1-\tanh^2(x)$。输入绝对值很大时二者饱和，局部导数趋近零。但完整梯度还乘权重和上游梯度，不能仅凭某个导数上界就断言所有层梯度的实际大小。

ReLU 在负半轴输出和局部导数均为零，正半轴导数为 1，零点由框架选择次梯度。一个 batch 中输出全零，不足以判定神经元在整个数据分布上永久死亡。若其所有相关输入长期都落在负区间，且更新只来自这一路损失，它可能收不到有效梯度；上游表示改变、动量、权重衰减或其他共享路径可能改变这一状态。

Sigmoid 在有限实数下数学导数为正，但数值饱和仍可能让梯度极小甚至在有限精度中变为零。Leaky ReLU 保留负区间斜率，也不保证整体优化一定成功。判断应该来自激活分布、梯度统计和训练曲线，而不是“这个函数不会出问题”的标签。

## 2. 平滑不等于导数处处为正

精确 GELU 为 $g(x)=x\Phi(x)$，其中 $\Phi$ 是标准正态分布函数，$\phi$ 是密度。导数为

$$g'(x)=\Phi(x)+x\phi(x).$$

它可以在部分负区间为负，也会有零点；“平滑”说的是函数正则性，不代表梯度永不小或训练必然更稳定。实现还可能使用 tanh 近似，因此核对数值导数时要确认用了哪种形式。

SiLU/Swish 的常用形式是 $x\sigma(x)$，导数为 $\sigma(x)+x\sigma(x)(1-\sigma(x))$。这些设计影响表示和优化，但优劣仍需在可比较的宽度、预算与训练配方下检验，不能从函数图形直接推出所有任务上的性能。

## 3. SwiGLU 是模块，不能只看一条曲线

对行向量批次 $X\in\mathbb R^{B\times d}$，一个省略偏置的 SwiGLU 前馈层可写为

$$F(X)=\left[\operatorname{SiLU}(XW_g)\odot(XW_u)\right]W_d,$$

其中 $W_g,W_u\in\mathbb R^{d\times m}$、$W_d\in\mathbb R^{m\times d}$。它有两路投影及逐元素乘法，输出仍为 `[B,d]`。门控分支不一定在 0 到 1 之间，不应套用 sigmoid 门的数值范围。

不计偏置时，这个模块约有 $3dm$ 参数；普通两层 FFN 约有 $2dm$。公平比较时可能需要缩小门控版本的中间宽度。若不说明这一点，就无法区分收益来自门控形式还是参数与计算增加。[GLU 变体论文](https://arxiv.org/abs/2002.05202)

## 4. 残差和归一化处理另一类问题

残差块 $y=x+F(x)$ 的 Jacobian 是 $I+J_F$，提供一条直接梯度路径，但 $J_F$ 仍可能与它抵消或放大。LayerNorm 对单个样本指定的特征轴做中心化和缩放，RMSNorm 使用均方根缩放而不减均值；二者都不是给权重施加正交约束。

pre-LN 和 post-LN 把归一化放在不同位置，影响梯度和训练动态。激活、残差、归一化、初始化与学习率共同作用。读技术报告时应记录整个块，避免只摘出“SwiGLU”就声称理解了训练稳定性。

## 5. 深入：归一化 Jacobian 与门控反向

令单样本 $x\in\mathbb R^d$，$P=I-\mathbf1\mathbf1^\top/d$、$u=Px$、$s=\sqrt{u^\top u/d+\epsilon}$。忽略可学习仿射，LN(x)=u/s，故

$$J_{LN}=\frac P s-\frac{uu^\top}{d s^3}.$$

由 $\mathrm du=P\,\mathrm dx$、$\mathrm ds=u^\top\mathrm dx/(d\,s)$ 推出；分母中的 $d$ 是特征维度。$J\mathbf1=0$ 说明共同平移不可见。epsilon=0且u非零时还有 $Ju=0$，体现正尺度方向不变；正epsilon时 $Ju=\epsilon u/s^3$。RMSNorm不中心化，Jacobian为 $I/s-xx^\top/(d\,s^3)$，不把全1方向自动清零。实际还需左乘learned scale的对角矩阵。

SwiGLU中记 $G=XW_g,U=XW_u,Z=SiLU(G)\odot U,Y=ZW_d$。上游 $D=\partial L/\partial Y$ 给 $\nabla_Z=DW_d^\top$，门支梯度 $(\nabla_Z\odot U)\odot SiLU'(G)$，上投影支梯度 $\nabla_Z\odot SiLU(G)$；再用线性层VJP得到各权重和输入梯度。门值很小会同时影响另一支路径，不能只检查单个SiLU导数判断整块训练。

残差也有反例：F(x)=-x时 $I+J_F=0$，直接路径完全抵消。初始化方差与激活分布要一起检查；He/Xavier的尺度推导依赖独立、零均值、激活等假设，不是适用于每种门控块的永久常数。先对同输入核对解析梯度，再做相同资源的训练对照。

## 6. 完整自测与面试问答

### 题 1：平滑激活为何不保证梯度处处为正？

**题目：**精确 GELU 为 $g(x)=x\Phi(x)$，$\Phi$ 为标准正态分布函数，密度 $\phi(x)=e^{-x^2/2}/\sqrt{2\pi}$。推导 g 的导数；已知 $\Phi(-1)\approx0.158655,\phi(-1)\approx0.241971$，计算 x=-1 处导数。另求 SiLU $s(x)=x\sigma(x)$ 的导数及零点值。

**参考答案：**$g'(x)=\Phi(x)+x\phi(x)$，在 -1 为约 -0.083316，说明平滑并不要求处处递增。$s'(x)=\sigma(x)+x\sigma(x)[1-\sigma(x)]$，在 0 为 1/2。数值核对 GELU 要说明使用精确形式还是 tanh 近似。

**面试追问：**有限差分核对导数要怎样给出条件？

**追问回答：**在本题这些光滑点，可用 float64、中心差分 $[f(x+h)-f(x-h)]/(2h)$，先取 $h=10^{-5}$，再改变 h 检查稳定性。步长过小会有浮点消减误差，ReLU 零点则不能用普通导数判断。

### 题 2：SwiGLU 与普通 FFN 怎样匹配参数量？

**题目：**输入 X 形状 `[2,16]`。普通 FFN 不含偏置，第一投影 $16\to96$，第二投影 $96\to16$。SwiGLU 为 $[\operatorname{SiLU}(XW_g)\odot(XW_u)]W_d$，两路投影 $16\to m$，回投影 $m\to16$，均不含偏置。求普通参数量、匹配参数量的 m、各中间形状，说明 SwiGLU 是否只有一条逐元素曲线。

**参考答案：**普通参数为 $2\times16\times96=3072$；SwiGLU 参数为 $3\times16\times m$，匹配得到 m=64。两路与乘积均为 `[2,64]`，输出 `[2,16]`。它包含两路投影、非线性与相乘，比较时要控制参数和训练预算。

**面试追问：**SiLU 门控分支一定在 0 到 1 吗？

**追问回答：**不一定，SiLU 不是 sigmoid 本身。不能把 sigmoid 门的取值范围直接搬到 SwiGLU。

### 题 3：LayerNorm、RMSNorm 与残差分别做什么？

**题目：**单样本特征为 $x=(1,3)$。只为手算，稳定项 epsilon=0、缩放 gamma=1、偏置 beta=0。LayerNorm 按两特征的总体方差中心化缩放；RMSNorm 只除以 $\sqrt{(1^2+3^2)/2}$。计算两种输出。另对残差 $y=x+F(x)$ 写出雅可比，解释其直接路径是否保证梯度不会消失。

**参考答案：**均值为 2、方差为 1，LayerNorm 输出 $(-1,1)$；RMSNorm 输出 $(1/\sqrt5,3/\sqrt5)$，不减均值。残差雅可比为 $I+J_F$，提供直接路径，但仍可与模块路径抵消或放大，不保证所有梯度良好。实际归一化需正的稳定项与可学习缩放等明确配置。

**面试追问：**Pre-LN 与 post-LN 的区别怎么说？

**追问回答：**Pre-LN 把归一化置于子模块前，post-LN 放在残差加法后；位置影响梯度与训练动态，比较要说明整个块，而不只列一个归一化名称。

### 题 4：手写 LN/RMSNorm 反向

**题目：**用x=[1,2,4]、epsilon=1e-5、无仿射，推导两种Jacobian并用float64 autograd核对；检查LN的全1方向与尺度方向，解释正epsilon的作用。

**参考答案：**按第5节矩阵式核对，LN全1方向为零，尺度方向 $\epsilon u/s^3$；RMSNorm不减均值。正确目标是解析和实现误差在容差内，不要求所有方向导数为零。epsilon防零分母并轻微破坏尺度不变。

**面试追问：**batch维和特征维搞反会怎样？

**追问回答：**归一化统计依赖其他样本，改变函数语义；用同样本改变批内伙伴检查是否符合目标轴。

### 题 5：手写 SwiGLU 核心与梯度

**题目：**实现输入[2,4]、中间宽度6的无偏置SwiGLU，逐项写前向形状与解析VJP，与autograd对照；计算参数量并给相同参数普通FFN宽度。

**参考答案：**两支及乘积[2,6]，输出[2,4]，参数 $3\times4\times6=72$；普通FFN宽度9给 $2\times4\times9=72$。VJP按第5节分叉相乘再汇合，输入梯度需累加两支贡献。

**面试追问：**参数相同就保证延迟相同吗？

**追问回答：**矩阵形状、逐元素操作和算子融合不同，需在同硬件输入实际测量。

### 题 6：激活失效的诊断作业

**题目：**给一个ReLU单元在当前batch全零的日志，设计判断长期失活、输入偏移与共享更新的实验；同时给残差抵消反例，说明局部导数不能证明整网稳定。

**参考答案：**检查跨batch/时间的pre-activation分布、输入与参数梯度、动量/衰减和其他路径，固定样本单因素对照；F=-x给残差总Jacobian零。只有当前batch零输出不能判整个分布永久死亡，换激活需匹配配方和资源测质量。

**面试追问：**Leaky ReLU就保证不失效吗？

**追问回答：**负区间保留局部斜率，但全路径仍可很小、抵消或优化失败，需证据。
