# 从激活函数到门控与归一化

**问题：一个局部导数怎样影响整条训练链，为什么现代网络不能只靠更换激活函数？** 本章保留已有笔记的直觉，同时补齐必要条件。

先从[从零上手](从零上手.md)中的 ReLU 例子继续：输入 $-2$ 时输出 0，局部导数也为 0；输入 3 时输出 3，局部导数为 1。**局部导数**只描述这一环节怎样把梯度传回去；整条网络还要乘上其他层的导数与权重。本篇先检查这个区别，再把激活函数放进门控、残差和归一化组成的完整模块。

## 1. 看局部导数，也看它乘了什么

Sigmoid 的导数为 $\sigma(x)(1-\sigma(x))$，最大为 $1/4$；tanh 的导数为 $1-\tanh^2(x)$。输入绝对值很大时二者饱和，局部导数趋近零。但完整梯度还乘权重和上游梯度，不能仅凭某个导数上界就断言所有层梯度的实际大小。

ReLU 在负半轴输出和局部导数均为零，正半轴导数为 1，零点由框架选择次梯度。一个 batch 中输出全零，不足以判定神经元在整个数据分布上永久死亡。若其所有相关输入长期都落在负区间，且更新只来自这一路损失，它可能收不到有效梯度；上游表示改变、动量、权重衰减或其他共享路径可能改变这一状态。

Sigmoid 在有限实数下数学导数为正，但数值饱和仍可能让梯度极小甚至在有限精度中变为零。Leaky ReLU 保留负区间斜率，也不保证整体优化一定成功。判断应该来自激活分布、梯度统计和训练曲线，而不是“这个函数不会出问题”的标签。

## 2. 平滑不等于导数处处为正

精确 GELU 为 $g(x)=x\Phi(x)$，其中 $\Phi$ 是标准正态分布函数，$\phi$ 是密度。导数为

$$g'(x)=\Phi(x)+x\phi(x).$$

它可以在部分负区间为负，也会有零点；“平滑”说的是函数正则性，不代表梯度永不小或训练必然更稳定。实现还可能使用 tanh 近似，因此核对数值导数时要确认用了哪种形式。

SiLU/Swish 的常用形式是 $x\sigma(x)$，导数为 $\sigma(x)+x\sigma(x)(1-\sigma(x))$。这些设计影响表示和优化，但优劣仍需在可比较的宽度、预算与训练配方下检验，不能从函数图形直接推出所有任务上的性能。

## 3. SwiGLU 是模块，不能只看一条曲线

对行向量批次 $X\in\mathbb R^{B\times d}$，一个省略偏置的 SwiGLU 前馈层可写为

$$F(X)=\left[\operatorname{SiLU}(XW_g)\odot(XW_u)\right]W_d,$$

其中 $W_g,W_u\in\mathbb R^{d\times m}$、$W_d\in\mathbb R^{m\times d}$。它有两路投影及逐元素乘法，输出仍为 `[B,d]`。门控分支不一定在 0 到 1 之间，不应套用 sigmoid 门的数值范围。

不计偏置时，这个模块约有 $3dm$ 参数；普通两层 FFN 约有 $2dm$。公平比较时可能需要缩小门控版本的中间宽度。若不说明这一点，就无法区分收益来自门控形式还是参数与计算增加。[GLU 变体论文](https://arxiv.org/abs/2002.05202)

## 4. 残差和归一化处理另一类问题

残差块 $y=x+F(x)$ 的 Jacobian 是 $I+J_F$，提供一条直接梯度路径，但 $J_F$ 仍可能与它抵消或放大。LayerNorm 对单个样本指定的特征轴做中心化和缩放，RMSNorm 使用均方根缩放而不减均值；二者都不是给权重施加正交约束。

pre-LN 和 post-LN 把归一化放在不同位置，影响梯度和训练动态。激活、残差、归一化、初始化与学习率共同作用。读技术报告时应记录整个块，避免只摘出“SwiGLU”就声称理解了训练稳定性。

## 5. 小练习

在 float64 中用中心差分核对 sigmoid、tanh、SiLU、GELU 导数，避开 ReLU 零点。统计某个固定数据集上的激活零比例，再换一组输入，解释统计量为什么变化。最后把 FFN 改成 SwiGLU，先匹配参数量再比较一次小训练；未运行的扩展保持待办，不凭公式宣布性能提升。
