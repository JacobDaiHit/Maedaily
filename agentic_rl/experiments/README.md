# 轨迹核算：mask、回报、终止与成本

这是使用 Python 标准库的教学实验。输入为人工构造的标量与片段标签，不调用模型、不访问工具服务、不训练参数，也不构成 Search-R1 或 Agent Lightning 复现。

在仓库根目录运行：

```powershell
python scripts/run_lesson.py trajectory
```

若当前终端没有 `python`，使用自己的 Python 可执行文件替代，不需要安装第三方依赖。脚本将结果打印为 JSON；它不会自动修改实验报告。

| 检查 | 预期结果 | 对应概念 |
| --- | --- | --- |
| 正确 mask 与误把工具算入 loss | 0.25 与约 3.166667 | 工具文本不是策略行动 |
| 奖励 `[-0.05,-0.05,1]`、折扣 1 | `[0.90,0.95,1]` | 回报从当前奖励开始 |
| 同一奖励、折扣 0.9 | `[0.715,0.85,1]` | 调用级折扣尺度 |
| 真终止 / 工程截断 TD 目标 | -0.05 / 0.67 | 是否保留尾部价值 |
| 100 题的 A/B 两策略，成本 0.02 | 效用 0.66 / 0.67 | 成功率与资源偏好分开 |

脚本还检查全零 mask 会显式报错，含工具 / 提示 / padding 的 token 计数不会被混成有效策略 token。这里的未裁剪 score loss 只是固定 log-prob 的数值核算，不包含自动微分、PPO clipping 或真实采样分布校正。

扩展核算的完整输入与参考答案见下列三题。真实实验还需要版本日志、采样、奖励程序、参数更新与独立测试集，参考[研究设计](../chapters/03_研究路线与实验设计.md)。

## 完整扩展题与面试问答

### 题 1：失败搜索是否计入回报？

**题目：**只构造奖励列表，不访问真实搜索服务。一次失败搜索、一次成功但重复的搜索、一次有效搜索各花成本 0.05，最终回答正确奖励 1；按时间排列奖励为 [-0.05,-0.05,-0.05,1]，折扣 gamma=1，末尾真正终止。请手算各步回报，再用 discounted_returns 核对。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**从后向前加，返回 [0.85,0.90,0.95,1]。失败和重复调用也占成本；不应删除它们后把首步回报写成 0.95。该列表仅检验核算，未检验真实检索或模型决策。

</details>

**面试追问：**成功调用为什么也可能是无效调用？

<details>
<summary>展开追问回答</summary>

**追问回答：**接口成功不代表提供新证据。重复结果可能没有增量信息，但成本仍真实存在，需要分开统计执行成功与证据收益。

</details>

### 题 2：重复查询时动作 mask 怎样构造？

**题目：**人工记录五个计分位置：第一次模型查询、第一次工具观察、第二次模型查询、第二次工具观察、模型答案。供核算的 log-prob 为 [-0.1,-8,-0.2,-8,-0.3]，固定动作优势全为 1，不裁剪。请写二元 mask、有效分母、负 score 平均，并算全计分的错误结果。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**mask=[1,0,1,0,1]，有效分母 3，正确平均为 0.6/3=0.2；全计分得到 16.6/5=3.32。重复查询仍是两次模型动作，两次外部返回仍是观察；不能因为内容重复就改变角色。

</details>

**面试追问：**能按工具文字长度判断这条策略更好吗？

<details>
<summary>展开追问回答</summary>

**追问回答：**文字长度是资源与上下文因素，不是正确性判据。还需验证证据是否有效以及最终答案。

</details>

### 题 3：预算终止与采集截断怎样分开核对？

**题目：**当前奖励 -0.05、gamma=0.9、下一状态估值 0.8。情形 A：任务契约规定 3 次调用用完即失败，当前已用完；情形 B：采集批次只收 3 步，但任务预算尚有 2 次。用 td_target(reward,gamma,next_value,terminated) 分别计算输入 terminated 和结果，解释停止字段。

<details>
<summary>展开参考答案（先独立作答）</summary>

**参考答案：**A 是任务真终止，terminated=true，目标 -0.05；B 只是采集截断，terminated=false，目标 0.67。不能把所有“budget/length exceeded”字符串统一解释为同一种终止；日志应写清任务预算和采集上限。

</details>

**面试追问：**把 A 也补上 0.8 会怎样？

<details>
<summary>展开追问回答</summary>

**追问回答：**会给已经没有合法未来的失败终点增加收益，造成错误的价值目标。

</details>
