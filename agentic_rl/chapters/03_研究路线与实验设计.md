# 第 3 章：研究路线与实验设计

> 目标：从一篇新论文抽出可验证的问题，设计一个算得清成本的小实验。对应 [GOAL 第 9—10 月](../../GOAL.md)；不替代项目 C 的单轮真实模型 RLVR 验收。

前两章已经让我们能记录一条轨迹、给它计分并写出训练目标。但“训练分数提高”还不是“模型更会搜索”：它可能只是多搜、利用验证器漏洞，或恰好遇上更容易的题。本章先确定比较对象，再安排实验。全文沿用“城市 → 国家 → 货币”的两跳问答；**两跳**指答案需要串联两条关系，而不是必须恰好调用两次工具。

第一次读可按第 3.2—3.4 节先设计实验，再回看第 3.1 节的论文路线。先设定一个能检查的问题：加上搜索成本后，模型能否少调用工具，且同一批题目的正确率没有明显下降？如果一个方法答对 70/100 题、平均搜两次，另一个答对 69/100 题、平均搜一次，结果应同时列出质量与成本，不能只说“分数更高”。

## 3.1 沿问题发展阅读

| 时间与锚点 | 新增的问题 | 不能据此推断什么 |
| --- | --- | --- |
| 2022/2023：[ReAct](https://arxiv.org/abs/2210.03629v3) | 推理与环境反馈能否交替组织 | 提示得到更好行为不等于参数经过 RL |
| 2023：[Toolformer](https://arxiv.org/abs/2302.04761v1) | 能否构造工具使用训练数据 | 工具能力不一定需要在线奖励优化 |
| 2024：[ArCHer](https://arxiv.org/abs/2402.19446) | token 与多轮行动的时间尺度怎样连接 | 某类交互任务的收益不能直接外推所有 Agent |
| 2025：[Search-R1](../papers/notes/2025_Search_R1.md) | 搜索环境如何进入结果奖励 RL | 冻结语料检索的改善不等于开放网页部署已验证 |
| 2025：[Agent Lightning](../papers/notes/2025_Agent_Lightning.md) | 多种工作流怎样共享训练接口 | 接口通用不等于所有信用分配问题已解决 |
| 2026：[Small Search Agents](../../post_train/papers/notes/2609.28765_small_search_agents.md) | 奖励形状在小模型搜索中怎样影响学习 | 单模型新稿不是普遍规律；本仓库未独立复现 |

这是理解动机的阅读顺序。它有多个并行分支：数据、奖励、状态表示、长时信用和系统调度。选择与你的实验瓶颈有关的一支，先读基础再读近期对照，避免把“最近发表”误当“最值得优先学”。

## 3.2 什么时候先不做 RL

如果失败源于检索语料缺失，先补语料；若工具参数常写错，先改善参数格式约定（schema）、示例和 SFT 数据；若任务只要确定性查询，先写规则流程。RL 需要探索空间、可重复的环境与有区分度的反馈。没有可测量目标时，训练分数上涨难以解释。

建议先比较三个**基线**，即用于衡量新方法收益的已有做法：固定提示直接回答、按规则固定检索、用少量成功轨迹做监督微调（SFT）。SFT 是用示范中的正确动作作为训练目标，不依赖模型在线探索后得到的奖励。只有这些基线仍暴露“何时搜、搜什么、何时停”的可学习缺口，且结果奖励可检验时，再增加 RL。SFT 能否胜过 RL 要靠实验回答；先做它可以发现动作格式和数据质量问题。

## 3.3 一项可以落地的专题

**研究问题：在冻结知识库的两跳问答中，加入工具成本后，是否能减少调用且保持成功率？** 这是本书提出的实验方案，不是已完成的结果。

先生成一组实体关系事实，例如“城市 → 国家 → 货币”，建立确定性的搜索程序调用接口（API）；保存语料、索引与返回排序。按实体或关系组合切分训练、验证、测试，避免把同一道问题换个说法分到不同集合。测试再加入无关文档和无答案问题，明确任务允许回答“不知道”。

从同一初始检查点建立提示基线与 SFT 基线；再从同一 SFT 检查点分出继续 SFT 和 RL 两支。主实验仅改变成本系数 $c\in\{0,0.02,0.05\}$，保留最大调用次数、模型、数据、温度和评测协议。训练资源不能完全匹配时，如实报告各支采样、优化和工具成本，不能只对齐更新步数。

奖励先验证：严格解析最终答案；无效调用、重复查询、多个矛盾答案和把所有候选枚举出来都要有明确定义。奖励测试使用人工编写轨迹，不执行模型随意生成的代码。通过格式检查只说明接口有效，不证明事实正确或证据充分。

## 3.4 成功率—成本曲线比单点排行榜更有用

定义任务成功率 $\hat p=n^{-1}\sum_i I_i$，平均工具调用 $\bar N=n^{-1}\sum_iN_i$。同时记录输入 / 输出 token、工具延迟、端到端耗时分位数、无效调用率与截断率。训练采样成本和部署时推理成本分开列；缓存命中也要披露。

在独立、同分布的二元任务结果近似下，成功率标准误可用 $\sqrt{\hat p(1-\hat p)/n}$ 粗估；同一题多个随机种子不是多个独立题目。策略之间用同题配对结果评估差异，重复训练再检查随机性。正式报告可用按题目反复有放回抽样的自助法（bootstrap），而非把所有 token 当作独立样本。

例如 A 在 100 题答对 70 题，共调用 200 次；B 答对 69 题，共调用 100 次。用 $\hat J=\hat p-c\bar N$，两者在 $c=0.01$ 时相同。不能仅凭少答对一题判断显著下降；也不能只看更高效用就说正确率提高。画不同预算下的曲线，并检查 B 是否通过放弃难题节省成本。

## 3.5 读论文时保留四层证据

先标明贡献类别：新的目标或估计量、训练配方、系统接口、数据或评测。再把作者的实验观察与机制解释分开。例如“mask 消融下降”支持该配置有效，尚不足以证明任何环境、任何 tokenizer 都同样受益。最后区分展示场景与真实部署：离线问答成功率没有直接测量网页变化、工具权限、费用或用户任务完成率。

近期预印本只加入一个可检验假设。先保存版本、读方法与实验，再核对基线和数据选择；论文标题中的“ANY”“emergent”等措辞不自动成为本书结论。对新结果未复现时明确标记，保留负结果也可以形成合格专题。

## 3.6 交付物与停止条件

交付环境说明、数据划分、固定提示、SFT / RL 配置、轨迹样例、成功率—成本表和失败分类。资源允许时做至少 3 个训练种子；不足时披露实际次数。先跑一批完整轨迹，检查显存、耗时和 mask，再估算扩大成本。

若验证器仍有漏洞、SFT 格式成功率太低、奖励组长期全同或工具不可重放，先停止扩大训练并修复对应环节。若 RL 在既定预算内无收益，分析信息不足、探索不足、奖励噪声或系统问题，不能只更换算法名。

### 题 1：调用减少是否证明查询更聪明？

**题目：**同一批 100 题上，系统 A 答对 70 题、调用工具 200 次；系统 B 答对 69 题、调用 100 次。B 的平均调用更少。请提出两种可同时存在的解释，并设计能区分它们的分析；题目难度桶和证据判据须在看结果前确定。

**参考答案：**解释一是查询更精准，较少调用就获得足够证据；解释二是更早放弃难题，降低了成本也损失成功。按同一难度桶比较配对成功变化、有效证据召回、停止位置、失败原因及每个成功任务成本；再固定允许预算重放，检查是否仍获得必要证据。两机制可能并存，不能用平均调用数单独归因。

**面试追问：**“消融实验”是什么意思？

**追问回答：**保持其他条件固定，移除或替换一个待研究组件，例如只替换查询选择器或停止规则，再比较结果，以缩小因果解释范围。

参考教材：[RL 理论书稿](../../RL/books/README.md)用于检查学习假设，[RLHF 书稿](../../post_train/books/README.md)用于连接训练、工具与评测。返回[本卷目录](../README.md)。

## 3.7 深入：可证伪专题与质量—成本约束

“正确率没有显著下降”不等于证明正确率损失小于容忍阈值。若业务允许最多2个百分点下降，应预先定义非劣界delta=.02，对同题质量差构造区间；下界高于-.02才提供相应非劣证据。测试太小导致宽区间时结论为不足，不是质量已保持。

质量与调用数同时比较可画Pareto前沿：另一个配置若质量不低且成本不高、至少一项严格更好，则当前点被支配。不同成本c会选择不同前沿点；报告原始指标和约束，不能只用一个c掩盖放弃困难题。模型/教师、训练获取数据与工具搜索成本分开列。

一个可证伪假设例子：“失败摘要帮助改查询，而非只靠多次尝试。”对照匹配重试次数、反馈、总token，比较有效摘要、无摘要、等长无关摘要，按故障类别预先分桶。若收益只在增加预算时出现，或查询/证据没有改善，原机制解释不被支持。提示适应与参数训练分别报告。

选题从真实失败桶出发：确定性基线能否已解决？环境是否给新增信息？奖励是否可信？采样是否有对比？只有缺口明确后再选RL估计器和系统。交付包含负结果与下一次最能区分解释的实验，不需要把每个组件都写成新算法。

## 3.8 完整计算与面试追问

### 题 2：成功率与成本怎样决定最优方案？

**题目：**系统 A 在 100 题中答对 70 题、工具调用总数 200；B 答对 69 题、总调用 100。定义效用 $J=\text{成功率}-c\times\text{每题平均调用}$，c 是每次平均调用的扣分系数。分别取 c=0.005 和 c=0.02，算 A/B 效用，再求两者相等的 c。

**参考答案：**A/B 平均调用为 2/1。c=0.005 时，A=0.69、B=0.685，A 较高；c=0.02 时，A=0.66、B=0.67，B 较高。由 0.70-2c=0.69-c 得 c=0.01 时相等。排序随目标权重改变，报告须同时给出原始成功与成本。

**面试追问：**70% 与 69% 足够说明能力有稳定差别吗？

**追问回答：**仅这组汇总不够。要检查逐题配对、样本量、重复运行与不确定性；固定评测协议后再判断差异，而不是只看一百分点。

### 题 3：用了 PPO 就能任意复用旧轨迹吗？

**题目：**采集器用策略版本 v1 生成工具轨迹，训练器已到 v5。轨迹中含提示、模型动作、工具观察、奖励，以及 v1 在动作位置的 log-prob；环境和工具版本有记录。请说明 PPO 分母应来自哪里、为什么仍需要样本年龄限制，并列出至少三项监控。

**参考答案：**比率分母是实际采样策略 v1 的动作概率，需保留不变。局部 token 裁剪并不自动修正任意旧历史的分布差异；长轨迹及环境变化会进一步影响偏差。监控策略版本差、轨迹年龄、比率/裁剪比例、KL、环境版本与失败类别，并以同步或低滞后采样作为对照。

**面试追问：**参考模型概率可以代替旧策略概率吗？

**追问回答：**不能。旧策略用于描述数据采样分布，参考模型用于约束偏离基准模型；即使初始相同，角色和更新规则也不同。

### 题 4：保持质量需要什么统计证据

**题目：**预先允许质量最多降.02，新旧正确率差区间为[-.05,.01]，能否宣称质量保持？若区间[-.01,.03]又怎样？列出配对与题族抽样要求。

**参考答案：**第一下界低于-.02，证据不足；第二下界高于-.02，在所定区间和条件下支持非劣，不代表两策略完全相同。保留同题对应、按题族重采样、冻结选择与预算，不把同题候选当独立题。

**面试追问：**下降检验p>.05能代替非劣吗？

**追问回答：**不能，缺少显著下降可能只是统计功效不足，需预定义可接受损失和相应区间。

### 题 5：用消融检验摘要机制

**题目：**按第3.7节设计有效摘要、无摘要、等长无关摘要的三组对照；给出预算、故障桶、主要指标与可能推翻假设的结果。

**参考答案：**固定模型与重试/反馈、计入摘要生成成本，测最终质量、查询变化和证据召回；若只额外token解释收益、有效摘要不改善查询或正常任务成本增加过多，机制需重审。不要只保存赢家；冻结验证测试。

**面试追问：**有用摘要来自更强教师会混入什么？

**追问回答：**额外模型能力、反馈信息与生成成本，应匹配或明确这是教师资源条件下的结果。

### 题 6：提交一份可答辩的 Agentic RL 方案

**题目：**围绕一个已定位失败桶，提交任务/环境、基线、数据划分、奖励、算法核心、版本契约、预算与预期可证伪结果。尚未训练时如何表达结论？

**参考答案：**每个选择对应失败证据，先有可重放环境和非训练/固定检索/SFT基线；真实RL样本与更新需实际运行才能报告收益。未运行部分标实验方案，已核算部分仅为公式验收；负结果按覆盖、探索、奖励和系统逐项解释。

**面试追问：**只读很多论文就足够证明研究能力吗？

**追问回答：**论文阅读提供假设和方法，独立实现、受控实验、失败分析与答辩证据才支持研究执行能力。
