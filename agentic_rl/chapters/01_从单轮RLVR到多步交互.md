# 第 1 章：从一次回答到多步交互

读这一章前，只要知道：语言模型逐个生成 token（文本的基本单位）；单轮可验证奖励强化学习（RLVR）让模型回答一道题，再由事先写好的验证器给分。可从 [GRPO 与 RLVR](../../post_train/chapters/06_GRPO与RLVR.md) 的开头补这两个概念。本章先跟着一道题走完过程，再用符号精确描述；第一次阅读可先完成第 1.1—1.5 节，把第 1.6 节的进阶推导留到第二遍。

## 1.1 搜索改变了什么

单轮数学 RLVR 通常给定题目，让模型生成回答，最后由验证器打分。搜索问答会在生成途中暂停：模型先提出查询，搜索工具返回文本，模型读到新信息后再决定继续搜索还是回答。这里把模型提出的查询或回答叫**动作**，把工具实际返回的内容叫**观察**。动作会影响下次能看到什么，因此最后答案相同的两次运行，也可能经历完全不同的过程。[ReAct](https://arxiv.org/abs/2210.03629v3) 展示了交替组织推理、动作与观察的方式；这种结构本身不意味着模型已接受 RL 训练。

用一道贯穿本章的教学题来看：“城市甲所属国家的货币是什么？”

| 次序 | 来源 | 这一步的内容 |
| --- | --- | --- |
| 题目 | 用户 | 城市甲所属国家的货币是什么？ |
| 第一次动作 | 模型 | 查询“城市甲属于哪个国家” |
| 第一次观察 | 搜索工具 | “城市甲属于国家乙” |
| 第二次动作 | 模型 | 查询“国家乙使用什么货币” |
| 第二次观察 | 搜索工具 | “国家乙使用货币丙” |
| 最后动作 | 模型 | 回答“货币丙”，结束 |

从题目开始到结束的整串事件叫一条**轨迹**。一次“模型选择动作 → 环境给出观察”叫一步交互。模型可以控制查询词和何时停下，却不能直接控制工具返回的文字。终局正确也不能证明两次查询都必要：模型可能事先知道答案，或第一次就检索到完整答案。后面设计实验时，要用对照来检验工具的实际作用。

## 1.2 先分清状态、观测与历史

在例子里，模型能读到搜索结果，却未必知道工具是否正在故障、知识库是否刚更新。这说明**环境真实情况**与**模型看到的内容**要分开。令 $S_t$ 为第 $t$ 步的环境状态，包括知识库版本、已执行操作和剩余搜索预算；$O_t$ 为这一步模型收到的观察；$A_t$ 为模型生成的一次查询或回答。下标 $t$ 只是步数，不是 token 的位置。此前能看到的观察与动作按顺序组成**历史** $H_t=(O_0,A_0,O_1,\ldots,A_{t-1},O_t)$。

系统往往把完整历史缩写成模型当前输入 $C_t=f(H_t)$，其中 $f$ 是摘要规则。**策略** $\pi_\theta(A_t\mid C_t)$ 是参数为 $\theta$ 的模型在实际输入 $C_t$ 下选择动作的概率规则。要保存完整日志，因为摘要会丢细节。例如两次运行都被摘要成“未找到答案”，一次已经用完搜索预算，另一次还有两次机会；两者允许的下一动作不同。把剩余预算写回输入能修复这个具体问题，却不证明摘要保留了所有决策信息。

第一次读这一章，只需记住真实环境、模型当前输入和完整日志是三种不同的东西。关于“摘要保留多少历史才够”的严格条件，放在第 1.6 节再讨论。

## 1.3 一次调用与一个 token 是两个尺度

上节的“一步”是一整次查询或回答；模型内部却是逐个 token 生成。令这次动作 $A_t=(Y_{t,1},\ldots,Y_{t,L_t})$，其中 $L_t$ 是输出 token 数，$Y_{t,j}$ 是第 $j$ 个 token，$Y_{t,<j}$ 是它之前已生成的 token。整次动作的概率由这些逐 token 概率相乘得到：

$$
\pi_\theta(A_t\mid C_t)=\prod_{j=1}^{L_t}\pi_\theta(Y_{t,j}\mid C_t,Y_{t,<j}).
$$

查询参数、模型自主生成的解释和结束标记属于模型动作；检索结果属于环境观察。外部文本会进入下次输入，却不是模型在该位置采样出的动作。若环境规则固定，改变模型参数 $\theta$ 只能直接改变模型动作的概率，不能直接改变工具返回文本的概率。这是训练损失排除工具返回 token 的依据。更完整的轨迹概率分解见 [Search-R1 §3 与附录 A](https://arxiv.org/html/2503.09516v5)。

更严格的概率解释放在第 1.6 节。这里先记住：训练要提高模型所选动作的概率，因此只给模型自己生成的 token 计策略损失。最终结果怎样反馈给途中各步，是下一章的**信用分配**问题。

## 1.4 哪些文字参与训练

训练程序用一个称为**损失**的数衡量当前生成概率与目标之间的差距，并沿梯度调整模型。**损失掩码**（loss mask）是给每个 token 位置记一个 0 或 1。定义 $m_i=1$ 表示第 $i$ 个 token 由待训练模型生成且有效；题目、工具返回和补齐长度用的 padding 取 0。工具文本仍要留在上下文中，供后续回答读取。**因果注意力掩码**（attention mask）控制生成当前位置时能看哪些位置；损失掩码控制哪些预测计入训练目标。前者不能代替后者。

| 轨迹片段 | 用户题目 | 模型查询 | 工具文档 | 模型答案 |
| --- | --- | --- | --- | --- |
| 策略损失 mask | 0 | 1 | 0 | 1 |
| 后续步骤可作为上下文 | 是 | 是 | 是 | 回合已经结束 |

例如题目 12 个 token、模型查询 4 个、工具返回 30 个、模型答案 6 个，计入策略损失的是 $4+6=10$ 个 token；52 个 token 仍影响上下文长度和计算成本。训练数据应保留每次调用的实际输入、输出、token IDs（token 的编号）、文本来源角色与生成模型版本。若训练时用事后重建的完整历史替代采样时的摘要，动作概率就条件在另一份输入上，后续比较新旧模型动作概率也失去原来的含义。

## 1.5 结束不是一个布尔值就够了

至少区分成功回答、明确失败、无效工具请求、环境故障和工程截断。**任务终止**是按题目规则确实结束，例如“最多两次搜索”且预算已用完；**工程截断**是原任务本可继续，只因采样程序的时间或长度上限而停下。是否把截断轨迹记零分、重采样或估计剩余价值，必须与任务目标一致，不能让默认 `done` 决定数学问题。[Gymnasium 对时间限制的说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

## 1.6 第二遍再读：隐藏状态与策略梯度

若模型看不到完整环境状态 $S_t$，可以用**部分可观测马尔可夫决策过程**（POMDP）描述。它用 $P(s'\mid s,a)$ 表示环境在状态 $s$ 执行动作 $a$ 后到达状态 $s'$ 的概率，用 $\Omega(o\mid s')$ 表示新状态产生观察 $o$ 的概率。两者分别叫状态转移规则和观察规则。若规则已知，**信念状态** $b_t(s)=\Pr(S_t=s\mid H_t)$ 表示看到历史后，隐藏状态为 $s$ 的条件概率。实际 Agent 常不显式计算它；把摘要命名为 `state`，也不能直接断言它满足马尔可夫性。严格的状态充分性见 [RL 第 1 章](../../RL/chapters/01_MDP与回报.md)。

再把整条轨迹记为 $\tau$，最终得分记为 $R(\tau)$，当前策略的平均得分记为 $J(\theta)=\mathbb E[R(\tau)]$。在交互步数有限、回报可积且允许交换求导与期望的条件下，一种策略梯度表达是

$$
\nabla J(\theta)=\mathbb E\!\left[R(\tau)\sum_t\nabla\log\pi_\theta(A_t\mid C_t)\right].
$$

这里 $\nabla$ 表示对参数求梯度，$\log\pi_\theta(A_t\mid C_t)$ 是模型实际动作的对数概率。求和只覆盖模型动作，暂取不折扣回报。公式没有宣称每次搜索的贡献相同；实际训练若加入裁剪（clipping）、归一化或重复使用旧数据，还要重新判断估计性质。第一次阅读到这里，可以直接转去做检查题。

## 1.7 手算与检查

1. 一条记录依次含 12 个提示 token、4 个查询 token、30 个工具 token、6 个答案 token。有效策略 token 有多少？**提示：**10；模型处理完整上下文时的计算与存储仍受全部 52 个 token 影响。
2. 末尾工具调用超时，但重试会成功。直接记为“模型错误”会改变什么？**提示：**把环境可靠性混进策略质量；同时记录端到端失败率和条件于工具正常的表现。
3. 两个不同隐藏状态产生同一观测，是否立即否定 MDP 建模？**提示：**否定的是把当前观测当充分状态；可以保留隐藏状态模型或增加历史。
