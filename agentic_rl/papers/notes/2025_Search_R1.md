# Search-R1：把搜索纳入 LLM 的 RL 轨迹

**省流：**值得精读的搜索 Agent RL 代表作。它把多轮检索接入 PPO / GRPO，并明确排除外部返回 token 的策略损失。贡献重在训练问题的组织与实证，不是发明新的策略梯度定理。

## 身份、版本与水平

- 完整题名：*Search-R1: Training LLMs to Reason and Leverage Search Engines with Reinforcement Learning*。
- 作者：Bowen Jin、Hansi Zeng、Zhenrui Yue、Jinsung Yoon、Sercan Ö. Arık、Dong Wang、Hamed Zamani、Jiawei Han。
- 固定阅读版本：arXiv **2503.09516v5，2025-08-05**；首稿 2025-03-12。核验日期 2026-09-26。
- 正式状态：**COLM 2025**，已在[官方录用列表](https://colmweb.org/2025/AcceptedPapers.html)核对；[会议 PDF](https://openreview.net/pdf?id=Rwhi91ideu)。会议收录说明经过相应评审，不代表结论没有适用边界。
- [固定版本摘要](https://arxiv.org/abs/2503.09516v5) · [原文](https://arxiv.org/html/2503.09516v5) · [作者代码](https://github.com/PeterGriffinJin/Search-R1) · [本地 PDF](../pdf/2503.09516.pdf)。

**阅读价值判断：核心实证论文。**适合第一次学习多轮搜索 RL；不应仅用“顶会 / 非顶会”代替贡献类型、对照质量和复现难度的判断。

## 做了什么

模型交替输出查询和回答，搜索器提供环境观测，以最终答案匹配提供结果奖励。PPO 为主实验默认方法，同时比较 GRPO；检索片段保留在上下文，但不作为模型行动计算策略损失。方法见原文 §3。

**贡献边界：**PPO、GRPO、检索器和语言模型均来自已有技术；论文把它们组织成可直接训练的交互流程，并用实验分析 mask、起始模型和优化方法。复现者应把“系统整合产生可研究的新训练设置”和“推导了新优化算法”分开。

## 试验了什么

使用 Qwen2.5 的 3B / 7B Base 与 Instruct；NQ、HotpotQA 训练，七个 QA 基准评测，包括域外多跳任务。检索固定为 Wikipedia-2018、E5、每次 3 篇文档。基线包含直接回答、RAG、SFT、无搜索 RL、拒绝采样等；另做 PPO / GRPO、外部 token mask、检索数量与组大小分析。详见 §4—5 与附录。

v5 表 2 的 **7B 七任务平均 EM** 为：RAG 0.304，拒绝采样 0.348，Search-R1-base 0.431。这是数据集指标的平均，不是所有测试题直接合并后的总体正确率。[表 2](https://arxiv.org/html/2503.09516v5#S4.T2)

**自己核算：**相对 RAG 为 $(0.431-0.304)/0.304\approx41.8\%$，相对拒绝采样约 $23.9\%$，绝对差分别为 12.7 与 8.3 个百分点。摘要页面与正文出现 41% / 24% 的文字口径，引用百分比必须同时写清版本、基线与指标，不能把它们当作同一比较。

## 在哪里应用，哪些尚未证明

**论文展示：**冻结知识语料下的通用与多跳问答；**潜在应用：**知识库搜索助手、资料检索。这里没有据此认定已在开放网页、企业生产环境或持续变化的搜索接口可靠部署。

**本书审查问题：**同检索器和同语料很有价值，但还要逐项检查训练成本、查询次数、Base / Instruct 起点及检查点选择。单项任务差异与随机性不能被平均值遮蔽。PPO 更稳定的观察限于文中配置，不是 GRPO 必然不稳定的定理。
