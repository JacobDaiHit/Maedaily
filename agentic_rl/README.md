# Agentic RL：从回答问题到学习交互决策

**想做完整自测或准备面试，打开 [各专题题目索引](../references/面试复习与题目索引.md)。** 题目均给出完整条件、参考答案、常见追问与回答；基础讲解、手算与实验排错按专题连接。

Agentic RL 在这里指针对多步工具交互的强化学习。本卷只追一个问题：模型回答“城市甲所属国家的货币”时，若需要先查城市、再查国家，怎样让它学会**何时搜索、搜什么、何时停**？先把每次模型提出的请求叫动作，把工具返回叫观察，把从题目到答案的整串过程叫轨迹。第 1 章用这条轨迹定义所有记号；第 2 章才问最终得分怎样反馈到中途动作；第 3 章再问怎样证明训练确实改善了决策。可以先读例子和检查题，公式留到第二遍。

新手先读 [工具交互第一课](../入门/工具交互第一课.md) 后半部分，手算损失掩码（哪些文本参与训练）、回报（从当前起累计的分数）和工具成本，再运行 `python scripts/run_lesson.py trajectory`。

这一卷连接 [强化学习](../RL/README.md) 与 [后训练](../post_train/README.md)。目标不是记住 Agent 框架，而是能把“生成查询—调用工具—观察结果—继续决策”写成可训练、可评测的问题，并判断 RL 是否值得做。教学内容更新：2026-10-02；收录资料的原始核验日期：2026-09-26，本轮方法与作业核对见[验证记录](../references/版本与验证记录.md)。

按照 [年度计划](../references/年度学习任务与验收.md#annual-roadmap)，它属于项目 C 之后的进阶分支，优先放在第 9—10 月专题；第 5—6 月可以读第 1 章帮助理解环境交互。先完成单轮 RLVR、验证器和独立评测，再增加多轮工具，避免同时排查模型、奖励、检索器和调度器。

## 发展脉络：每一步增加了什么问题

```text
提示组织行动与观测（ReAct）
          ↓ 工具调用能否从数据中学习？
工具示范与自监督训练（Toolformer）
          ↓ 只有最终结果，如何优化多次决策？
多轮 RL 与分层时间尺度（ArCHer）
          ↓ 外部搜索结果怎样进入 rollout 和 loss？
搜索环境中的结果奖励 RL（Search-R1）
          ↓ 不同 Agent 如何复用同一个训练系统？
运行与训练解耦（Agent Lightning）
          ↓ 成本、奖励误差、长期信用与泛化仍待解决
具体问题驱动的近期实验，而非按发布时间追榜
```

这是一条教学问题链，不是“后一种方法全面替代前一种”的历史结论。提示、SFT、检索与 RL 可以组合，系统贡献也不等于新的最优性定理。

## 书籍与论文怎么搭配

基础参考沿用 [RL 书籍导读](../RL/books/README.md)：Sutton–Barto 补回报、策略梯度与函数逼近；已下载的 *Reinforcement Learning: Theory and Algorithms* 用来检查状态、覆盖和可学习性假设。后训练参考 [Lambert 的 RLHF 书稿](../post_train/books/README.md)，重点连接工具与评测章节。无需再下载重复副本。

| 资料 | 本卷用途 | 阅读层级 |
| --- | --- | --- |
| [Search-R1 省流版](papers/notes/2025_Search_R1.md) | 搜索轨迹、外部 token mask、结果奖励、PPO / GRPO 对照 | 核心精读，COLM 2025 |
| [Agent Lightning 省流版](papers/notes/2025_Agent_Lightning.md) | 调用级 transition、训练 / 运行解耦、信用分配实际做了什么 | 系统选读；此处固定 2025 原稿 |
| [Small Search Agents 省流版](../post_train/papers/notes/2609.28765_small_search_agents.md) | 奖励形状、低参数模型与高训练成本之间的区别 | 2026-09 新预印本，未独立复现 |

两篇本卷 PDF 的固定版本、来源与保存位置记录在 [manifest](papers/manifest.json)。笔记区分“发表状态”“阅读价值”“论文展示的应用”和“可能应用”；会议名、作者机构与下载量都不能代替实验审查。

## 最小实践

先运行 [轨迹核算实验](experiments/README.md)，核对损失 mask、回报、截断及相同任务上的预算比较。它只使用 Python 标准库和人工构造轨迹，**不是 LLM 训练或论文复现**。通过后再按第 3 章搭建小型冻结知识库任务，把真实模型实验保留为需要完成的能力证据。
