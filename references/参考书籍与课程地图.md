## 3. 官方文档怎样配合书籍

[PyTorch 2.7 autograd](https://docs.pytorch.org/docs/2.7/notes/autograd.html) 用于核对梯度语义，[可复现说明](https://docs.pytorch.org/docs/2.7/notes/randomness.html) 用于确认确定性边界。仓库框架实验实跑的是 2.7.1；课程中其他框架版本的代码不应直接视为兼容。

MindSpore 对照以 [2.4.0 PyNative](https://www.mindspore.cn/docs/en/r2.4.0/model_train/program_form/pynative.html) 与 [Graph 模式](https://www.mindspore.cn/docs/en/r2.4.0/model_train/program_form/static_graph.html) 为固定教学资料，未在本机训练验证。先按“参数—前向—损失—梯度—更新”的契约迁移，再处理 API 差异。

## 4. 精读、选读与下载原则

第 1 月精读 D2L 相关章节和 Transformer；第 2–6 月以 Lambert 与核心后训练论文为主，RL 理论书按缺口补；第 7–8 月读 Chinchilla、ZeRO、V3；第 9–10 月只追与实验问题有关的新论文。

已有 2 本公开书稿和论文固定版本保存在模块目录。在线教材保留官方链接，避免下载重复书库。所有已下载论文配有省流，说明水平判断、贡献、实验、展示的应用与限制；参考链接中的补充论文不都下载，以 [资料清单](readings.json) 为准。

读完一节，关闭页面写出三个东西：一个核心定义或公式、一个手算/代码例子、一个适用边界。写不出就回到该节，写得出就继续项目，不靠通读页数衡量学习进度。
