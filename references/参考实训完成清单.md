## 状态与证据口径

| 状态 | 含义 |
| --- | --- |
| `pending` | 尚缺实现、实际运行或对应证据；计划不能填成已完成 |
| `implemented` | 公共代码、配置和入口已存在，但完整实训证据仍待产生 |
| `executed` | 指定配置真实运行，所有声明的阶段、种子与变体有产物 |
| `verified` | 独立检查、重载或复算已执行并保留记录 |
| `quality_unqualified` | 实现与运行可复查，但预先登记的质量门槛未达到 |
| `not_applicable` | 配置未使用该功能，说明原因，不伪造通过 |

工程完成与效果判断使用不同字段。完整负结果可以完成参考研究交付；预先登记的质量门槛未通过仍如实记录，不能因工程检查通过而改写为模型合格。无法建立起始回归能力时，能力保持结论继续为 `pending`，不能以最终零分代替。

证据包 manifest 对实际打包的相对路径、字节数与 SHA-256 校验；绝对路径、路径穿越、别名路径、符号链接、缺少必需文件、未登记文件和内容篡改均拒绝。只有 hash 而没有权重或可重建路径，不能证明参数梯度可以回放。用于统计复算的包明确标为统计范围，不能扩大为训练全过程已经复现。

公共工具位于[reference_reporting.py](../post_train/experiments/reference_reporting.py)，独立测试位于[test_reference_reporting.py](../tests/test_reference_reporting.py)。它接收真实 JSONL 预测记录，通过标准库重算 Wilson 区间、整题族配对 bootstrap、能力桶、格式、长度、成本与多 seed 统计；同一题的采样重复始终留在族内。

2026-10-02 已通过 15 项纯标准库独立测试，包括复制证据包到临时目录后的 CLI 复算和采样成本与选中回答长度分离。另以明确 `example_only` 的 48 条合成记录实跑 CLI，样例位置为 `study_runs/reference_reporting_example_20261002/report/`；其 8 文件证据包通过实际 hash 校验。这个样例只验证统计与打包流程，没有模型训练或真实人工评审，不能替代上面的 A/B/C 实训证据。

2026-10-03 新增的 [独立正式运行核验器](../scripts/verify_reference_run.py)与[对抗测试](../tests/test_verify_reference_run.py)已在无 Torch 的 Python 3.13 实跑 17 项、14.161 秒全部通过。训练环境 Python 3.11 与 Python 3.13 在 68 个派生成本字段出现约 1e-16 至 1e-14 的求和末位差异，核验器只对明确命名的派生成本/时间/ratio 有限浮点使用绝对和相对 1e-12 容差。原始字节 SHA、gold、判定、bool、整数、ID、配置与置信参数仍精确；1e-4 改动和评分/身份篡改仍拒绝，没有修改冻结统计模块或原始报告。

完整回归测试由根协调运行，146 项、364.850 秒全部通过且无资源警告；该计数与独立核验器的 17 项分开。原本地日志为 `study_runs/reference_final_unittest_portable_20261003.log`，本地 15 个注册默认课程入口也已真实运行退出 0。公开证据的复算命令不需要这些 ignored 日志。

每条记录必需 `sample_id/family_id/panel/bucket/arm/training_seed/training_run_id/checkpoint_id/correct/format_valid/input_tokens/output_tokens/elapsed_seconds/output_text/termination_reason`；盲表另需实际 `prompt_text`。重复采样指定不同 `generation_index`。各 arm 的训练 seed 集合及每 seed 的题目、族、桶与协议必须一致，缺失或重复硬拒。

多候选采样另保存 `evaluation_cost_tokens` 和 `evaluation_cost_input_tokens`，分别汇总所有候选输出与重复 prompt 成本，不得小于选定回答的单条值。长度统计仍使用选中的 `output_tokens`，不能把采样更多次误写成回答变长。

独立训练回执使用 `training_run_id/training_seed/arm/checkpoint_id/optimizer_steps/initial_weight_hash/final_weight_hash`。无回执时只报告登记 seed、实训练来源 `unverified`；有回执检查身份、真实更新声明与权重变化，仍需证据包核对对应文件。三 seed 的离散度不和题族区间混成一个未经实现的总体置信区间。

```powershell
python post_train/experiments/reference_reporting.py --records 实际预测.jsonl --training-receipts 实际训练回执.json --output-dir study_runs/新的报告目录
python post_train/experiments/reference_reporting.py --verify-package study_runs/新的报告目录/evidence
python -m unittest discover -s tests -p test_reference_reporting.py -v
```

上面的输入文件名是明确待替换的位置，不是已运行的 A/B/C 文件。工具默认 bootstrap seed 19、2,000 次；报告可使用一个具体的低预算配置验证工作流，但缩短流程不能代替完整参考配置。

输出目录生成原始记录副本、`report.json/report.md`、匿名 `blind_review/` 和可独立统计复算的 `evidence/`。身份映射写在输出目录外的单独封存文件，不放入匿名包。空白表保留 `not_reviewed`；AI 辅助复核不能冒充外部人工盲评。统计证据包携带实际输入与标准库源码，复算输出应写到包外的新目录，不修改已冻结包。
