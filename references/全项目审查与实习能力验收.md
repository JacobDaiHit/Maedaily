## 2. 每节课的内容验收

“足够详细”按推理是否闭合判断，不使用字数阈值冒充质量。核心系统课至少具备以下内容；入门课先完成基本层，再明确链接到相应深读。

1. **定义问题：**输入、输出、训练数据、被优化对象与目标；每个首次出现的符号有对象和形状。
2. **逐步展开：**关键公式从假设推到结论，说明负号、归一化、停止梯度与边界；区分定理、经验与启发式。
3. **独立例子：**完整给出数据、初始值、损失归约和更新规则，让读者能合上讲义复算。
4. **实现联系：**核心函数、张量轴或伪代码可对应现有程序；说明骨架与独立可运行文件的区别。
5. **深入追问：**至少一个反例、失效条件或设计取舍，给出可证伪的排查方法。
6. **学习证据：**作业要求提交推导、代码、输出或实验表；参考答案解释中间过程与判断标准。

核心课的作业覆盖口述、手推、手写核心函数、带症状排错与受控实验。难度递进：能说清 → 能算对 → 能实现 → 能解释失败 → 能提出下一步实验。不能用增加同义定义题替代深入学习。

本轮 **33 个核心单元各有 6 道完整主问题，共 198 题**；连同入门、短程序、实验说明和论文阅读，合计 **287 道主问题与 287 道带答案的追问，分布在 71 份文件**。每节作业先独立作答，再用参考答案检查假设和中间过程。手推保留符号及数值，核心函数提交最小输入与输出，排错提交排除顺序，实验提交协议与实际结果；仅摘录答案不能记为完成。

## 3. 面试题与“面经”的证据规则

本仓库题目按算法技术面试的常见形式原创设计。只有能定位原始面经的题，才标注公司、日期与轮次；第三方汇总、传闻和岗位要求不能当作 DeepSeek 真题。目前没有经核验的完整 DeepSeek 私有题库。

每道题包含完整条件、参考答案、面试追问和追问回答。实现题明确函数接口、最小输入与正确输出；排错题给症状并要求区分解释；研究题给预算、基线、指标和可以推翻假设的证据。作业可参考公开方法和实际岗位职责，但不预设某家公司一定问这些题。

## 5. 学完后的作品与模拟面试验收

课程阅读完成后，学习者提交三个项目的实际证据，而非仅提交讲义摘抄。具体范围沿用 [年度目标](../GOAL.md) 与 [年度任务](年度学习任务与验收.md)。

- **项目 A，基模机制：**能从数据到 loss 独立实现小型语言模型，定位标签、mask、梯度错误；完成训练、验证、保存恢复与一项预算对照。增加 RoPE / KV cache 时给出数值等价与失败反例。
- **项目 B，SFT 与 DPO：**同一初始模型、同题族独立切分，核对 SFT token mask 和 DPO 四个 log-prob；报告训练外生成质量、长度、成本与一项单因素消融。
- **项目 C，RLVR：**验证器先通过正确性与作弊边界检查，再完成真实策略采样与更新；比较不训练、继续 SFT 和 RL，并报告零方差组、长度、预算和失败案例。

模拟技术面分四段：20 分钟讲一个算法的目标与推导；30 分钟手写核心函数并用小输入核对；20 分钟从给定日志定位训练问题；20 分钟答辩自己的实验与一个失败结果。每段按正确性、条件、实现与证据评分，不能因会背公式而跳过代码和项目。

课程自测可用同一评分口径：0 分为无法形成正确解释；1 分为能复述但漏掉关键条件；2 分为在提示下完成且能复核；3 分为独立完成、说明边界，并给出有效反例或实验证据。四段均至少 2 分，代码与项目段达到 3 分后，再做陌生题模拟。这个标准用于本仓库学习验收，不是 DeepSeek 官方录用分数线。
