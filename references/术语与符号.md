# 全项目共用的术语与符号

[总入口](../README.md)

符号以每章的局部定义为准；尤其注意奖励下标、损失正负号，以及按 token 还是按序列平均。

| 符号或术语 | 含义 | 容易混淆之处 |
| --- | --- | --- |
| $s_t,a_t$ | 时刻 t 的状态、动作 | LLM 可把完整前缀作为状态，下一 token 作为动作 |
| $P$ | 环境转移分布 | 不是策略；在工具场景也包含外部响应 |
| $r_{t+1}$ 或 $r_t$ | 执行动作后取得的奖励 | 两种编号约定均常见，按章内定义使用 |
| $G_t$ | 从 t 起的折扣回报 | 不是即时奖励，也不必是最终任务正确率 |
| $\gamma$ | 折扣因子 | 无限时域压缩证明通常要求小于 1；有限生成任务需另看终止设定 |
| $V^\pi,Q^\pi$ | 策略 pi 的状态价值、动作价值 | 神经网络预测值只是估计，不等于真实价值 |
| $A^\pi$ | 优势，一般为 Q 减 V | 估计优势的 baseline 不一定是学习的 critic |
| $\pi_\theta$ | 当前可训练策略 | 与采样策略及参考策略角色不同 |
| $\pi_{\mathrm{old}}$ | 本批 rollout 的采样策略 | PPO 比率的分母；每轮采样后可变化 |
| $\pi_{\mathrm{ref}}$ | 正则化或偏好目标的参考策略 | 不自动等于 old；有些迭代方法也会更新 reference |
| rollout | 按策略与环境交互得到的轨迹 | 多条回答可对应同一 prompt 的多个 rollout |
| on-policy / off-policy | 数据是否来自正在评价或更新的策略 | 具体算法允许的偏离程度需看校正方式 |
| offline RL | 主要从固定历史数据学习控制策略 | 并非所有使用离线数据的监督训练都等同于完整离线 RL |
| $x,y$ | prompt 与完整回答 | 序列概率由各 token 条件概率相乘得到 |
| mask | 选择参与计算的位置 | attention mask、loss mask、有效 rollout mask 作用不同 |
| KL | 两个分布的相对熵 | 方向、采样分布和估计器不同会改变意义 |
| reward model / verifier | 学习的打分器 / 验证程序 | 两者都可能给出错误反馈，不能当成任务真值 |
| RLHF / RLVR | 从人类反馈 / 可验证奖励进行强化学习 | GRPO 是优化方法，RLVR 是反馈设置，不是互斥算法 |
| distillation | 以教师信号训练学生 | 教师经过 RL 不意味着学生也接受了 RL 更新 |
| pass@k | k 次采样中至少有一次成功的指标或估计 | 不是多数投票正确率，不等于部署时能挑中正确答案 |
| ablation | 控制其他条件、改变某一组成的对照 | 同时换模型、数据、预算不能清楚隔离算法贡献 |

梯度公式默认讨论被优化的标量目标。阅读代码时先确认是在最小化 loss 还是最大化 reward，再核对负号；参考策略、旧 log-prob、采样奖励或优势是否停止梯度，须按算法定义判断。

## 训练基础、模型与交互系统

| 符号或术语 | 含义 | 容易混淆之处 |
| --- | --- | --- |
| $B,T,d,V$ | 批量、序列长度、隐藏维度、词表大小的常用记号 | $V$ 在 RL 中也可表示价值函数，按局部定义判断 |
| $Q,K,V$ | Attention 的 query、key、value 矩阵 | Attention 的 $Q$ 不是 RL 的动作价值函数 |
| logits | 归一化前的分类分数 | 不是概率；交叉熵 API 往往直接接收 logits |
| VJP | 向量与 Jacobian 的乘积 | 反向传播通常不显式构造完整 Jacobian |
| BPTT | 沿展开时间图的反向传播 | 参数跨时间共享；截断会切断部分梯度路径 |
| next-token / teacher forcing | 给定真实前缀预测下一个 token | 训练时前缀与自由生成时前缀分布可能不同 |
| prefill / decode | 处理已有提示 / 逐步生成新 token | 两阶段的并行度与瓶颈不同 |
| KV Cache | 已有前缀在各层的 key/value 或压缩表示 | 占用随长度、批量、层数、KV 维度增加 |
| MoE / MLA | 稀疏专家 / 多头潜在注意力 | 分别主要涉及 FFN 容量与注意力表示/缓存，不是同一机制 |
| DP / TP / PP | 数据 / 张量 / 流水线并行 | 状态分片是另一维度，能与这些方式组合 |
| Agent / policy | 带模型、工具、状态与执行器的系统 / 决策分布 | 系统有重试和记忆不说明模型权重更新 |
| observation / action | 环境返回的信息 / 策略作出的选择 | 工具返回 token 可以进入上下文，但通常不作为策略行动计算 loss |
| $S_t,O_t,A_t$ | 第 $t$ 步的环境状态、模型所见观察、模型所选动作 | 真实环境状态未必都能直接给模型看；各章大小写约定以局部定义为准 |
| $H_t,C_t$ | 截至第 $t$ 步的可见历史、实际送给模型的上下文 | $C_t$ 可能是 $H_t$ 的摘要，摘要不自动保留所有决策信息 |
| POMDP / 信念状态 | 部分可观测决策模型 / 给定历史后隐藏状态的条件分布 | 形式模型不意味着实际 Agent 显式计算了该分布 |
| loss mask / attention mask | 哪些 token 直接计入训练损失 / 当前位置能读取哪些位置 | 工具返回可供后续读取，但通常不作为模型生成目标计分 |
| credit assignment | 把结果信号分配到影响它的决策 | 给每次调用相同终局奖励是简单策略，不等于细粒度因果归因 |
| termination / truncation | 任务真正结束 / 外部限制提前停止采集 | 工程截断可能仍需尾部价值，按目标时域定义处理 |

一篇论文复用符号时，先写变量的对象、形状、时间尺度，再代入公式。尤其不要把调用级折扣直接无说明地套到 token 级更新。
