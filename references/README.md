# 阅读附录：需要查证时从这里进入

正文负责把概念和计算讲清，本目录负责回答“接下来读什么、术语怎么统一、某个结论依据是什么”。第一次学习不需要先通读附录；遇到疑问再按下面的问题查。

| 遇到的问题 | 从哪里开始 |
| --- | --- |
| 不知道一个缩写或符号指什么 | [术语与符号](术语与符号.md)，再回到首次出现的正文段落 |
| 不知道各专题为何按这个顺序读 | [学习路线与发展脉络](学习路线与发展脉络.md) |
| 想把章节对应到具体练习和项目 | [年度学习任务与验收](年度学习任务与验收.md) |
| 想补一本书的特定章节 | [参考书籍与课程地图](参考书籍与课程地图.md) |
| 想从正文转向论文 | [论文索引](论文索引.md) 与 [阅读方法与证据标准](阅读方法与证据标准.md) |
| 想写一篇可复核的论文笔记 | [论文省流模板](论文省流模板.md) |
| 想知道资料版本或本机验证范围 | [版本与验证记录](版本与验证记录.md) |

使用顺序是“正文例子 → 自己复算 → 查附录中的定义或出处 → 返回正文”。术语表是检索工具，不能代替章节里第一次出现术语时的解释。论文索引提供进一步阅读入口，不能把论文里的实验结论直接当作本地已复现的结果。
