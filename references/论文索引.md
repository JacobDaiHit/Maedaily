## 阅读路线

结构基础建议：Transformer → 按缺口读位置与训练 → 第 7–8 月的 Chinchilla / ZeRO / V3。Agent 分支建议：ReAct → Reflexion → Search-R1 → Agent Lightning → Small Search Agents。它们分别涉及提示、反馈记忆、参数训练和系统接口，不是一条统一算法的版本升级线。

后训练主线建议：GAE → PPO → InstructGPT → DPO → DeepSeekMath → R1 → Dr. GRPO → 验证器误差。Small Search Agents 用于工具轨迹与实验审查；阅读其结果时重点检查验证集和检查点选择。

离线 RL 主线建议：DQN 与函数逼近 → 离线 RL 数据覆盖 → FQL → ALBUM。ALBUM 的新稿身份和确定性假设应与其理论贡献一起阅读。
