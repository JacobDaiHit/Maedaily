# 实验：纯本地工具调用状态机

[tool_state_machine.py](tool_state_machine.py) 用确定性规则策略计算 `(7+5)/3`，把工具请求、校验、观察、重试与停止写入完整事件轨迹。它只使用 Python 标准库，不调用模型、不联网、不执行任意代码，不代表真实 LLM Agent 评测或强化学习训练。

## 运行

在仓库根目录执行：

```powershell
python agent_design/experiments/tool_state_machine.py
```

本机验证命令为：

```powershell
& 'C:\Python313\python.exe' agent_design/experiments/tool_state_machine.py
```

成功时打印 JSON，包括检查数、九个案例的终止状态，以及一次暂时故障后恢复的完整轨迹。运行不会写入任何结果文件；如需保留，可以自行将输出重定向到独立路径。

## 设计与边界

- 工具只有 `add` 和 `divide`，参数字段、数值范围和除零由执行器校验；字符串不会被解释为代码。
- 第一步结果是第二步参数，实际观察成功前不会推进计划。
- 重试保留逻辑请求 ID，但每次执行消耗调用预算；永久失败不会无限重试。
- 已完成两步才报告最终答案；预算不足时中间结果不会冒充完成结果。
- 全部动作是纯计算。真实有副作用工具的幂等性、超时并发与权限管理，需要另行实现和验证。

## 学习任务

先根据 `ALLOWED_TRANSITIONS` 画图，然后不运行代码预测 `max_calls=1`、`temporary_failures=1`、`denominator=0` 的结果。最后观察日志中“参数校验失败”与“暂时执行失败”发生在不同位置，解释为什么只对后者重试。

进一步练习是接入一个会输出合法/非法请求的模拟决策器，测试接口契约。接入真实模型后要增加独立任务集与选择动作的准确性评测，不能直接沿用本实验的检查通过率作为模型成功率。
